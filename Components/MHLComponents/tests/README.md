# Нативные тесты компонентов

`LightLibTest.dproj` проверяет совместимость компактных коллекций: ZIP/PPMd,
извлечение по точному имени при устаревшем INSNO, несколько серий INPX,
раздельные номера источников, преобразование WebP в PNG, цвет и прозрачность,
обложки, сохранность FB2 и кодировки windows-1251.

Соберите проект в RAD Studio в конфигурации Release для Win32 или Win64.
Результат находится в `Out\Win32` или `Out\Win64`. Рядом с EXE должны быть
`tools\7zip\7za.exe` и `tools\webp\libwebp.dll` соответствующей архитектуры.
Скопируйте эти две папки из подготовленного runtime `Program\Out\Bin` или
`Program\Out\Bin64`, вместе с лицензиями. WebP runtime воспроизводится командой
`scripts\prepare-webp-runtime.ps1 -Platform Win32` или `Win64`.

Запуск без аргументов создаёт небольшие временные архивы и удаляет только
собственную временную папку. Личный профиль и каталог книг не открываются:

```powershell
& .\Out\Win64\LightLibTest.exe
```

Необязательные аргументы — путь к существующему архиву и точное имя одной FB2:

```powershell
& .\Out\Win64\LightLibTest.exe 'H:\LibFlib\lib.flib\f.fb2-173909-177717.zip' '173914.fb2'
```

Такой запуск читает одну книгу, проверяет PNG и сохранность исходного потока.
Архив не изменяется, коллекция не индексируется. Проверка разметки использует
представление байтов без предположения, что настоящая книга сохранена в UTF-8.

Подтверждённый результат 05.10.2026 для обеих архитектур: 51 проверка на
синтетических данных; 57 для `173914.fb2` (1 картинка PNG); 133 для `821887.fb2`
из `fb2-821884-824013.zip` (39 картинок PNG). SHA-256 двух исходных архивов до
и после запусков совпал. Нативный `MetabibImportTest` отдельно проверяет реальный
импорт INPX, несколько серий, раздельные пользовательские данные источников,
полное обновление и режим сохранения исходного WebP.
