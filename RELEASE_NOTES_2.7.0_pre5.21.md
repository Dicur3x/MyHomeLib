# HomeLib Ru pre5.21 — 2.7.0.1089

- В читалке рядом расположены значки добавления закладки и заметки, затем кнопка «Закладки и заметки». В общем окне видны фильтры обоих типов; по умолчанию показаны все записи.
- При добавлении закладки можно задать название. Новые закладки сохраняют время; оно показывается в местном часовом поясе. Для старых записей неизвестное время не подменяется текущим.
- Заметка без выделения захватывает весь текст видимой страницы. Закладки других книг тоже доступны в общем окне; экспорт и удаление учитывают выбранную книгу и фильтры типов.
- Любимые авторы входят в экспорт и импорт «Данных пользователя». В меню любимых авторов есть отдельные команды переноса; импорт объединяет списки без повторов.
- Тёмная тема применяется до создания окон. Окно обновлений учитывает системный шрифт и пересчитывает размеры при изменении DPI и размера текста.
- Конвертер дополнен MHT/MHTML, CHM, PalmDoc/zTXT, TCR и Microsoft Write. PDF и DjVu можно преобразовать, если у них есть пригодный текстовый слой; программа предупреждает о возможных ошибках OCR и изменении вёрстки. Сканы без текста не конвертируются, распознавание не запускается.
- Файлы с числовыми и ошибочными расширениями распознаются по содержимому рабочей копии. Оригиналы сохраняются. Для сохранённых веб-страниц исправлен разбор старой вложенной вёрстки и ссылок.
- Ошибка отдельной обложки больше не мешает чтению метаданных книги. При ошибке чтения карточка показывает причину и имя файла.
- FBD из ZIP PPMd и solid 7z передаёт описание, обложку и иллюстрации в карточку. Исправлены поиск путей с разными разделителями в 7z и скрытая галерея у книги с парным FBD.
- Читалка получила статус beta. Убрана зависимость от установленного LibreOffice: DOC, PPT и XLS используют общий DocSharp, современные Office/OpenDocument разбираются локально, WPS/WPD читаются компактными комплектными библиотеками. Эти форматы доступны и для экспорта в FB2/EPUB с указанными ограничениями.
