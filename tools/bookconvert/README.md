# Конвертация книг в FB2 и EPUB

Поддерживаются **FB2 → EPUB**, **EPUB → FB2**, а также **FB3, TXT, HTML/HTM/XHTML, Markdown, RTF, DOC/DOT, DOCX/DOCM/DOTX/DOTM, ODT/OTT, PPT/PPTX и варианты, XLS/XLSX и варианты, ODP/OTP, ODS/OTS, WPS/WPD, Kindle MOBI/AZW/AZW3/PRC без DRM, MHT/MHTML, CHM, PalmDoc/zTXT (PDB), TCR и Microsoft Write (WRI) → FB2 или EPUB**. Пользователь выбирает один формат результата. Преобразование выполняется локально. Используются поставляемые Python, DocSharp и KindleUnpack; компактный разборщик Markdown Mistune включён в конвертер. LibreOffice для этих направлений не нужен.

Выберите книгу, нажмите правую кнопку мыши → **«Конвертировать / сохранить» → «Экспорт в FB2…» или «Экспорт в EPUB…»**. Неподдерживаемые направления скрыты; повторное преобразование в текущий формат не предлагается. Для записи каталога, которая обозначает целый архив, конвертер проверяет содержимое после запуска. Если подходящих книг несколько, предлагает выбор. Файлы, уже имеющие выбранный формат результата, в этот выбор не попадают. PDF и DjVu конвертируются при наличии пригодного текстового слоя. Сканы без текста отклоняются; новое OCR не выполняется. Перед использованием результата программа предупреждает о возможных ошибках распознавания и изменении вёрстки.

Конвертер сохраняет текст, разделы и подглавы, основные выделения текста, таблицы, изображения и ссылки на сноски. Для EPUB создаются оглавление и стандартный пакет EPUB 3. PNG/JPEG/GIF переносятся без пересжатия; BMP/TIFF и офисные EMF/WMF переводятся в PNG системным компонентом Windows. Описание исходного FB2 сохраняется в метаданных EPUB; сведения EPUB, для которых нет прямого поля FB2, сохраняются в `custom-info`.

EPUB допускает оформление, которое FB2 не описывает. Списки преобразуются в абзацы с нумерацией, абзацы внутри ячеек разделяются переносами. Основные CSS-выделения (жирный, курсив и зачёркивание) переносятся; точная вёрстка, произвольные CSS-селекторы и встроенные шрифты могут отображаться иначе. Такие упрощения перечисляются в отчёте. SVG-обёртка одного обычного изображения заменяется этим изображением с сохранением его данных. Вложенные таблицы переносятся последовательными блоками с сохранением текста, изображений и ссылок; сложные цитаты с внутренними разделами представляются разделами FB2. Эти изменения оформления явно перечисляются в отчёте. Сложные SVG-композиции, формулы, аудио, видео, внешние изображения и зашифрованные книги отклоняются с объяснением.

Исходник открывается только для чтения. Существующий файл результата не заменяется. Сначала создаётся и проверяется отдельный временный файл рядом с результатом, затем он публикуется без перезаписи. Неудачное преобразование удаляет собственный временный файл. HomeLib Ru дополнительно запускает преобразование в изолированной рабочей папке и убирает её после отмены или завершения.

Для PDF/DjVu окно экспорта показывает обработанные страницы и проценты. Обработка страниц занимает 0–95%, затем собирается и проверяется книга; 100% означает, что результат записан. Большая книга может обрабатываться дольше трёх минут: остановка по времени происходит при отсутствии продвижения более трёх минут, а общий защитный предел составляет шесть часов. Кнопка «Отмена» останавливает конвертер вместе с его дочерними процессами и убирает неполный результат. Для остальных входных форматов сохраняется прежний общий предел в три минуты.

Редкие недопустимые символы текстового слоя PDF/DjVu остаются на своих местах как видимые пометки вида `[OCR U+0011]`; номера страниц перечисляются в предупреждениях. Угадать исходную букву по такому управляющему коду нельзя. Если большая часть текстового слоя повреждена, преобразование останавливается с объяснением. XML всех созданных глав EPUB проверяется до записи готовой книги.

Для новых входных форматов:

| Формат | Что переносится | Ограничения |
| --- | --- | --- |
| TXT | Текст UTF-8, UTF-16 или Windows-1251, явные переносы и пустые строки | Главы по догадке не создаются; исходные переносы строк сохраняются |
| FB3 | Разделы и подглавы, основные выделения, таблицы, растровые изображения и сноски | Сложное оформление и шрифты заменяются оформлением электронной книги |
| Markdown | Заголовки, выделения, списки, таблицы, блоки кода, сноски и локальные изображения | HTML внутри Markdown показывается как текст; используется Mistune 3.3.4 |
| MOBI/AZW/AZW3/PRC | Незашифрованные MOBI7 и KF8 через поставляемый KindleUnpack; текст и ресурсы | Старый MOBI разбирается из подготовленного HTML, KF8 — из EPUB. DRM, PalmDoc без MOBI и неизвестные варианты отклоняются |
| HTML | Заголовки, абзацы, основные выделения, таблицы, списки, внутренние и интернет-ссылки; PNG/JPEG/GIF рядом с файлом или в data URI | Обрабатывается выбранный HTML, а не весь связанный сайт. Внешние картинки не скачиваются. Сценарии, внешние CSS и сложное оформление не переносятся. Для HTML, извлечённого из архива, доступны только уже присутствующие рядом ресурсы и data URI |
| RTF | Кодировки заголовка и шрифта, Unicode, абзацы, жирный/курсив/зачёркивание, PNG/JPEG/GIF | Таблицы упрощаются до строк с табуляцией, сноски включаются в основной текст. Сложные поля и страничная вёрстка упрощаются |
| DOCX | Основной текст, заголовки и наследуемые стили, выделения, растровые изображения, таблицы, ссылки, сноски | Сложная нумерация упрощается; используются итоговый текст и оформление электронной книги. Колонтитулы, макеты страниц и шрифты не переносятся |
| ODT | Основной текст, заголовки, основные стили, растровые изображения, таблицы, ссылки и сноски | Сложная нумерация заменяется маркерами. Страничная вёрстка и колонтитулы не переносятся |
| DOC/DOT | Сначала DocSharp читает документ в DOCX, затем действует тот же путь, что для DOCX | Сохраняются ограничения встроенного DocSharp: защищённые, повреждённые и очень старые варианты DOC могут не поддерживаться |
| PPT/PPS/POT, PPTX/PPTM/PPSX/PPSM/POTX/POTM, ODP/OTP | Слайды в порядке презентации, текст, таблицы, заметки докладчика и встроенные изображения | Расположение объектов и анимация упрощаются. Диаграммы передаются сохранёнными данными; OLE/SmartArt без полного переноса отклоняются при экспорте |
| XLS/XLT, XLSX/XLSM/XLTX/XLTM, ODS/OTS | Листы с адресами ячеек, сохранённые значения, изображения и данные диаграмм | Формулы не вычисляются, макросы не выполняются; сложные числовые форматы упрощаются |
| WPS, WPD | Текст и изображения через комплектные libwps/libwpd | Требуется 64-разрядная Windows, установленные офисные приложения не нужны; исторические варианты поддерживаются в пределах библиотек |
| MHT/MHTML | Основная сохранённая веб-страница и вложенные изображения | Без обращения к сети. Сложная табличная вёрстка и списки разворачиваются в блоки с предупреждением |
| CHM | HTML-разделы в порядке HHC-оглавления, изображения и внутренние ссылки | Чтение уже поставляемым 7-Zip. Без HHC разделы идут по именам; служебные элементы веб-страницы упрощаются |
| PDB | Текст PalmDoc без сжатия и с PalmDoc-сжатием, zTXT с zlib | PDB — семейство несовместимых контейнеров. iSilo и eReader не поддерживаются; повреждённые записи отклоняются |
| TCR, WRI | Текст, переносы строк и кириллица старых кодировок | Страничное оформление Write упрощается; встроенные объекты не переносятся |
| PDF, DjVu | Пригодный текстовый слой и найденные области иллюстраций | Используются PDFium и DjVuLibre из дистрибутива. Сложные колонки, таблицы, формулы и OCR требуют сверки с оригиналом. Строки сохраняются; точная страничная вёрстка не переносится |

Формат определяется по сигнатуре содержимого, в том числе у файлов с числовым расширением. Переименование выполняется только для рабочей копии. LIT, LRF, защищённые книги и неподдерживаемые варианты PDB пока не конвертируются. PDF/DjVu с изображением и без читаемого текста на внутренней странице отклоняется целиком, чтобы не выдать неполную книгу за успешно преобразованную. Обложка на первой странице допускается, если дальше есть читаемый текст.

Из новых текстовых форматов сначала строится EPUB с читаемой структурой. Если выбран FB2, эта структура преобразуется в FB2; результат EPUB при этом пользователю не сохраняется. Это внутренний этап, а не последовательная конвертация пользовательской книги туда и обратно. Неподдерживаемые изображения, формулы, встроенные объекты и отсутствующие иллюстрации вызывают понятную ошибку. Упрощения записываются в отчёт.

Текущие ограничения: исходный файл до 64 МБ; распакованные ресурсы пакета суммарно до 256 МБ, до 20 000 ZIP-записей; отдельная новая растровая иллюстрация до 16 МБ; XML до 500 000 узлов и глубины 128. Повреждённая структура не публикуется как готовая книга.

DjVu обрабатывается порциями до четырёх страниц: DjVuLibre повторно использует открытый документ и общие словари. Порция RGB ограничена 31 МБ; число текстовых страниц и точные размеры каждого растра проверяются, поэтому байты изображения не принимаются за заголовок следующей страницы. Весь многостраничный растр в память или на диск не выгружается. Счётчик прогресса обновляется после обработки каждой страницы.

Для разработчиков:

```text
python -X utf8 convert_book.py source.fb2 result.epub --report report.json
python -X utf8 convert_book.py source.epub result.fb2 --report report.json
python -X utf8 convert_book.py source.docx result.epub --report report.json
python -X utf8 convert_book.py source.txt result.fb2 --title "Название книги" --language ru
```

Путь отчёта должен быть новым и отличаться от путей книг. Код завершения `0` означает завершённое преобразование, `1` — ошибку. Отчёт JSON содержит `output`, `size`, `warnings` либо `error`.

Регрессионные тесты находятся в `tests/test_conversion.py` и `tests/test_text_inputs.py` и `tests/test_legacy_fixed.py`, `tests/test_office_inputs.py`. При заданных `HOMELIB_TEST_FB2_SCHEMA`, `HOMELIB_TEST_EPUBCHECK` и `HOMELIB_TEST_JAVA` они дополнительно используют полную схему FB2 и официальный EPUBCheck. Схемы, EPUBCheck и тестовые зависимости в дистрибутив программы не включаются. CLI обрабатывает DOCX; двоичный DOC подготавливается обёрткой HomeLib Ru через поставляемый DocSharp.
