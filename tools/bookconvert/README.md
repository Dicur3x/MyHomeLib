# Конвертация FB2 и EPUB

Два отдельных направления: **FB2 → EPUB** и **EPUB → FB2**. Преобразование выполняется локально, без сетевых запросов и без установки дополнительных пакетов. Используется стандартная библиотека Python, уже поставляемого с HomeLib Ru.

Конвертер сохраняет текст, разделы и подглавы, основные выделения текста, таблицы, изображения и ссылки на сноски. Для EPUB создаются оглавление и стандартный пакет EPUB 3. Данные изображений не пересжимаются. Описание исходного FB2 сохраняется в метаданных EPUB; сведения EPUB, для которых нет прямого поля FB2, сохраняются в `custom-info`.

EPUB допускает оформление, которое FB2 не описывает. Списки преобразуются в абзацы с нумерацией, абзацы внутри ячеек разделяются переносами. Основные CSS-выделения (жирный, курсив и зачёркивание) переносятся; точная вёрстка, произвольные CSS-селекторы и встроенные шрифты могут отображаться иначе. Такие упрощения перечисляются в отчёте. SVG-обёртка одного обычного изображения заменяется этим изображением с сохранением его данных. Сложные SVG-композиции, формулы, аудио, видео, вложенные таблицы, внешние изображения и зашифрованные книги отклоняются с объяснением.

Исходник открывается только для чтения. Существующий файл результата не заменяется. Сначала создаётся и проверяется отдельный временный файл рядом с результатом, затем он публикуется без перезаписи. Неудачное преобразование удаляет собственный временный файл. HomeLib Ru дополнительно запускает преобразование в изолированной рабочей папке и убирает её после отмены или завершения.

Текущие ограничения: исходный файл до 64 МБ; распакованные ресурсы EPUB суммарно до 256 МБ, до 20 000 ZIP-записей; XML до 500 000 узлов и глубины 128. Непредставимая или повреждённая структура приводит к ошибке, а не к успешному результату с пропавшими фрагментами.

Для разработчиков:

```text
python -X utf8 convert_book.py source.fb2 result.epub --report report.json
python -X utf8 convert_book.py source.epub result.fb2 --report report.json
```

Путь отчёта должен быть новым и отличаться от путей книг. Код завершения `0` означает завершённое преобразование, `1` — ошибку. Отчёт JSON содержит `output`, `size`, `warnings` либо `error`.

Регрессионные тесты находятся в `tests/test_conversion.py`. При заданных `HOMELIB_TEST_FB2_SCHEMA`, `HOMELIB_TEST_EPUBCHECK` и `HOMELIB_TEST_JAVA` они дополнительно используют полную схему FB2 и официальный EPUBCheck. Схемы, EPUBCheck и тестовые зависимости в дистрибутив программы не включаются. Обратное преобразование результата используется только в тестах сохранности; пользователь выбирает одно направление.
