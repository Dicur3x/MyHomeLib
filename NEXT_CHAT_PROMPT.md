В 1069 дополнительных переносов upstream нет: исправляется медленное
заполнение издательских серий по замечанию владельца (4500 книг за пять минут
при коллекции 845008). Ускорение обязательно и для обычных ZIP/FB2, не только 7z.

Индексатор использует лёгкий DAO-итератор, группировку по архиву, один открытый
ZIP и поток MSXML6 SAX до конца description. Для 7z пакет ограничен 64 MiB
и будущими книгами текущего блока, с одиночным fallback и отменой процесса.
Временная распаковка только в собственный уникальный каталог; удаление только
отслеживаемых файлов. Открытие/экспорт обычных книг остаётся с полным чтением
и проверкой CRC. Восстановление картинок FLibrary при индексации не нужно.

`PublisherSeries_Index` хранит ключ успешного чтения источника (путь, размер,
точное время, запись книги, версия алгоритма). Серии и ключ атомарны; ошибки
не стирают старые связи, пустой корректный результат кэшируется. Удаление,
пересоздание и обычное редактирование метаданных инвалидируют ключи.
Отмена сохраняет завершённые книги, следующий проход пропускает их. Флажок
«Полная проверка» заставляет перечитать всё. Первый проход после 1068 снова
читает книги, поскольку старый EXE отметки проверки не хранил.
Обычный INPX не содержит издательских серий: первичная обработка не может
стать простым открытием вкладки. Автосканирования при запуске нет.
