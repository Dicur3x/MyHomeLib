Текущий выпуск: **HomeLib Ru 2.7.0_pre5.02**, EXE **2.7.0.1069**.
Предыдущий опубликованный `2.7.0_pre5.01` (1068) включил upstream `1bbae78`
через merge `400df2f`; документация после публикации: `3663ec6`.
В 1069 дополнительных переносов upstream нет: исправляется медленное
заполнение издательских серий по замечанию владельца (4500 книг за пять минут
при коллекции 845008). Ускорение обязательно и для обычных ZIP/FB2, не только 7z.

Индексатор использует лёгкий DAO-итератор, группировку по архиву, один открытый
ZIP и поток MSXML6 SAX до конца description. Для 7z пакет ограничен 64 MiB
и будущими книгами текущего блока, с одиночным fallback и отменой процесса.
Временная распаковка только в собственный уникальный каталог; удаление только
отслеживаемых файлов. Открытие/экспорт обычных книг остаётся с полным чтением
и проверкой CRC. Восстановление картинок FLibrary при индексации не нужно.

`PublisherSeries_Index` хранит ключ успешного чтения источника (путь, размер,
точное время, запись книги, версия алгоритма). Серии и ключ атомарны; ошибки
не стирают старые связи, пустой корректный результат кэшируется. Удаление,
пересоздание и обычное редактирование метаданных инвалидируют ключи.
Отмена сохраняет завершённые книги, следующий проход пропускает их. Флажок
«Полная проверка» заставляет перечитать всё. Первый проход после 1068 снова
читает книги, поскольку старый EXE отметки проверки не хранил.
Обычный INPX не содержит издательских серий: первичная обработка не может
стать простым открытием вкладки. Автосканирования при запуске нет.

Delphi 13.2 Trial `37.0.60952.8797` активирована, сборка только через IDE.
Проекты открывать через junction `C:\Users\cloud\HomeLibRu-build` на активное
дерево: BRCC32 из пути с `.codex` молча создаёт пустые RES. Обновляй SQL
ресурсы `Program/MyhomeLib.dres` и `MHLMcpServer_SQL.res`, а также явный
`HomeLibRuManifest.res` через этот короткий путь. `Manifest_File=None`
исключает дублирующий манифест IDE, основной манифест явно подключён в DPR.
После изменения открытого в IDE исходника перечитай его с диска перед Build.

1069 Win32/Win64: основные EXE собраны без ошибок/предупреждений (106 hints),
MCP также (15 hints). Проверены версия, бренд, авторство, CC6/PerMonitorV2.
На каждой архитектуре прошли SAX291, fixture22, protocol48, extract10,
cache43, publisher-source12. Fixture включает cancel108/resume12/cached120,
force120, ошибки/повтор, изменение размера/mtime, миграцию/rollback/recreate.
ZIP1000: x64 5,89 → 0,72 с, x86 6,13 → 0,62 с. Реальный 7z40 x64:
6,57 → 1,55 с. Кэш Windows не очищался, обе реализации с текущим DAO.
Не выдавай эти числа за прогноз для всей библиотеки: 845008 книг не измерялись.
Восстановление реальных FB2/EPUB пройдено обеими архитектурами. GUI проверен
из ZIP на отдельном mcpfixture: заполнение, повторный кэш, принудительный
проход x64, серия и номер17/ссылки в Win32. Личные базы не использовались.
