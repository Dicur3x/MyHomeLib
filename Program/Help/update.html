Обновление коллекции

Обновление — это подтягивание свежих поступлений из источника сетевой библиотеки в уже подключенную коллекцию; это не то же самое, что синхронизация папок и файлов, которая лишь сверяет то, что уже есть в каталоге, с тем, что физически лежит на диске или загружено.

Два способа обновить коллекцию

Обновить коллекцию можно либо из сети, либо из файла, который у вас есть на диске.

Обновление из сети

Касается только коллекций, подключённых из источников, перечисленных в файле collections.ini (см. Установка), — то есть известных сетевых библиотек вроде lib.rus.ec или Флибусты; произвольные пользовательские коллекции так не обновляются. Запустить проверку и загрузку обновлений можно командой «Обновить коллекции» в меню «Инструменты» (см. Меню «Инструменты»); также программа может самостоятельно проверять наличие обновлений во время работы, если это разрешено в настройках, и предложить их загрузить.

Обновление из файла

Команда «Обновить коллекцию из файла…» в меню «Коллекция» (см. Меню «Коллекция») обновляет активную коллекцию из списка книг, который вы выбираете сами. В отличие от обновления из сети, этот способ работает с любой коллекцией — в частности с собственной, которой нет в collections.ini.

Подходит файл списка книг в формате INPX. Такие файлы часто имеют расширение .zip вместо .inpx (например, update.zip) — оба варианта принимаются, так как это один и тот же формат.

В окне выбора укажите файл кнопкой «Обзор…» и, при необходимости, включите «Полный переимпорт (очистить коллекцию)». Галочка по умолчанию отключена, то есть обычное обновление добавляет записи в существующий каталог.

Выбранный вами файл программа не изменяет и не удаляет — после обновления он остаётся на диске. Свойства самой коллекции (адрес, скрипт подключения, примечания) при обновлении из файла также не изменяются, даже если файл содержит свои значения для них.

Что меняется в коллекции

Обновление бывает двух видов. Для обновления из сети вид определяет сам источник, для обновления из файла — отметка «Полный переимпорт»:

  • Частичное (инкрементное) — новые и изменённые записи из файла обновления добавляются в существующий каталог коллекции, остальные записи каталога не затрагиваются.
  • Полное — каталог коллекции (книги, авторы, серии, жанры) сначала полностью очищается, а затем заполняется заново из файла обновления.

Если прервать обновление кнопкой «Отменить», все изменения отменяются — коллекция остаётся такой, какой была до начала. Если выбранный файл окажется не списком книг, программа сообщит об этом и не будет изменять коллекцию.

Что происходит с данными пользователя

Перед полным обновлением программа отдельно сохраняет рейтинги, прогресс чтения, рецензии и принадлежность книг к группам (в частности «Избранное» и «К прочтению»), а после повторного наполнения каталога восстанавливает их, сопоставляя книги по стабильному идентификатору (LibID), а не по внутреннему номеру, который при полном обновлении присваивается заново. Данные книг, которых в обновлённом каталоге больше нет, при этом теряются вместе с самими записями об этих книгах. При частичном обновлении этот шаг вообще не требуется: существующие записи каталога не удаляются, поэтому привязанные к ним данные пользователя остаются на месте без отдельного сохранения и восстановления.

Эти внутренние данные пользователя не следует путать с перечнем коллекций в системной базе — обновление коллекции на него не влияет.
