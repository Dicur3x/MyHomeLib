Свойства коллекции

Команда «Коллекция» → «Свойства коллекции» открывает окно «Свойства коллекции» с полями активной коллекции. Окно предупреждает: «Внимание! Некорректное изменение свойств коллекции может привести к ее непригодности!» — и это следует воспринимать всерьез, так как, в частности, папка с книгами и файл коллекции изменяются здесь без проверки самих файлов на диске.

Вкладка «Основные»

ПолеЧто означает
Название коллекцииИмя, под которым коллекция отображается в списках и меню. Редактируется; должно оставаться уникальным среди подключенных коллекций.
Файл коллекцииПуть к файлу базы .hlc2. Только для чтения — это поле показывает, куда указывает регистрация коллекции, но окно не позволяет его изменить.
Папка с книгамиПапка, в которой находятся файлы книг коллекции. Редактируется (кнопка «Выбрать»); изменение лишь перемещает указатель — файлы книг при этом никуда не перемещаются.
Описание коллекцииПроизвольное текстовое описание, которое показывает окно «Статистика» (см. Работа с коллекциями). Редактируется.

Вкладка «Подключение» (только для сетевых коллекций)

Эта вкладка отображается только для активной сетевой коллекции (см. Типы коллекций); для локальной коллекции она вообще не показывается.

ПолеЧто означает
URLАдрес сервера библиотеки. Редактируется.
Пользователь / ПарольУчётные данные для входа на сервер библиотеки. Редактируются.
Сценарий подключенияТекст скрипта, которым MyHomeLib пользуется для входа, поиска и загрузки книг из этой сетевой коллекции. Это свойство самой коллекции — не путать со скриптами, которые запускаются после отправки книг на устройство и настраиваются отдельно. Редактируется.

Что нельзя изменить

Кроме файла коллекции, в этом окне нет полей для типа коллекции (см. Типы коллекций) и формата файлов (FB2 или не-FB2) — они фиксируются навсегда в момент создания коллекции мастером и после этого нигде в программе не редактируются.

Сохранение

Кнопка «Сохранить» проверяет, что название и файл коллекции заполнены и не совпадают с уже зарегистрированными у другой коллекции, и что указанный файл коллекции существует на диске, — и только после этого записывает новые значения свойств.
