Основные термины

Эта страница объясняет термины, которые последовательно используются во всей справке MyHomeLib.

Коллекция
Отдельная база данных книг (файл .hlc2) — собственная библиотека пользователя или подключенная внешняя библиотека. Одновременно можно держать несколько коллекций и переключаться между ними; подробнее — в разделе Работа с коллекциями.
Тип коллекции: локальная и сетевая
Внутреннее разделение коллекций по способу хранения книг, а не по названиям, которые видны на экране. Локальная коллекция хранит файлы книг на диске пользователя. Сетевая (онлайн) коллекция обращается за книгами к серверу библиотеки (например, Флибуста) и загружает их только по мере необходимости. Оба варианта создаются мастером создания коллекции; см. Типы коллекций и Создание коллекции.
INPX
Формат файла-каталога, которым обмениваются библиотеки на движке Либрусек: архив с описаниями книг без самих файлов. С INPX можно создать новую коллекцию или обновить существующую, а свою коллекцию — экспортировать обратно в INPX; см. Создание коллекции и Экспорт коллекции в формате INPX.
FB2, FB2.ZIP, FBD, не-FB2
FB2 — основной формат книг, с которым работает MyHomeLib; FB2.ZIP — тот же файл, сжатый в ZIP-архив. Книгу в любом другом формате (PDF, DjVu, EPUB, TXT и т.д.) программа сохраняет как не-FB2; для такой книги можно создать небольшой файл-описание — FBD, который упаковывается вместе с самим файлом в один архив, чтобы книга имела автора, название и жанр так же, как FB2. См. Импорт книг в формате FB2 и Импорт книг не-FB2 и FBD.
Группа
Произвольная именованная метка, с помощью которой можно отметить любые книги в коллекции, чтобы затем быстро найти их вместе — независимо от автора или серии. Группами управляют на вкладке «Группы»; см. Группы и избранное.
Избранное
Одна из двух групп, которые в MyHomeLib существуют по умолчанию и которые нельзя удалить, — наряду с группой «К прочтению». Группа «Избранное» предназначена для книг, которые нужно отложить для быстрого доступа. Технически это та же самая механика групп, что и для обычных групп; подробнее — в разделе Группы и избранное.
Жанр
Отметка книги по теме или направлению из стандартного списка жанров (отдельного для FB2 и не-FB2 книг). Жанры организованы в виде дерева и отображаются на вкладке просмотра по жанрам; см. Списки жанров и Просмотр коллекции: авторы, серии, жанры.
Серия
Группа книг одного автора или цикла, объединённых общим названием и порядковым номером внутри неё. Серии показываются на отдельной вкладке просмотра; см. Просмотр коллекции: авторы, серии, жанры.
Устройство
Папка или подключённое устройство, куда MyHomeLib копирует или конвертирует книги для чтения вне программы, — например, электронная книга или смартфон. Устройства с нужными форматами настраиваются заранее; см. Устройства и экспорт и Отправка книг на устройство.
Читалка
Внешняя программа, которую MyHomeLib запускает для просмотра книги определённого формата (по расширению файла). Если для расширения программа для чтения не назначена, используется программа, зарегистрированная в системе по умолчанию. Настраивается в разделе Типы файлов и программы для чтения.
Скрипт
Внешняя программа или пакетный файл, который MyHomeLib по желанию запускает сразу после отправки книг на устройство, подставляя в параметры её запуска путь к только что отправленным файлам. Не путать со сценарием подключения сетевой коллекции (отдельное свойство самой коллекции — см. Свойства коллекции); зарегистрированные скрипты настраиваются в разделе Скрипты, примеры — в разделе Примеры скриптов.
Системная база
Файл user.dbs2 — общая для всех коллекций база, в которой MyHomeLib хранит список и свойства подключенных коллекций, группы (в частности «Избранное»), а также назначенные пользователем рейтинги, прогресс чтения и заметки к книгам. Где именно находится этот файл — см. Часто задаваемые вопросы.
