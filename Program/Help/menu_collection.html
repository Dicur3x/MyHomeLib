Меню «Коллекция»

Меню «Коллекция» объединяет управление подключенными коллекциями, импорт и экспорт книг и данных пользователя, а также обслуживание базы данных активной коллекции.

КомандаЧто делает
Создать новую коллекцию Ctrl+NЗапускает мастер создания новой коллекции. См. Создание коллекции.
Выбрать коллекциюПодменю со списком других подключенных коллекций — выбор коллекции делает её активной.
Свойства коллекцииОткрывает свойства активной коллекции. См. Свойства коллекции.
СтатистикаПоказывает окно со статистикой активной коллекции.
Обновить коллекцию из файла…Обновляет активную коллекцию из списка книг в формате INPX, выбранного на диске, — частично или с полным повторным импортом. См. Обновление коллекции.

Подменю «Импорт»

КомандаЧто делает
Файлы fb2 и fb2.zipИмпортирует книги в формате FB2 или FB2.ZIP в активную коллекцию. См. Импорт книг в формате FB2.
Файлы не-fb2Импортирует книги в других форматах (PDF, DjVu, EPUB и т.д.). См. Импорт книг не-FB2 и FBD.
Файлы FBD (pdf.zip djvu.zip)Импортирует уже готовые файлы-описания FBD вместе с файлами книг.
Данные пользователяИмпортирует ранее экспортированный файл данных пользователя (рейтинги, группы, прогресс чтения). См. Экспорт и импорт данных пользователя.

Подменю «Экспорт»

КомандаЧто делает
Экспорт активного списка (подменю: html, txt, RTF)Экспортирует список книг, показанный сейчас в окне, в файл выбранного формата. См. Экспорт списка книг.
Экспортировать в inpxЭкспортирует всю активную коллекцию в файл-каталог формата INPX. См. Экспорт коллекции в формат INPX.
Данные пользователяЭкспортирует рейтинги, группы и прогресс чтения активной коллекции в файл. См. Экспорт и импорт данных пользователя.

Подменю «Обслуживание»

КомандаЧто делает
Обновить список жанровПеречитывает список жанров коллекции из файла списка жанров. См. Списки жанров.
Синхронизировать файлыДля сетевой коллекции — синхронизирует состояние загруженных файлов с сервером; для локальной — синхронизирует содержимое папок и файлов коллекции. См. Синхронизация папок и файлов.
Проверить базуПроверяет целостность базы данных коллекции средствами SQLite и сообщает, что ошибок не найдено, или показывает перечень проблем. Ничего не изменяет и не исправляет. См. Обслуживание базы данных.
СжатьСжимает (уплотняет) файл базы данных коллекции. См. Обслуживание базы данных.

Удаление коллекции

КомандаЧто делает
УдалитьОтключает активную коллекцию от программы, с возможностью также удалить файл базы данных коллекции. См. Удаление коллекции.
