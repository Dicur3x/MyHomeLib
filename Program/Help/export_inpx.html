Экспорт коллекции в формат INPX

Команда «Коллекция» → «Экспорт» → «Экспортировать в inpx» сохраняет весь каталог активной коллекции в файл-архив формата INPX (см. Основные термины) — тот же формат, из которого создают новую коллекцию и которым обновляют существующую.

Что попадает в файл

Для каждой книги коллекции в архив записывается одна строка библиографического описания: авторы, жанры (кодами — FB2 или внутренними, в зависимости от того, FB2-коллекция это или нет), название, серия и номер в ней, имя файла, размер, стабильный идентификатор книги (LibID), отметка удаления, расширение, дата, язык и ключевые слова. Кроме этого, в архив добавляются файл версии данных, описание структуры полей и служебная запись с названием, файлом, типом, описанием, адресом и скриптом подключения самой коллекции.

Личные данные пользователя — рейтинги, прогресс чтения, рецензии, аннотации, принадлежность к группам — в файл INPX не попадают. Для их экспорта предназначена отдельная команда, см. Экспорт и импорт данных пользователя.

Чего в файле нет

Файл INPX — это лишь каталог, без самих файлов книг: размер экспортированного архива не зависит от того, сколько весят книги коллекции.

Для чего это нужно

Экспортированный файл INPX можно передать другому пользователю MyHomeLib как готовый каталог для создания новой коллекции, использовать как источник данных для обновления похожей коллекции или сохранить как текстовый снимок каталога коллекции на определённый момент времени — независимо от самой базы .hlc2.
