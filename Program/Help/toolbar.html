Панель инструментов

В MyHomeLib две панели инструментов — основная и панель редактирования. Обе можно скрыть или показать через Меню «Вид» → «Панели».

Основная панель инструментов

КнопкаДействиеЭквивалент в меню
ЧитатьОткрывает выделенную книгу для чтения.Книга → Читать (Enter)
Добавить в список загрузокПомещает выделенные (отмеченные) книги в очередь на загрузку из сетевой коллекции.Книга → Добавить в список загрузок (Ctrl+L)
Кнопка с подсказкой «Отправить на устройство»Копирует выделенные книги на устройство по умолчанию; стрелка раскрывает список настроенных скриптов для выбора другого.Книга → Отправить на устройство
Кириллический алфавитПоказывает или скрывает строку кириллических букв над деревом на вкладках «Авторы» и «Серии».Вид → Панели → Кириллический алфавит
Латинский алфавитТо же самое для латинского алфавита.Вид → Панели → Латинский алфавит
Кнопка с подсказкой «Выбрать коллекцию»Раскрывает список подключенных коллекций для переключения и пункт создания новой коллекции.Коллекция → Выбрать коллекцию / Создать новую коллекцию
Добавить в избранноеДобавляет выделенные книги в группу «Избранное»; стрелка раскрывает список других групп для выбора.Книга → Добавить в избранное (Ctrl+F в списке книг)
Кнопка с подсказкой «Отметить все»Включает или отключает отметки (флажки) во всех строках активного списка книг.Контекстное меню списка книг → Отметить все / Снять отметки
Кнопка с подсказкой «Развернуть/Свернуть список»Полностью разворачивает или сворачивает активное дерево книг.—
Кнопка с подсказкой «Переключить в режим 'Таблица'»Переключает активный список книг между режимом дерева (с группировкой) и плоской таблицей.Вид → Режим просмотра
Скрыть удаленные книгиСкрывает в списке книги, отмеченные как удаленные.Вид → Скрыть удаленные книги
Показывать только загруженные книгиОставляет в списке только книги, файлы которых уже есть на диске.Вид → Показывать только загруженные книги
Панель информации о книгеПоказывает или скрывает правую панель с обложкой, аннотацией и описанием книги.Вид → Панель информации о книге
НастройкиОткрывает окно настроек программы.Инструменты → Настройки
Кнопка с подсказкой «Справка»Открывает эту справку.Помощь → Справка

Панель редактирования

Эта панель показывает текстовые кнопки редактирования для книги, выделенной в списке.

КнопкаДействиеЭквивалент в меню
АвторОткрывает редактирование данных автора выделенной книги.Редактирование → Автор
Название серииОткрывает редактирование названия серии.Редактирование → Название серии
Название жанраОткрывает редактирование названия (псевдонима) жанра.Редактирование → Название жанра
Информация о книгеОткрывает полное редактирование описания книги.Редактирование → Информация о книге
УдалитьУдаляет выделенную книгу.Книга → Удалить
Преобразовать в FBDПреобразует описание не-FB2 книги в файл FBD.Редактирование → Преобразовать в FBD
Автоматически преобразовать в FBDВ текущей сборке кнопка не имеет обработчика — щелчок по ней не выполняет никаких действий.Редактирование → Автоматически преобразовать в FBD
