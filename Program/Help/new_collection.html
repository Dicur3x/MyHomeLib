Создание коллекции

Команда «Коллекция» → «Создать новую коллекцию» (Ctrl+N) запускает мастер, который и создает новую пустую коллекцию, и подключает существующую, и строит коллекцию из файла INPX. Набор шагов, которые покажет мастер, зависит от выбора, сделанного на втором шаге — ниже шаги приведены в том порядке, в котором они фактически идут друг за другом; шаги, обозначенные как условные, появляются только для определенного выбора.

Шаг 1. Приветствие

Первая страница мастера создания коллекции MyHomeLib содержит только пояснительный текст; полей для заполнения здесь нет.

Шаг 2. Тип коллекции

Здесь выбирают, что именно будет делать мастер:

  • Новая пустая коллекция — создать пустую коллекцию, которую потом наполняют импортом книг;
  • Существующая коллекция (hlc2) — подключить уже имеющийся файл коллекции;
  • Коллекция из файла inpx — создать и сразу заполнить коллекцию из файла-каталога INPX (см. Основные термины).

Шаг 3. Источник INPX (только для «Коллекция из файла inpx»)

Показывается только если на предыдущем шаге выбрано «Коллекция из файла inpx». Здесь указывают, откуда взять файл INPX:

  • Локальный файл INPX — файл, который уже есть на диске пользователя (кнопка «Выбрать» открывает диалог выбора файла);
  • Загрузить с сайта — список готовых коллекций (lib.rus.ec, Флибуста и т. д.), источники для которого берутся из файла collections.ini (см. Установка); файл INPX будет загружен с сервера. Этот вариант доступен, только если список не пуст.

Тип будущей коллекции (собственная или внешняя, локальная или сетевая, FB2 или не-FB2) определится позже — из данных, сохранённых внутри самого файла INPX; см. Типы коллекций.

Шаг 4. Загрузка файла INPX (только при выборе «Загрузить с сайта»)

Показывает ход загрузки выбранного файла INPX с сервера: скорость и объем загруженного. Шага нет, если файл INPX берется с локального диска.

Шаг 5. Название коллекции

Общий шаг для всех вариантов: название коллекции, файл коллекции и папка с книгами.

  • Название коллекции — произвольное имя, под которым коллекция будет отображаться в списках и меню; должно быть уникальным среди подключенных коллекций;
  • Файл коллекции — путь к файлу .hlc2. Для новой коллекции и коллекции с INPX указывают, где создать файл (кнопка «Выбрать»); для подключения существующей коллекции — где найти уже существующий файл;
  • Папка с книгами — папка, где будут храниться (или уже хранятся) файлы книг этой коллекции.

Если коллекция создается из файла INPX, мастер сразу подставляет название и файл коллекции из данных, сохраненных в самом INPX, — это можно исправить вручную.

Шаг 6. Формат файлов (только для «Новая пустая коллекция»)

Показывается только если на шаге 2 выбрано «Новая пустая коллекция». Определяет содержимое будущей коллекции:

  • Книги в формате FictionBook — коллекция будет хранить книги FB2/FB2.ZIP, со стандартным деревом жанров FB2;
  • Книги в других форматах (fbd, pdf, djvu) — коллекция для книг не-FB2, со своим деревом жанров (следующий шаг позволит выбрать файл жанров).

Флажок «Начать импорт книг после создания коллекции» (по умолчанию включен, доступен только для FB2) сразу после создания коллекции открывает импорт книг — см. Импорт книг в формате FB2.

Шаг 7. Файл описания жанров (только для новой не-FB2-коллекции)

Показывается только при создании новой пустой коллекции с форматом «Книги в других форматах». Для новой FB2-коллекции, подключения существующей и создания из файла INPX жанры выбираются автоматически, и этот шаг не появляется.

  • По умолчанию — использовать файл описания жанров, который поставляется с программой;
  • Специальный файл жанров — указать свой файл (кнопка «Выбрать»).

Флажок «Запустить импорт после создания коллекции» здесь повторяет тот же выбор, что и на шаге формата файлов. О самих файлах жанров — см. Списки жанров.

Шаг 8. Порядок выполнения

Общий для всех вариантов шаг: здесь мастер фактически создаёт или подключает коллекцию в системной базе, а для вариантов с INPX — сразу после этого импортирует данные из файла INPX (с журналом событий и индикатором прогресса). На этом шаге доступна только кнопка «Отмена» — кнопок перехода на предыдущий или следующий шаг здесь нет; если регистрацию коллекции завершить не удалось, мастер остаётся на этой странице и предлагает сохранить журнал ошибок.

Шаг 9. Завершение

Итоговая страница: коллекция уже создана (или подключена), и после закрытия мастера ею сразу можно пользоваться.
