Создание коллекции

Команда «Коллекция» → «Создать новую коллекцию» (Ctrl+N) запускает мастер, который создаёт новую пустую коллекцию, подключает существующую либо строит коллекцию из каталога INPX или metabib. Набор шагов, которые покажет мастер, зависит от выбора, сделанного на втором шаге — ниже шаги приведены в том порядке, в котором они фактически идут друг за другом; шаги, обозначенные как условные, появляются только для определенного выбора.

Что выбрать на втором шаге
  • Свои файлы в папке — Новая пустая коллекция. Книги добавляются через импорт.
  • Есть индекс скачанной библиотеки — Коллекция из файла INPX. Укажите также папку с архивами.
  • Уже есть каталог HomeLibre — Существующая коллекция (hlc2). Укажите его файл.

Шаг 1. Приветствие

Первая страница мастера создания коллекции HomeLibre содержит только пояснительный текст; полей для заполнения здесь нет.

Шаг 2. Тип коллекции

Здесь выбирают, что именно будет делать мастер:

  • Новая пустая коллекция — создать пустую коллекцию, которую потом наполняют импортом книг;
  • Существующая коллекция (hlc2) — подключить уже имеющийся файл коллекции;
  • Коллекция из файла INPX — создать и сразу заполнить коллекцию из обычного файла-каталога INPX (см. Основные термины);
  • Коллекция из каталога metabib — импортировать новый потоковый формат каталогов .jsonl, .jsonl.zst, .jsonl.gz либо ZIP с файлом JSONL внутри.

Шаг 3. Источник INPX (только для «Коллекция из файла inpx»)

Показывается только если на предыдущем шаге выбрано «Коллекция из файла inpx». Здесь указывают, откуда взять файл INPX:

  • Локальный файл INPX — файл, который уже есть на диске пользователя (кнопка «Выбрать» открывает диалог выбора файла);
  • Загрузить с сайта — список готовых коллекций (lib.rus.ec, Флибуста и т. д.), источники для которого берутся из файла collections.ini (см. Установка); файл INPX будет загружен с сервера. Этот вариант доступен, только если список не пуст.

Тип будущей коллекции (собственная или внешняя, локальная или сетевая, FB2 или не-FB2) определится позже — из данных, сохранённых внутри самого файла INPX; см. Типы коллекций.

Шаг 3. Источник metabib (только для «Коллекция из каталога metabib»)

Выберите локальный файл каталога. Для распаковки .zst рядом с программой должна находиться штатная libzstd.dll. Metabib содержит полный снимок каталога, поэтому при последующем обновлении из такого файла выполняется полный переимпорт с сохранением пользовательских оценок, прогресса чтения и групп.

Шаг 4. Загрузка файла INPX (только при выборе «Загрузить с сайта»)

Показывает ход загрузки выбранного файла INPX с сервера: скорость и объем загруженного. Шага нет, если файл INPX берется с локального диска.

Шаг 5. Название коллекции

Общий шаг для всех вариантов: название коллекции, файл коллекции и папка с книгами.

  • Название коллекции — произвольное имя, под которым коллекция будет отображаться в списках и меню; должно быть уникальным среди подключенных коллекций;
  • Файл коллекции — путь к файлу .hlc2. Для новой коллекции и коллекции с INPX указывают, где создать файл (кнопка «Выбрать»); для подключения существующей коллекции — где найти уже существующий файл;
  • Папка с книгами — папка, где будут храниться (или уже хранятся) файлы книг этой коллекции.

Если коллекция создается из файла INPX, мастер сразу подставляет название и файл коллекции из данных, сохраненных в самом INPX, — это можно исправить вручную.

Шаг 6. Жанры и импорт из папки (для новой пустой коллекции)

На этом шаге выбирают набор жанров и способ пакетного импорта. В обоих вариантах можно добавлять отдельные FB2, EPUB, PDF и другие поддерживаемые книги. Сведения из EPUB подставляются, если они есть в файле.

  • Жанры FictionBook и пакетный импорт FB2 — стандартное дерево жанров FictionBook и импорт FB2 из папок и архивов.
  • Общие или собственные жанры — на следующем шаге можно выбрать поставляемый или собственный файл жанров.

В первом варианте флажок «Начать пакетный импорт FB2 после создания коллекции» открывает окно импорта сразу после создания каталога. Подробности см. в разделе Импорт книг в формате FB2.

Шаг 7. Файл описания жанров (для новой коллекции с общими или собственными жанрами)

Шаг открывается после выбора «Общие или собственные жанры». В остальных режимах мастер определяет жанры из выбранного типа или данных каталога.

  • По умолчанию — использовать файл описания жанров, который поставляется с программой;
  • Специальный файл жанров — указать свой файл (кнопка «Выбрать»).

О значениях и назначении жанровых файлов см. в разделе Списки жанров.

Шаг 8. Порядок выполнения

Общий для всех вариантов шаг: здесь мастер фактически создаёт или подключает коллекцию в системной базе, а для вариантов с INPX или metabib — сразу после этого импортирует данные из выбранного файла (с журналом событий и индикатором прогресса). На этом шаге доступна только кнопка «Отмена» — кнопок перехода на предыдущий или следующий шаг здесь нет; если регистрацию коллекции завершить не удалось, мастер остаётся на этой странице и предлагает сохранить журнал ошибок.

Шаг 9. Завершение

Итоговая страница: коллекция уже создана (или подключена), и после закрытия мастера ею сразу можно пользоваться.
