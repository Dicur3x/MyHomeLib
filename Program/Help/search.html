Поиск книг и фильтры

Вкладка «Поиск» — отдельный список книг, который наполняется не просмотром дерева авторов/серий/жанров, а произвольным набором условий. В отличие от деревьев просмотра, здесь можно одновременно искать по нескольким полям и сохранять набор условий для повторного использования.

Поля поиска

Панель слева собрана из трех сворачиваемых групп.

Книга
Автор, Название, Серия, Жанр (с кнопкой, которая открывает дерево жанров для выбора мышью), Ключевые слова, Аннотация.
Файл
Имя, Папка (архив), Тип — то есть расширение файла.
Разное
Дата добавления (готовые интервалы в выпадающем списке — «сегодня», «за 3 дня», «за неделю», «за 2 недели», «за месяц», «за 3 месяца»), Язык (двухбуквенный код), внешняя Оценка библиотеки (1–5), флажки «Скрывать удалённые» и «Только прочитанные».

Простой и расширенный поиск

Самый простой вариант — просто вписать текст в нужное поле: MyHomeLib ищет его как подстроку без учёта регистра в любом месте значения. Для более точного запроса то же поле понимает и прямой язык условий SQL-подобного вида:

  • %текст% — подстрока явно, с возможностью поставить % только с одной стороны;
  • ="точное значение" — точное соответствие;
  • <, >, <> — сравнение (удобно для даты или размера);
  • ="имя1" OR ="имя2" — несколько вариантов в одном поле; именно в таком виде в поле «Автор» подставляются несколько авторов, выбранных сразу через пункт «Добавить к "Поиску"» дерева авторов (см. Контекстные меню).

Кнопка справа от каждого поля открывает для него отдельное окно редактирования — удобнее для длинного или многострочного запроса, чем однострочное поле. В поле «Жанр» эта же кнопка вместо текстового редактора открывает дерево жанров: выбор там подставляет в поле список псевдонимов жанров вместо произвольного текста.

Клавиша Enter в любом поле сразу запускает поиск — так же, как кнопка «Применить».

Область поиска

Поиск выполняется только в пределах активной на данный момент коллекции. Чтобы найти книгу в другой подключенной коллекции, сначала переключитесь на неё (см. Работа с коллекциями), а затем повторите поиск.

Пресеты

Заполненный набор условий можно сохранить под любой выбранной кнопкой «Сохранить» и потом вызвать его снова, выбрав это имя из списка над панелью поиска. Кнопка «Удалить» убирает выбранный пресет из списка (её подсказка — «Удалить пресет»). Кнопка «Очистить» очищает все поля, не затрагивая выбор пресета. Пресеты сохраняются в отдельном файле в рабочей папке программы и общие для всех коллекций.

Эта страница заменяет справку о поиске из версии 2011 года и закрывает её мёртвую ссылку на несуществующую тему.
