Меню «Книга»

Меню «Книга» содержит действия над книгой (или книгами), выделенными в активном списке.

КомандаЧто делает
ЧитатьОткрывает выделенную книгу программой, настроенной для этого типа файлов (см. Типы файлов и программы для чтения), а если для типа файла ни одна не настроена — программой, которую для него определила Windows по умолчанию. Собственной встроенной читалки в MyHomeLib нет.
Отправить на устройствоКопирует (при необходимости конвертируя в формат, требуемый устройством) выделенные книги в настроенную папку устройства.
Добавить в список загрузок Ctrl+LПомещает книгу (для сетевой коллекции) в очередь на загрузку на вкладке «Список загрузок».
ПрочитаноПереключает прогресс чтения: если он равен 0%, устанавливает 100% (книга «прочитана»); в любом другом случае — обнуляет прогресс до 0%.
Рейтинг (подменю: *, * *, * * *, * * * *, * * * * *, Очистить)Ставит личную оценку книги от одной до пяти звезд или снимает её пунктом «Очистить».
Добавить в избранноеДобавляет книгу в группу «Избранное». Когда активная вкладка уже показывает «Избранное», этот пункт скрывается, а на его месте становится видимым отдельный пункт Удалить из группы (см. ниже).
Добавить в группуПодменю со списком имеющихся групп (кроме «Избранное») — выбор группы добавляет в неё выделенную книгу.
Удалить из группыУдаляет книгу из группы, которую сейчас просматривают (доступно только при просмотре содержимого группы или «Избранного»).
Копировать в коллекциюПодменю со списком подходящих локальных FB2-коллекций — выбор коллекции копирует в неё книгу.
УдалитьУдаляет книгу из активной коллекции.
ВыходЗакрывает программу.

Внимание: команда «Прочитано» не только отмечает не начатую книгу как прочитанную — для книги с любым ненулевым прогрессом (включая уже прочитанную на 100%) она обнуляет прогресс до 0%. На частично прочитанной книге повторное использование этой команды приводит к потере отметки прогресса чтения.
