Удаление коллекции

Команда «Коллекция» → «Удалить» всегда относится к активной коллекции — выбирать её отдельно не нужно. Команда открывает диалог с двумя вариантами, и именно выбор в этом диалоге определяет, насколько серьёзными будут последствия.

Два варианта — и разница между ними принципиальна

Отключить коллекцию
Удаляет коллекцию только из списка подключенных. Файл коллекции .hlc2 и файлы книг остаются на диске без изменений. Эту коллекцию можно подключить снова — командой «Создать новую коллекцию», выбрав на шаге «Тип коллекции» вариант «Существующая коллекция (hlc2)» и указав тот же файл.
Удалить коллекцию
Удаляет коллекцию из списка подключённых и дополнительно удаляет сам файл коллекции .hlc2 с диска. Это удаление файла необратимо — если резервной копии нет, каталог книг, авторов, серий и жанров этой коллекции восстановить невозможно. Группы хранятся отдельно, в системной базе.

Что не удаляется ни в одном из вариантов

Файлы самих книг в папке коллекции никогда не удаляются, независимо от выбранного варианта, — удаляется только файл каталога .hlc2. Если нужно освободить место, занятое книгами, папку с ними приходится удалять вручную — средствами проводника Windows, вне MyHomeLib.

Последствия для остальной программы

После удаления или отключения активной становится первая из оставшихся подключённых коллекций; если не осталось ни одной, активной коллекции не будет вообще, пока не подключат или не создадут новую — см. Работа с коллекциями.
