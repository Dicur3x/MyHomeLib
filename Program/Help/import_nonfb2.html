Импорт книг не-FB2 и FBD

Книга не в формате FB2 (PDF, DjVu, EPUB, TXT и т. д.) не содержит внутри ни автора, ни названия, ни жанра, которые программа могла бы прочитать сама, — в отличие от FB2. Чтобы такая книга полноценно отображалась в каталоге (с автором, названием, серией и жанром), для неё создают небольшое сопроводительное описание — файл FBD. Он упаковывается в один архив вместе с самим файлом книги, и с этого момента книга в коллекции ведёт себя как обычная запись. Пункты меню «Коллекция» → «Импорт» дают два разных способа это сделать — ручной и пакетный; это две отдельные команды с разными диалогами, а не два режима одного окна.

«Файлы не-fb2» — ручное добавление

Эта команда открывает отдельное окно, в котором необходимо вводить библиографические данные самостоятельно. Окно сканирует саму папку коллекции (а не отдельную папку импорта) и показывает деревом файлы, для расширения которых настроен ридер (см. Типы файлов и программы для чтения) и которые еще не занесены в каталог; файлы fb2 и fb2.zip в этот список не попадают — для них есть отдельный импорт.

Для выбранного файла вручную заполняют автора (кнопкой или через список имеющихся авторов коллекции), название, серию с номером, жанр (через дерево жанров), ключевые слова и язык; кнопки типа «Фамилия», «Имя», «Название», «Серия» позволяют подставить выделенный фрагмент имени файла в нужное поле одним кликом. Флажок «Конвертировать в FBD» включает создание FBD-архива для файла; без него файл заносится в каталог как есть, без обертки FBD. Кнопка «Сохранить» записывает книгу в каталог и переходит к следующему файлу из списка.

Группы полей в этом окне подписаны «Параметры» и «Обложка»; подсказки кнопок загрузки обложки — «Вставить из буфера» и «Загрузить из файла».

«Файлы FBD (pdf.zip djvu.zip)» — пакетный импорт

Эта команда предназначена для уже готовых архивов FBD (например, полученных от кого-то еще или заранее подготовленных) — тех самых .zip, которые содержат файл книги вместе с файлом описания .fbd. В отличие от «Файлов не-fb2», здесь ничего не вводят вручную: команда сканирует папку импорта, находит в каждом архиве описание FBD и сама считывает из него автора, название, жанр, серию — так же, как импорт FB2 считывает эти данные из fb2-файла. Ход импорта показывает то же окно прогресса с живым списком ошибок и кнопкой сохранения этого списка в файл, что и в импорте FB2 — отдельного автоматического файла журнала нет.

Дубликаты

В обоих случаях книга, для которой в каталоге уже есть запись с таким же именем файла в той же папке, повторно не добавляется.
