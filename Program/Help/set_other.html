Поведение

Раздел «Разное» диалога настроек (см. Настройки программы) собрал параметры поведения программы, которые не относятся ни к одному другому разделу.

Показывать книги из вложенных жанров (не-fb2)
Для коллекций не-FB2 книг: при просмотре вложенного родительского жанра показывать и книги, отмеченные его поджанрами, а не только самим этим жанром. Для FB2-коллекций не действует — там книги всегда показываются так. Самые верхние группы дерева жанров только раскрываются и не загружают книги всех своих поджанров независимо от этой настройки. По умолчанию включено.
Свернуть в трей
Нажатие кнопки сворачивания окна убирает MyHomeLib в трей вместо панели задач. По умолчанию выключено.
Запускать загрузку автоматически
Очередь загрузок (см. Загрузка книг) начинает загружать добавленные в нее книги сама, без отдельной команды «Начать загрузку». По умолчанию отключено.
Разрешить смешанные коллекции
Дает доступ к действиям, которые обычно показываются только для коллекций FB2 (в частности — отправка на устройство с конвертацией в другой формат), также и для коллекций книг не-FB2 формата. По умолчанию отключено.
Удалять «удаленные в библиотеке»
Относится только к сетевым коллекциям при синхронизации с библиотекой-источником: если книга, уже загруженная на диск, помечена библиотекой как удалённая, MyHomeLib удаляет её локальный файл вместе с этой пометкой (сама запись в каталоге остаётся — см. Удаление книг). По умолчанию выключено.
Автоматически загружать обзоры
Для книг сетевой коллекции — загружать рецензию вместе с самой книгой, без отдельного действия пользователя. Обычно включено.
Удалять файлы при удалении книг
Удалять ли файл книги с диска вместе с удалением её записи из каталога (см. Удаление книг, где подробно расписано, для каких именно книг это произойдет). По умолчанию отключено.
Перезаписывать заголовок fb2
Позволяет MyHomeLib переписывать в самом FB2-файле автора, название, жанр и серию значениями из каталога коллекции — при отправке на устройство и при открытии на чтение; подробно, для каких именно файлов и когда именно, — в разделах Редактирование описаний книг, Отправка книг на устройство и Чтение книг. По умолчанию выключено.

Поле «Шаблон заголовка книги:» ниже (кнопка «Изменить» рядом открывает тот же редактор шаблона, что и для устройства и сортировки файлов; стандартное значение — просто %t, то есть название книги без изменений) задаёт, что именно попадает в заголовок. Если этот флажок включён, а шаблон оставить пустым, при попытке сохранить настройки появится сообщение о необходимости задать шаблон, и окно не закроется.

Игнорировать отсутствующие архивы
Если при попытке открыть книгу (для чтения или отправки) архив с файлом на диске не найден или поврежден, по умолчанию (флажок включен) MyHomeLib не отображает отдельное сообщение с именем архива — действие для этой книги просто не выполняется. Если флажок выключен, вместо этого появляется сообщение об отсутствующем архиве.
Считать выделенные отмеченными
Позволяет считать отмеченными для некоторых групповых действий (в частности удаления, отправки на устройство и копирования между коллекциями) не только книги с установленным флажком, но и просто выделенные строки списка. По умолчанию параметр включён; если его отключить, для таких действий придётся отдельно устанавливать флажки у нужных книг. Пример поведения — в разделе Выделение и отметка книг.
