FAQ

Where are the settings and the system database stored?

In the ZIP edition, myhomelib2.ini is beside HomeLibre.exe. The system database is Data\user.dbs2 in the same folder. Older installations may have their profile in %APPDATA%\MyHomeLib. Portable profile files.

Why does a book not open?

  1. Use the book location command to check the folder or archive. For a local collection, you can find entries without files.
  2. If the file is there, try opening it in HomeLibre Reader. Some formats need an optional module.
  3. If you use an external reader, check its path and the format association in file type settings.

Why is a downloaded book missing?

A downloaded book goes into the very online collection it was downloaded from, not into some separate "downloads" folder — check that this is the collection you have open. If the download ended in an error, the details are written to the download_errors.log log next to the program settings. See Downloading books.

What happens if the collection file disappears from disk?

HomeLibre keeps the path to the collection file and its other properties in the system database, not in the collection file itself. So when a .hlc2 file has been moved, renamed or deleted outside the program, the collection does not vanish from the list you switch collections with (Collection → Select collection) — that list is built without checking whether the file exists. You will not be able to open that particular collection, though, until the file is put back where it was or the collection is connected again with the new path; see Working with collections. The message "Collection file not found. The program cannot start." appears only once — at startup, and only when the files of every single registered collection are unavailable at the same time; if even one of them still has its file, HomeLibre simply opens that one instead of the collection that went missing.

How do I move a collection to another drive?

Open Collection → Gather files into one folder…, choose the new drive and select Check plan. Before moving files, HomeLibre shows the space required, unavailable files and shared archives. Moving collection files.

How do I move my whole library to a new computer?

Close HomeLibre. Copy the application folder and its profile, then copy any books and .hlc2 files stored elsewhere. If drive letters or paths changed, open the new copy and check the collection paths. Moving the application · Moving personal data.
