Sending books to a device

Save as… in the Book menu and the book-list context menu saves one or more selected books to a folder. The shortcut is Ctrl+D. Choose a local folder, a cloud-sync folder or a folder on a connected reader.

Book format

Keep each book's original format or convert to FB2, FB2.ZIP, EPUB, TXT, MOBI or AZW3. For one book the original-format option names its format. The list does not repeat a conversion to the same format. Mixed selections offer rules to keep every original, convert to the chosen format, or keep existing FB2/EPUB books and convert the others.

FB2.ZIP contains an FB2 file in a ZIP archive. EPUB is already an archive and is not wrapped in another ZIP. Creating a standard FB2.ZIP does not require 7-Zip. You can keep PDF, DjVu and DOC in their original formats. Enable More formats to see which of EPUB 2, EPUB 3, KEPUB, KFX, AZW8, PDF and Markdown are available for the selected books. Exporting EPUB to PDF uses Microsoft WebView2 Runtime.

Images and size

Image options include As is, Balanced, Economy, Maximum savings and No images. Availability depends on the book and output format. Grayscale removes colour from illustrations and scans in the copy and can reduce file size. Estimate size uses the checkbox setting. Run the estimate again after changing it. Image changes while keeping the original format are supported for FB2 and EPUB; other original formats are copied unchanged. Scanned pages remain images rather than OCR text. Spread options keep scans intact, split them automatically or split at the centre.

A known original-copy size appears immediately. Estimate size prepares selected books with progress and cancellation. The list shows each result or its failure reason, with totals for every image mode above it. Unknown sizes are not counted as zero. The 20 MB mark is a hint for large results, not a format limit.

Names and folders

The last destination, default format and name templates are shared with Devices and export settings. Expand Names and folders to edit the filename template; Save as immediately previews the result including its extension. For example, [%n - ]%t adds a series number only when present. Disable subfolders to save everything in one folder; its template remains stored. For existing names choose to ask, keep both or replace the existing file.

Components and results

An unchanged copy needs no conversion module. If preparation, conversion or image processing needs optional components, HomeLibre offers the required downloads and their sizes, then restores the operation after installation. MOBI/AZW3 writing uses a separate Kindle module, absent from the minimal package.

Books in compressed collections may need reconstruction of their standard file and images. The resulting FB2 size can therefore differ from its catalogue entry. Saving does not change books in the collection.

The result reports saved books and individual failures. Details are appended to export_errors.log in the program's working folder; the result message shows its path. An external script is started through its own menu command.
