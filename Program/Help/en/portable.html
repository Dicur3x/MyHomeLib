Portable version

Starting the portable application

Extract the ZIP into a writable folder and run HomeLibRu.exe. The application is portable by default; no uselocaldata marker is required. Settings stay beside the application; the system database is Data\user.dbs2. Do not move profile files while the program is running.

Distribution files

The root contains HomeLibRu.exe, the updater HomeLibRuUpdater.exe, the catalogue library sqlite3.dll, and LICENSE and NOTICE. Icons contains interface icons; Help contains help and the local release history CHANGES.txt.

Genre lists genres_*.glst live in tools\genres, with separate FB2 and other-format lists and translations. tools\updates\COMPONENTS.json supplies initial component details and update history; it does not install components. Legacy files in the root are also supported.

HomeLibRu.update.json stays at the ZIP root so older versions can verify the release, architecture and file hashes. The updater does not install this transport manifest as an application file; manual extraction leaves it beside the EXE. Editing it is not a repair for an update error.

The minimal catalogue excludes the Reader, fonts and optional format modules. The program offers the relevant component when needed. Copy the complete application folder to retain installed components and user data.

Temporary files and moving the folder

Temporary files normally use the Windows temporary folder. An empty uselocaltemp file beside the EXE, or the same launch argument, selects the local $tmp folder. uselocaldata is not required and does not control temporary files.

Book, download and device paths may be absolute. Check them after a drive-letter change. Extracting the archive does not create Windows shortcuts or an uninstall entry.
