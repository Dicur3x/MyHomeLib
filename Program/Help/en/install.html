Installation

System requirements

HomeLib Ru is a Windows application, available as a 32-bit (x86) and a 64-bit (x64) build; choose the installer that matches the architecture of your copy of Windows. The installer itself runs with administrator rights. Everything the program needs in order to work — the SQLite library (sqlite3.dll), the bundled AlReader reader and the genre lists — is placed next to the program by the installer, so there is nothing to install separately.

x86 or x64

This fork publishes HomeLibRu.zip (x86) and HomeLibRu_x64.zip (x64) on its releases page. Extract the entire archive into a clean folder and run HomeLibRu.exe. x64 requires 64-bit Windows; x86 also supports 32-bit Windows. Read upgrading before moving an existing profile.

Optional installers can be built from source as Setup_HomeLibRu_<version>.exe and Setup_HomeLibRu_<version>_x64.exe. The sections below describe those installers, not ZIP extraction.

What the installer writes to the program folder, and what to %APPDATA%\MyHomeLib

By default the program is installed into the standard Program Files folder — Program Files\MyHomeLib for the x64 version, or Program Files (x86)\MyHomeLib for the x86 version on 64-bit Windows. There the installer puts the executable HomeLibRu.exe, the sqlite3.dll library, the bundled AlReader reader, the format converters (where a particular build includes them), the genre lists, the help file, the license text and a shortcut to the project website.

Separately, the installer creates the %APPDATA%\MyHomeLib folder (writable by any Windows user) and puts a single file there — collections.ini, the list of sources for updating online libraries — and only when no such file is there yet. Everything else in that folder — the settings, the system database (Data\user.dbs2, see Key terms) and the working logs — is created by the program itself on its first and later runs, not by the installer; there is more about this in FAQ.

Start menu shortcuts

The installer creates a program group with a shortcut that starts HomeLib Ru, a shortcut that opens the help file (the installer writes its caption, HomeLib Ru Help, in Ukrainian whichever wizard language you choose), a HomeLib Ru website link to the project home page, and an entry that uninstalls the program. Tick the corresponding checkbox during installation and a desktop shortcut is created as well. The setup wizard also lets you skip creating a Start menu folder altogether.

Uninstalling

You can remove HomeLib Ru either through the uninstall shortcut in the Start menu program group or through the standard Windows list of installed programs — both run the same uninstaller.

The new uninstaller preserves %APPDATA%\MyHomeLib and its Data folder. Collections, groups and personal settings are not automatically deleted. Back up before uninstalling an older release: its old uninstaller may remove the profile.

The collections themselves — the book files and the .hlc2 database file — are touched by neither the installer nor the uninstaller: they stay where you put them when you created or connected the collection (see Collection properties), so uninstalling the program does not affect them.
