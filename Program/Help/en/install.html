Installation

HomeLibre runs on Windows 10 and later. Download a ZIP from the releases page and extract the entire archive to a folder you can write to.

Which ZIP to download

PackageWindows x64Windows x86
CompactHomeLibre_x64_portable.zipHomeLibre_portable.zip
FullHomeLibre_x64_full.zipHomeLibre_full.zip

The compact package downloads Reader and other optional modules when needed. The full package includes them, along with the WebView2 and .NET Framework installers for offline use. Both packages are portable.

HomeLibre releases and checksums

First launch

  1. Run HomeLibre.exe from the extracted folder.
  2. Open Collection → Create new collection.
  3. Choose your own books folder, an INPX index, or an existing .hlc2 catalogue.

Where your data goes

Settings and the system database are stored beside the application. Books and collection files can stay in other folders. Move the application and its profile · Upgrade from an earlier version.
