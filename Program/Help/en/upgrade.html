Upgrading a previous version

Application updates and updates to your book catalogue are separate actions. To use a new INPX, see updating a library.

Update HomeLibre

  1. Open Help → Check for updates.
  2. Select HomeLibre and choose Download update.
  3. Choose Install and restart. HomeLibre closes, checks and replaces the application files, then restarts with your profile.

If you are using beta 13, update to beta 14 first. Then check for updates again.

Update manually

Close the application and back up its profile and any separately stored .hlc2 catalogues. The current ZIP uses a profile beside the EXE. An older installation may store it in %APPDATA%\MyHomeLib.

Download the ZIP for the same architecture. Extract it to a separate folder and copy the settings file (HomeLibre.ini or myhomelib2.ini), Data and presets.cxml2, if present, from your old profile. Run HomeLibre.exe and check that your collections and books open from the expected paths. Portable profile details.

On its first launch, beta 16 migrates myhomelib2.ini to HomeLibre.ini and saves a rollback copy as HomeLibre.ini.rollback.bak. When restoring an older version, copy that backup to its profile as myhomelib2.ini.

Modules and release notes

Choose Check all and select a component. The Changelog tab shows its history. Use Modules… to manage installed extras.

If a check fails, select the component and retry. If an application file is in use, close HomeLibre Reader and other programs using the folder, then try again.

Use A−, A+ or Ctrl + mouse wheel to change the text size. Enter and Space expand a selected release.
