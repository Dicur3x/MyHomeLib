Списки жанров

Дерево жанров, по которому книги размещены на вкладке просмотра (см. Просмотр коллекции: авторы, серии, жанры) и которое предлагается при редактировании описания книги, берется не из самой коллекции, а из отдельного файла списка жанров.

Два списка: FB2 и не-FB2

Программа поставляется с двумя готовыми списками жанров, которые устанавливаются рядом с исполняемым файлом (см. Установка):

  • genres_fb2.glst — стандартное дерево жанров FictionBook, для FB2-коллекций;
  • genres_nonfb2.glst — отдельное дерево для коллекций произвольных форматов (не-FB2).

Какой из них получает новая коллекция — и можно ли заменить его своим — решается при создании коллекции в мастере, на шаге «Файл описания жанров» (см. Создание коллекции): для FB2-коллекций всегда берется стандартный файл жанров FB2, а для коллекций произвольного формата можно либо оставить стандартный файл не-FB2, либо указать свой файл с расширением .glst. Рядом со стандартными списками устанавливаются их переведенные копии — с кодом языка в имени файла, — и программа берет ту из них, которая соответствует языку интерфейса, если такая копия есть.

Обновление списка жанров коллекции

Команда «Коллекция» → «Обслуживание» → «Обновить список жанров» перечитывает файл жанров заново для активной коллекции. Для FB2-коллекции это всегда стандартный файл genres_fb2.glst, без вопросов. Для коллекции произвольного формата команда каждый раз открывает диалог выбора файла — можно указать тот же файл повторно или другой.

Обновление полностью заменяет список доступных жанров коллекции новым перечнем из файла. Если в новом файле какого-либо кода жанра, который ранее уже был присвоен книгам, больше нет, эта отметка жанра у них исчезает — сама книга из коллекции не пропадает, но жанр, которого нет в файле, с нее снимается.
