Синхронизация папок и файлов

Команда «Коллекция» → «Обслуживание» → «Синхронизировать файлы» сверяет каталог активной коллекции с тем, что фактически есть на диске, и выполняет это по-разному для локальных и сетевых коллекций (см. Типы коллекций).

Для локальных коллекций: поиск перенесённых файлов

Направление — с диска в базу данных: команда сама ничего не изменяет на диске, а лишь исправляет в каталоге коллекции ссылки на файлы, и делает это только для книг, чей файл в данный момент не находится по сохраненному пути.

  1. Сначала строится полный список файлов в папке коллекции (с размером каждого; для файлов в ZIP-архивах — размер содержимого архива).
  2. Далее для каждой книги каталога проверяется, существует ли её файл по сохранённому пути.
  3. Если файла там нет, среди только что собранного списка ищется файл с таким же именем и размером; если он найден — путь к книге в каталоге исправляется на новое место.

Таким образом, обнаруживаются только файлы, перемещённые в другое место внутри папки коллекции без изменения названия и размера. Новые файлы, которых ещё нет в каталоге, эта команда не добавляет — для этого нужен отдельный импорт (см. Добавление книг в коллекцию). Файлы, не найденные нигде в папке коллекции, а также файлы с изменённым названием или размером этой командой не обнаруживаются: запись о книге остаётся в каталоге со ссылкой на старый, отсутствующий путь.

Для сетевых коллекций: состояние загруженных файлов

Здесь другой подход: команда проверяет, действительно ли на диске есть файл каждой книги (то есть была ли книга уже загружена), и исправляет отметку «загружено» в каталоге в соответствии с фактом. Если для книги, помеченной в библиотеке как удалённая, локальный файл при этом найден и в настройках включено удаление удалённых книг, файл убирается с диска, а отметка «загружено» снимается.
