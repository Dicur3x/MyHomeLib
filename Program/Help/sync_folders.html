Синхронизация папок и файлов

Команда «Коллекция → Обслуживание каталога → Синхронизировать файлы» доступна для собственных и сетевых коллекций. В подключённых внешних локальных коллекциях этой команды нет. Их пути можно проверить в настройках коллекции и источников.

Для собственных локальных коллекций: поиск перенесённых файлов

HomeLibre проверяет книги, чей файл отсутствует по сохранённому пути. Чтобы восстановить путь, программа ищет в папке коллекции файл с совпадающим именем и размером. Для книги внутри архива она проверяет имя архива, имя файла внутри него и размер этой книги.

При единственном подходящем результате HomeLibre меняет путь в каталоге. Если совпадений несколько, прежний путь сохраняется и программа сообщает об этом. Файлы на диске остаются на месте. Для книг, добавленных ссылками, можно изменить путь вручную через «Информация о книге».

Новые книги добавляются отдельной командой импорта. Если имя или размер файла изменились, запись сохраняется со старым путём.

Для сетевых коллекций: состояние загруженных файлов

Здесь другой подход: команда проверяет, действительно ли на диске есть файл каждой книги (то есть была ли книга уже загружена), и исправляет отметку «загружено» в каталоге в соответствии с фактом. Если для книги, помеченной в библиотеке как удалённая, локальный файл при этом найден и в настройках включено удаление удалённых книг, файл убирается с диска, а отметка «загружено» снимается.
