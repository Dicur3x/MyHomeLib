Чтение книг

Книгу можно читать в экспериментальной встроенной читалке, в настроенной внешней читалке или в системной программе. По умолчанию двойной щелчок открывает поддерживаемую книгу во встроенной читалке. В настройках типов файлов можно отключить это поведение; пути внешних читалок сохраняются. В контекстном меню доступны оба способа открытия.

Встроенная читалка

Для FB2, EPUB, FB3, RTF, DOCX, ODT, TXT, HTML, MHT/MHTML и Windows Write доступны изменение шрифта, поля, межстрочный интервал, шесть цветовых тем и закладки. Поиск умеет переходить к следующему и предыдущему совпадению, учитывать регистр и целые слова, подсвечивать совпадения на странице; цвет подсветки можно выбрать. Колесо перелистывает, Ctrl+колесо меняет размер. Незашифрованные Kindle-книги сначала подготавливаются; для старых Office-документов используется установленный LibreOffice.

PDF и DjVu показываются страницами. CBR/CBZ/CB7 открываются как комиксы с естественным порядком страниц; TIFF может содержать несколько страниц. Для этих форматов и изображений щелчок приближает страницу, движение мыши позволяет её осмотреть, повторный щелчок или Esc возвращает прежний вид. При этом исходный файл сохраняется. Поиск PDF использует имеющийся текстовый слой; для DjVu и изображений поиск пока недоступен. OCR не применяется.

Как выбирается программа

По расширению файла программа ищет в списке Типы файлов и программы для чтения назначенную читалку. Если для расширения настроена читалка — запускается именно она; если нет — файл открывается программой, которую для этого расширения выбрала Windows.

В папке Readers поставляются AlReader и SumatraPDF. Настроенные пути внешних читалок можно изменить в настройках. Для ZIP/RAR/7z и других поддерживаемых архивов команда чтения выбирает книгу внутри. Команда «Посмотреть содержимое архива» отдельно открывает сам архив в установленной архивной программе; «Где хранится книга…» показывает контейнер коллекции и точное имя книги внутри.

DjVu держит книгу открытой в декодере между перелистываниями и передаёт готовые пиксели прямо в читалку. Промежуточные TIFF-файлы не создаются.

Что происходит во время открытия

Книга из архива распаковывается в управляемый кэш. Готовая копия используется повторно, пока исходник не изменился. Настройки кэша позволяют выбрать папку и предел размера, увидеть занятое место и очистить кэш. При переносе папки накопленные записи перемещаются; при достижении предела удаляются старые неиспользуемые записи. Флажок очистки при выходе включён по умолчанию; его можно снять для сохранения кэша между запусками. Статус подготовки показывается возле курсора и в окне чтения.

Если книга принадлежит сетевой коллекции и еще не загружена, перед открытием HomeLib Ru сначала дозагружает именно её (короткий промежуточный прогресс); если дозагрузить не удалось, книга не открывается.

Если в настройках включен параметр «Перезаписывать заголовок fb2», открытие на чтение распакованного FB2-файла из собственной коллекции сразу переписывает в самом этом файле автора, название, жанр и серию значениями из каталога — это происходит с файлом, который лежит в папке коллекции, а не с временной копией. Тот же параметр и та же запись управляют перезаписью заголовка и при отправке на устройство; см. Редактирование описаний книг и Отправка книг на устройство.

Если ничего не открывается

  • Проверьте в разделе Типы файлов и программы для чтения, указан ли для этого расширения путь, который до сих пор существует на диске (перемещали или обновляли читалку — путь мог устареть).
  • Для книги сетевой коллекции убедитесь, что файл действительно загружен (метка локальности видна в списке книг). Если последняя загрузка завершилась ошибкой, попробуйте снова через очередь загрузок.
  • Если для расширения не назначена читалка, срабатывает обычная ассоциация Windows — убедитесь, что для этого типа файлов в системе есть подходящая программа.
