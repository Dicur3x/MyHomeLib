Чтение книг

MyHomeLib сама не показывает содержимое ни одной книги — она лишь каталогизирует файлы и, по команде «Читать», передаёт файл внешней программе. Собственной встроенной читалки в MyHomeLib нет.

Как выбирается программа

По расширению файла программа ищет в списке Типы файлов и программы для чтения назначенную читалку. Если для расширения настроена читалка — запускается именно она; если нет — файл открывается программой, которую для этого расширения выбрала Windows.

В папке Readers поставляются AlReader и свободная SumatraPDF. При первом запуске AlReader назначается для FB2/FBD, DOC/DOCX, RTF, TXT и HTML, а SumatraPDF — для PDF, DjVu, EPUB, MOBI/Kindle, CHM, XPS, комиксов и поддерживаемых графических форматов. Обычные ZIP/RAR/7z/TAR открываются через ассоциации Windows, поскольку внутри них не обязательно находятся изображения для SumatraPDF. MyHomeLib запускает выбранную внешнюю программу и передаёт ей путь к файлу; эти соответствия можно изменить в настройках. Если файл назначенной читалки удалён, сообщение об ошибке показывает полный ожидаемый путь.

Что происходит во время открытия

Если книга хранится в архиве (fb2.zip, FBD, упакованный не-FB2), MyHomeLib сначала распаковывает нужный файл в рабочую папку «Для чтения» под именем «Автор - Название» (при необходимости сокращая его), а затем открывает эту копию в читалке. Если файл с таким именем там уже есть с прошлого раза, повторно он не распаковывается. Неупакованные FB2- и raw-файлы открываются напрямую из папки коллекции, без копирования. Содержимое этой рабочей папки можно удалить одним действием: «Инструменты» → «Очистить папку "Для чтения"».

Если книга принадлежит сетевой коллекции и еще не загружена, перед открытием MyHomeLib сначала дозагружает именно её (короткий промежуточный прогресс); если дозагрузить не удалось, книга не открывается.

Если в настройках включен параметр «Перезаписывать заголовок fb2», открытие на чтение распакованного FB2-файла из собственной коллекции сразу переписывает в самом этом файле автора, название, жанр и серию значениями из каталога — это происходит с файлом, который лежит в папке коллекции, а не с временной копией. Тот же параметр и та же запись управляют перезаписью заголовка и при отправке на устройство; см. Редактирование описаний книг и Отправка книг на устройство.

Если ничего не открывается

  • Проверьте в разделе Типы файлов и программы для чтения, указан ли для этого расширения путь, который до сих пор существует на диске (перемещали или обновляли читалку — путь мог устареть).
  • Для книги сетевой коллекции убедитесь, что файл действительно загружен (метка локальности видна в списке книг). Если последняя загрузка завершилась ошибкой, попробуйте снова через очередь загрузок.
  • Если для расширения не назначена читалка, срабатывает обычная ассоциация Windows — убедитесь, что для этого типа файлов в системе есть подходящая программа.
