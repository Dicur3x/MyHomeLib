Встановлення

HomeLibre працює у Windows 10 і новіших версіях. Завантажте ZIP зі сторінки випусків і розпакуйте весь архів у теку, доступну для запису.

Який ZIP завантажити

КомплектWindows x64Windows x86
КомпактнийHomeLibre_x64_portable.zipHomeLibre_portable.zip
ПовнийHomeLibre_x64_full.zipHomeLibre_full.zip

Компактний комплект завантажує читалку й додаткові модулі за потреби. Повний містить їх одразу разом з інсталяторами WebView2 і .NET Framework для роботи без інтернету. Обидва комплекти портативні.

Випуски HomeLibre та контрольні суми

Перший запуск

  1. Запустіть HomeLibre.exe з розпакованої теки.
  2. Відкрийте Колекція → Створити нову колекцію.
  3. Виберіть свою теку з книжками, готовий індекс INPX або наявний каталог .hlc2.

Де зберігаються дані
