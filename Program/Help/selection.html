Выделение и отметка книг

В списке книг есть два независимых состояния строк. Команды, которые работают сразу с несколькими книгами, учитывают их по-разному.

Выделение
Обычное выделение строк мышью или клавиатурой — с помощью Shift, Ctrl и других привычных способов Windows. Само по себе выделение не задаёт набор книг для групповой операции, а только показывает активные строки.
Отметка
Флажок слева от строки. Большинство групповых команд выполняется именно для отмеченных книг, независимо от обычного выделения.

Какие состояния учитывают команды

Команды меню Книга и контекстного меню, которые применяются сразу к нескольким книгам (Прочитано, подменю Рейтинг, Добавить в избранное, Добавить в группу и другие), действуют на отмеченные строки. Если отметок нет, операция применяется только к текущей активной строке.

Команда Удалить — исключение. Параметр Считать выделенные отмеченными в разделе настроек Поведение определяет, считать ли обычное выделение отметкой для этой команды. По умолчанию параметр включён, поэтому можно выделить несколько строк мышью и нажать Delete. Если отключить его, перед удалением нескольких книг потребуется установить флажки.

Команды управления выделением и отметками

КомандаКомбинация клавишЧто делает
Отметить всеCtrl+AУстанавливает флажки во всех строках, не меняя обычное выделение.
Выделить всёCtrl+SВыделяет все строки, не изменяя флажки.
Отметить выделенныеCtrl+MУстанавливает флажки только у выделенных строк.
Снять отметкиCtrl+UСнимает все флажки, не меняя обычное выделение.

Все четыре команды доступны в контекстном меню списка книг. Полный перечень его пунктов приведён в разделе Контекстные меню.
