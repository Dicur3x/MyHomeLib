Типы файлов и приложения для чтения

Раздел «Типы файлов» диалога настроек (см. Настройки программы) — таблица соответствия «расширение файла → программа для просмотра», которой пользуется команда «Читать»; подробнее о самом механизме выбора читалки — в разделе Чтение книг.

Список

Таблица имеет две колонки — «Расширение» и «Путь» — и управляется тремя кнопками под ней:

Добавить
Открывает небольшое окно «Добавление типа файлов» с полями «Тип:» (расширение, без точки — регистр не важен) и «Путь:» (полный путь к программе-читалке; кнопка «Обзор...» открывает стандартный диалог выбора файла). Расширение обязательно — без него запись не добавится; если такое расширение уже есть в списке, появится сообщение об этом, и запись также не добавится.
Изменить
Открывает то же окно для выбранной строки (или двойной щелчок по строке); можно изменить как путь, так и само расширение.
Удалить
Удаляет выбранную строку из списка без дополнительного подтверждения.

Если для расширения читалки нет

Список не обязан охватывать все типы файлов в коллекции: если расширения нет в таблице, MyHomeLib просто передаёт файл программе, которую для этого расширения определила сама Windows (обычная файловая ассоциация), — так же, как и для записи с пустым полем «Путь».

Встроенная читалка

MyHomeLib не имеет собственной встроенной читалки — «Читать» всегда запускает отдельную программу. Установщик лишь кладет рядом читалку AlReader и при первом запуске (пока список читалок еще пуст) сам заполняет таблицу: расширения fb2, doc, txt, htm и html назначает AlReader, а еще для четырех расширений — pdf, djvu, mht и chm — тоже добавляет строку, но с пустым полем «Путь», то есть, как описано выше, открывает такой файл программой, зарегистрированной в Windows по умолчанию. Этот начальный набор — лишь удобное стартовое состояние таблицы: его можно свободно редактировать или удалять, как и любую другую строку.
