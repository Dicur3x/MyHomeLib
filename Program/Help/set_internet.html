Интернет и прокси

Эти два раздела диалога настроек (см. Настройки программы) описаны вместе, потому что оба касаются сетевого доступа: «Интернет» — параметры соединения и обновлений, «Прокси» — прокси-сервер, через который эти соединения проходят.

Интернет: параметры обновления

Папка с обновлениями
Папка, в которую загружаются файлы обновления библиотек перед применением. Если оставить пустой или указать несуществующую папку, используется рабочая папка программы.
Сервер INPX
Адрес, с которого MyHomeLib берет каталоги INPX при создании или обновлении сетевых коллекций (см. Создание коллекции и Обновление коллекции); также запасной вариант для загрузки книги или рецензии, если у самой подключенной коллекции нет собственного адреса источника.
Сервер обновлений
Адрес, по которому MyHomeLib проверяет наличие новой версии самой программы.

Три флажка ниже управляют автоматическими проверками во время работы программы:

Проверять обновления библиотек
Периодически проверять, есть ли обновления для подключенных сетевых коллекций (по умолчанию включено).
Запускать обновление библиотек автоматически
Если обновление библиотек найдено — запускать загрузку сразу, без запроса; если флажок выключен (по умолчанию), программа сначала запросит подтверждение. Не имеет смысла без предыдущего флажка.
Проверять наличие обновлений программы
Периодически проверять выход новой версии MyHomeLib и сообщать об этом (по умолчанию включено).

Интернет: параметры соединения

Тайм-аут соединения (мс)
Сколько ждать установки соединения с сервером, прежде чем считать попытку неудачной.
Тайм-аут чтения (мс)
Сколько ждать ответа сервера после установления соединения.
Интервал (мс)
Пауза между загрузкой отдельных файлов в очереди загрузок (см. Загрузка книг) — чтобы не перегружать сервер библиотеки частыми запросами подряд. По умолчанию — 0 (без пауз).

Оба тайм-аута применяются к любому обращению MyHomeLib к сети — загрузке книг, рецензий и проверке обновлений.

Прокси: основной

Флажок «Использовать настройки Internet Explorer» (по умолчанию включен) — MyHomeLib автоматически берет прокси-сервер из системных настроек Windows/Internet Explorer; если система сообщает, что прокси не настроен, соединение идет напрямую, без прокси. Поля ниже («Сервер», «Порт», «Пользователь», «Пароль») для ручной настройки доступны только тогда, когда этот флажок выключен.

Этот блок (автоматический или ручной) используется для всего сетевого трафика MyHomeLib, кроме того, что описано ниже отдельно для обновлений библиотек.

Прокси: тип

Выпадающий список «Тип прокси» — HTTP, SOCKS 4 или SOCKS 5. Это общая настройка: один и тот же тип применяется как к основному прокси выше, так и к отдельному прокси для обновлений ниже — собственного выбора типа прокси для обновлений нет.

Прокси для обновления коллекций

Этот блок имеет заголовок «Настройка прокси для обновления коллекций»; его поля легко спутать с полями основного прокси выше, поэтому перед редактированием проверьте, под каким именно заголовком вы работаете.

Это отдельный, полностью самостоятельный прокси-сервер — он используется только при проверке и загрузке обновлений для сетевых коллекций (и сопутствующих файлов INPX), а не для загрузки самих книг или рецензий, которая всегда выполняется через основной прокси выше. Переключатель «Не использовать прокси для обновлений» / «Использовать прокси для обновлений» определяет, использовать ли для этого трафика отдельные «Сервер», «Порт», «Пользователь» и «Пароль» ниже (поля доступны только при выборе второго варианта), или подключаться напрямую, без прокси (обычный вариант). Настройки Internet Explorer на этот блок не влияют.
