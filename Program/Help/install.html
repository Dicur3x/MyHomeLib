Установка

HomeLibre работает в Windows 10 и новее. Скачайте ZIP со страницы выпусков и распакуйте его целиком в папку, где у вас есть право записи.

Какой ZIP скачать

КомплектWindows x64Windows x86
КомпактныйHomeLibre_x64_portable.zipHomeLibre_portable.zip
ПолныйHomeLibre_x64_full.zipHomeLibre_full.zip

Компактный комплект скачивает читалку и другие дополнительные модули по мере необходимости. Полный комплект содержит их заранее, включая установщики WebView2 и .NET Framework для работы без интернета. Оба комплекта портативны.

Выпуски HomeLibre и контрольные суммы

Первый запуск

  1. Запустите HomeLibre.exe из распакованной папки.
  2. Откройте Коллекция → Создать новую коллекцию.
  3. Выберите свою папку с книгами, готовый INPX или существующий каталог .hlc2.

Где данные

Настройки и системная база сохраняются рядом с программой. Книги и файлы коллекций могут лежать в других папках. Перенос программы и профиль · Обновление с прежней версии.
