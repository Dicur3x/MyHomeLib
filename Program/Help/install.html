Установка

Системные требования

MyHomeLib — приложение для Windows, доступное в 32-битной (x86) и 64-битной (x64) сборках; для установки необходимо выбрать вариант под разрядность Windows. SQLite, списки жанров и внешние читалки AlReader и SumatraPDF уже находятся в поставке, отдельно устанавливать их не нужно.

x86 или x64

Существуют два дистрибутива: Setup_MyHomeLib_<версия>.exe (32-разрядный) и Setup_MyHomeLib_<версия>_x64.exe (64-разрядный). x64-версия устанавливается только на 64-битную Windows; x86-версия работает как на 32-, так и на 64-битной. Во всём остальном оба установщика одинаковы — та же папка установки по умолчанию, те же ярлыки, тот же выбор языка мастера установки (Русский, English, Українська или Български).

Что инсталлятор записывает в папку программы, а что — в %APPDATA%\MyHomeLib

По умолчанию программа устанавливается в стандартную папку Program Files — Program Files\MyHomeLib для x64-версии или Program Files (x86)\MyHomeLib для x86-версии на 64-битной Windows. Сюда установщик помещает MyHomeLib.exe, необходимые DLL, папку Readers, списки жанров, справку и лицензии.

Отдельно установщик создаёт папку %APPDATA%\MyHomeLib (с правом записи для любого пользователя Windows) и помещает туда единственный файл — collections.ini со списком источников для обновления сетевых библиотек, и только тогда, когда такого файла там ещё нет. Всё остальное в этой папке — настройки, системная база (Data\user.dbs2, см. Основные термины) и рабочие журналы — создаёт уже сама программа при первом и последующих запусках, а не установщик; подробнее — в разделе Часто задаваемые вопросы.

Ярлыки в меню «Пуск»

Инсталлятор создаёт группу программ с ярлыками запуска MyHomeLib, справки (название и язык справки соответствуют языку мастера установки), «MyHomeLib website» (ссылка на домашнюю страницу проекта) и пункт удаления программы. Если во время установки отметить соответствующий флажок, дополнительно появится ярлык на рабочем столе. Мастер установки также позволяет вообще не создавать папку в меню «Пуск».

Удаление программы

Удалить MyHomeLib можно через ярлык удаления из группы программ в меню «Пуск» или через стандартный список программ Windows — оба способа запускают один и тот же деинсталлятор.

Деинсталлятор удаляет не только файлы из папки программы, но и всю папку %APPDATA%\MyHomeLib, включая подпапку Data, где хранится системная база user.dbs2. То есть удаление программы уничтожает список подключенных коллекций, группы (в том числе «Избранное»), рейтинги и заметки к книгам. Если эти данные нужно сохранить, скопируйте папку %APPDATA%\MyHomeLib в другое место до удаления.

Сами коллекции — файлы книг и файл базы .hlc2 — установщик и деинсталлятор не трогают: они находятся там, куда их положил пользователь при создании или подключении коллекции (см. Свойства коллекции), поэтому удаление программы на них не влияет.
