Часто задаваемые вопросы

Где хранятся настройки и системная база?

По умолчанию MyHomeLib хранит настройки и системную базу (см. Основные термины) в папке %APPDATA%\MyHomeLib, а саму базу — в подкаталоге Data внутри неё. Если рядом с исполняемым файлом программы есть признак portable-режима (или нет папки с данными пользователя Windows), MyHomeLib вместо этого сохраняет те же файлы в собственной папке рядом с MyHomeLib.exe. Подробнее — в разделе Portable-версия.

Почему книга не открывается?

Чаще всего причина одна из двух. Во-первых, для расширения файла может не быть назначено приложение для чтения, а в Windows нет программы по умолчанию для этого типа файлов — тогда назначьте приложение для чтения в разделе Типы файлов и программы для чтения. Во-вторых, сам файл книги мог исчезнуть с диска — переместиться, переименоваться или быть удалённым вне MyHomeLib; об этом сообщает ошибка «Файл … не найден! Проверьте настройки коллекции!».

Почему загруженная книга отсутствует?

Загруженная книга попадает в ту же сетевую коллекцию, из которой она была загружена, а не в какую-то отдельную «загруженную» папку — проверьте, открыта ли именно эта коллекция. Если загрузка завершилась с ошибкой, подробности записываются в журнал download_errors.log рядом с настройками программы. См. Загрузка книг.

Что произойдет, если файл коллекции исчезнет с диска?

Путь к файлу коллекции и другие её свойства MyHomeLib сохраняет в системной базе, а не в самом файле коллекции. Поэтому когда файл .hlc2 перемещали, переименовывали или удаляли вне программы, из списка для переключения коллекций (меню «Коллекция» → «Выбрать коллекцию») он не исчезает — этот список формируется без проверки, существует ли файл. Открыть именно эту коллекцию, однако, не получится, пока файл не вернут на прежнее место или пока коллекцию не подключат заново, указав новый путь; см. Работа с коллекциями. Сообщение «Файл коллекции не найден. Невозможно запустить программу.» появляется только один раз — при запуске, и только тогда, когда одновременно недоступны файлы всех без исключения зарегистрированных коллекций; если файл есть хотя бы у одной из них, MyHomeLib просто откроет её вместо той, что исчезла.

Как перенести коллекцию на другой диск?

Скопируйте (или переместите) папку с файлами книг и файл базы коллекции на новый диск, а затем откройте свойства коллекции и укажите новый путь в поле «Папка с книгами:». См. Свойства коллекции.

Как перенести всю библиотеку на новый компьютер?

Скопируйте на новый компьютер папку с данными MyHomeLib (системную базу, настройки, журналы) вместе с папками, где лежат файлы коллекций, сохранив тот же путь, или воспользуйтесь портативным режимом — тогда всё это уже находится рядом с программой и переносится простым копированием одной папки. См. Portable-версия. Отдельно перенести или объединить только данные пользователя (оценки, группы и т. д.) можно средствами раздела Экспорт и импорт данных пользователя.
