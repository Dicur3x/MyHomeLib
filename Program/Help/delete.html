Удаление книг

Команда «Удалить» (меню «Книга» или контекстное меню списка; см. Меню «Книга») ведет себя по-разному в зависимости от типа активной коллекции — и в одном из двух случаев действительно безвозвратно удаляет книгу из базы. Перед выполнением команда всегда запрашивает подтверждение, и текст вопроса подсказывает, что именно произойдет.

Удалить книгу, просматривая её через вкладку группы или «Избранного», нельзя — программа сначала попросит перейти на вкладку той коллекции, которой книга действительно принадлежит. Это ожидаемо: группы — лишь способ просмотра, а не собственная коллекция; см. Группы и избранное.

Сетевая (онлайн) коллекция: «Удалить загруженные файлы?»

Здесь «Удалить» вообще не трогает каталог. Если файл книги уже загружен на диск, MyHomeLib удаляет только этот файл и помечает книгу как незагруженную; сама запись в каталоге, её рейтинг, прогресс и принадлежность к группам остаются без изменений. Книгу всегда можно загрузить снова — см. Загрузка книг.

Собственная или подключенная коллекция: удаление записи из базы

Здесь запись о книге удаляется из каталога коллекции безвозвратно — прямым удалением строки из базы данных, без корзины или отметки «удалено», которую можно было бы отменить. Вместе с книгой:

  • из базы удаляются авторы, которые после этого удаления больше не остались связанными ни с одной другой книгой;
  • книга исчезает из всех групп, в которые она входила, — в том числе из «Избранного» и «К прочтению».

Восстановить удалённую запись можно только повторным импортом (например, повторно импортировав коллекцию из INPX или заново просканировав файлы) — сама программа нигде не сохраняет удалённое описание книги.

Удаляется ли файл с диска

Зависит от параметра «Удалять файлы при удалении книг» в настройках (см. Поведение):

  • параметр выключен — удаляется только запись в каталоге, файл остаётся на диске как есть (осиротевшим); при необходимости его можно снова добавить в каталог повторным импортом;
  • параметр включён — для книги не-FB2-формата файл удаляется всегда; для книги в формате FB2 — только если активная коллекция собственная (частная). Если коллекция подключена из чужого INPX и использует чужие файлы, файл при удалении записи не трогается, чтобы не задеть файлы, которыми программа фактически не владеет.

Когда файл все же удаляется, это обычное удаление Windows мимо корзины (кодовая попытка перенести файлы в корзину в программе есть, но отключена как «странно работающая») — восстановить такой файл можно только с помощью средств восстановления данных, справка MyHomeLib этого не гарантирует.
