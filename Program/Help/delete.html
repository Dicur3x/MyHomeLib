Удаление книг

Команда «Удалить» (меню «Книга» или контекстное меню списка; см. Меню «Книга») ведет себя по-разному в зависимости от типа активной коллекции. В подтверждении показаны название коллекции, число выбранных книг и действие с записями и файлами. Одна книга, показанная в нескольких сериях, считается один раз. По умолчанию выбран ответ «Нет».

Удалить книгу, просматривая её через вкладку группы или «Избранного», нельзя — программа сначала попросит перейти на вкладку той коллекции, которой книга действительно принадлежит. Это ожидаемо: группы — лишь способ просмотра, а не собственная коллекция; см. Группы и избранное.

Сетевая (онлайн) коллекция: «Удалить загруженные файлы?»

Здесь «Удалить» вообще не трогает каталог. Если файл книги уже загружен на диск, HomeLibre удаляет только этот файл и помечает книгу как незагруженную; сама запись в каталоге, её рейтинг, прогресс и принадлежность к группам остаются без изменений. Книгу всегда можно загрузить снова — см. Загрузка книг.

Собственная или подключенная коллекция: удаление записи из базы

Здесь запись о книге удаляется из каталога коллекции безвозвратно — прямым удалением строки из базы данных, без корзины или отметки «удалено», которую можно было бы отменить. Вместе с книгой:

  • из базы удаляются авторы, которые после этого удаления больше не остались связанными ни с одной другой книгой;
  • книга исчезает из всех групп, в которые она входила, — в том числе из «Избранного» и «К прочтению».

Восстановить удалённую запись можно только повторным импортом (например, повторно импортировав коллекцию из INPX или заново просканировав файлы) — сама программа нигде не сохраняет удалённое описание книги.

Удаляется ли файл с диска

В подтверждении можно выбрать «Удалить файлы книг с диска». Начальное значение галочки задаёт параметр «Удалять файлы при удалении книг» в настройках (см. Поведение).

  • Без галочки удаляются записи, файлы книг остаются на диске. Их можно снова добавить в каталог повторным импортом.
  • С галочкой удаляются также файлы выбранных книг. В ZIP и поддерживаемых 7z программа сверяет точные имена и проверяет, нужны ли эти файлы другим записям. Соседние книги и служебные файлы сохраняются. Если удаляются все записи обычного архива, программа может убрать исходный файл целиком после обновления каталога.

Обработка архивов идёт в фоне. Одно окно показывает ход всей операции. При сбое журнал позволяет продолжить незавершённое удаление после перезапуска. Подробности доступны в «Помощь → Журнал ошибок…».

В коллекциях FLibrary вместе с файлами книг можно убрать их отдельные обложки и иллюстрации. Из архивов covers и images удаляются только изображения, принадлежность которых удалось подтвердить. Общие изображения и файлы с неясной принадлежностью сохраняются.

Отдельные файлы удаляются мимо корзины. Восстановление удалённого файла средствами программы не предусмотрено.
