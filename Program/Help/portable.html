Portable-версия

Запуск и данные

Распакуйте ZIP-комплект в доступную для записи папку и запустите HomeLibRu.exe. Программа портативная по умолчанию: файл uselocaldata создавать не нужно. Настройки находятся рядом с программой, системная база — в Data\user.dbs2. Не переносите файлы профиля вручную, пока программа работает.

Структура поставки

В корне находятся HomeLibRu.exe, механизм обновления HomeLibRuUpdater.exe, библиотека каталогов sqlite3.dll и условия использования LICENSE, NOTICE. Папка Icons содержит значки, Help — справку и локальную историю выпусков CHANGES.txt.

Справочники жанров genres_*.glst собраны в tools\genres: отдельно для FB2 и прочих коллекций, с переводами. tools\updates\COMPONENTS.json содержит начальные сведения и историю обновлений компонентов; сами компоненты он не устанавливает. Старое расположение этих файлов в корне также поддерживается.

HomeLibRu.update.json в корне архива нужен прежним версиям для проверки обновления: версии, разрядности и контрольных сумм файлов. Обновлятор не устанавливает его как часть программы; при ручной распаковке он остаётся рядом с EXE. Редактировать его для исправления обновления не нужно.

Минимальный комплект не содержит читалку, шрифты и дополнительные модули форматов. При необходимости программа предложит скачать соответствующий компонент. Копируйте папку программы целиком, чтобы сохранить установленные компоненты и данные.

Временные файлы и перенос на другой диск

По умолчанию временные файлы находятся во временной папке Windows. Для локальной временной папки $tmp можно создать рядом с EXE пустой файл uselocaltemp или передать одноимённый параметр запуска. Файл uselocaldata для этого не нужен и на временную папку не влияет.

Пути к книгам, загрузкам и устройствам могут быть абсолютными. После смены буквы диска проверьте их в настройках. Распаковка архива не создаёт ярлыки и пункт удаления Windows.
