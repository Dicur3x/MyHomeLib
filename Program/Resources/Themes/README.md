# HomeLib Ru dark interface style

HomeLibRuDark.vsf is the unmodified Charcoal Dark Slate VCL style distributed
with Embarcadero RAD Studio 13 in Redist/styles/vcl/CharcoalDarkSlate.vsf.
It is embedded as the MHL_DARK_STYLE VCLSTYLE resource.
The Embarcadero redistributable style is separate from the MIT source code.

HomeLib Ru adds its own table, tab, link and reader colours in unit_MHLTheme
and the corresponding view components.
