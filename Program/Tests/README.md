# Проверки OPDS HomeLib Ru

`OPDSServerTest.dproj` — консольный тестовый сервер, использующий настоящий
`unit_OPDSServer`, SQLiteWrap, Indy и путь получения книг из HomeLib Ru.
`opds_tests.js` создаёт отдельную коллекцию во временной папке и проверяет её
через HTTP. Дополнительные пакеты Node.js и Python не нужны.

## Подготовка и запуск

1. Собрать `Utils/MHLMcpServer/MHLMcpServer.dproj` и
   `Program/Tests/OPDSServerTest.dproj` в RAD Studio для нужной платформы.
2. Подготовить штатные runtime-файлы рядом с MCP EXE по `BUILDING.md`:
   `sqlite3.dll`, `libzstd.dll` соответствующей архитектуры и `genres_fb2.glst`.
3. Запустить команду из корня репозитория. Требуются Node.js 18+ и Python 3,
   доступный командой `python`.

Win32:

```powershell
node Program/Tests/opds_tests.js Program/Tests/Out/Win32/OPDSServerTest.exe Program/Out/Bin/MHLMcpServer.exe
```

Win64:

```powershell
node Program/Tests/opds_tests.js Program/Tests/Out/Win64/OPDSServerTest.exe Program/Out/Bin64/MHLMcpServer.exe
```

Оба переданных EXE и DLL должны относиться к одной архитектуре. Скрипт копирует
runtime в `%TEMP%\homelib-opds-test-*`, запускает MCP с `--make-fixture` и
профилем `uselocaldata user mcpfixture`, затем подготавливает 100 дополнительных
книг. С учётом шести исходных книг получается 106 записей, из которых одна
помечена удалённой: сервер показывает 105 книг. После проверки временная папка
удаляется.

Консольный EXE имеет строгую защиту тестовой среды: принимает только профиль
`mcpfixture`, расположение непосредственно под `%TEMP%`, имена базы и корня,
сформированные скриптом, и маркер `uselocaltemp`. Проверки неверных аргументов
выполняются до создания настроек, файлов или строк коллекции. Сервер слушает
`127.0.0.1` на свободном порту, выдаёт JSON с адресом и завершает работу по
команде `stop` через стандартный ввод.

## Что проверяется

- Отказ защиты среды при неверных путях и параметрах; SQLite read-only
  соединение отклоняет `UPDATE`.
- Отказ `Start` для онлайн-коллекции с русским пояснением, в том числе после
  работы с локальной коллекцией: сервер остаётся выключенным. Для
  `AllowLAN=True` проверяются IPv4-привязка `0.0.0.0` через Windows
  `GetTcpTable`, запрос Atom по `127.0.0.1` и закрытие временного слушателя.
- Корневой Atom OPDS 1.2 каталог, переходы к книгам, авторам, жанрам и сериям,
  `self`, `start`, `search` и OpenSearch с адресом работающего сервера.
- Страницы 50/50/5 для 105 видимых книг, `next`/`previous`, отсутствие
  повторов книг из нескольких серий, обе серии каждой тестовой книги.
- Фильтры авторов и жанров, пропуск авторов без книг и с одними удалёнными
  книгами, поиск названий и авторов с кириллицей, эмодзи, `%`, `_`, `+`, `&`
  и текстом, похожим на SQL.
- Ссылки скачивания с реальным расширением, совместимый числовой адрес,
  MIME и `Content-Disposition`. Проверяется передача исходных байтов FB2
  в UTF-8 и Windows-1251, книги из обычного ZIP, EPUB, PDF, TXT и BIN.
- `HEAD`: длина и тип совпадают с `GET`, тело отсутствует. У скачиваемого
  файла сохраняется собственная кодировка; HTTP не приписывает ему charset.
- Четыре одновременных скачивания, ответы 404/405/400/503, неверный токен,
  удалённая книга, обход пути, неверное расширение и параметры; восстановление
  после временной недоступности базы или файла.
- 24 ответа разбираются настоящим XML-парсером Python, с проверкой пространств
  имён и обязательных элементов Atom.
- Хеши базы, архивов и книг сохраняются после запросов и остановки. SQLite
  SHM и пустой WAL считаются служебными файлами; содержимое непустого WAL
  тоже сравнивается. `Stop` закрывает простаивающее соединение и освобождает
  файловые дескрипторы базы.

Воспроизводимая проверка периодов даты добавления и присланного пресета:

```powershell
node Utils/MHLMcpServer/tests/search_date_tests.js Program/Out/Bin/MHLMcpServer.exe
node Utils/MHLMcpServer/tests/search_date_tests.js Program/Out/Bin64/MHLMcpServer.exe
```

Она выполняет 17 реальных поисков SQLite: шесть периодов без пресетов, шесть
с сохранением и повторным чтением пресетов, три из исходного
`search-date-reported.cxml2`, пользовательскую дату и пустую дату. Изменения
шести тестовых книг откатываются. Обычный `--make-fixture` также выполняет
14 проверок дат без необязательного присланного файла.

## Зафиксированный результат

2026-10-05: окончательные сборки Win32 и Win64 прошли все 15 групп OPDS,
включая 24 XML-ответа, и все 17 поисков даты. Проверены отказ для
онлайн-коллекции, IPv4-привязка режима LAN и локальный HTTP-запрос,
сохранность байтов и завершение сервера. Испытания проводились на
синтетической коллекции; правила брандмауэра не изменялись.

Для FB2 используется `application/x-fictionbook+xml`, присутствующий в
[таблице MIME KOReader](https://github.com/koreader/koreader/blob/master/frontend/document/credocument.lua)
и [FBReaderJ](https://github.com/geometer/FBReaderJ/blob/master/fbreader/app/src/main/java/org/geometerplus/zlibrary/core/util/MimeType.java).
[OPDS-клиент KOReader](https://github.com/koreader/koreader/blob/master/plugins/opds.koplugin/opdsbrowser.lua)
сначала распознаёт расширение ссылки, затем MIME; поэтому адрес скачивания
содержит суффикс формата. Это проверка совместимости по исходникам клиентов.
Физические PocketBook, KOReader, FBReader, Moon+ Reader и подключение
с другого устройства в LAN в этой проверке не запускались. Проверка LAN-режима
использует только локальный HTTP-запрос на тестовом компьютере.
