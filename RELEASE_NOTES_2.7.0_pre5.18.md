# HomeLib Ru 2.7.0_pre5.18

Версия программы: **2.7.0.1086**.

## Сохранность коллекций

- При перенумерации книг во время обновления коллекции личные сведения и группы
  перемещаются атомарно. Обмен и циклическая смена номеров больше не используют
  удаление конфликтующих записей.
- Если книга пропала из каталога, её личная карточка сохраняется отдельно.
  Повторное появление с подтверждённым исходным ID возвращает прежние сведения.
  Совпадение одного номера другой книги не считается подтверждением.
- Обновление различает отмену до сохранения, сохранённую часть операции и ошибку
  после сохранения. Любимые авторы обновляются для действительно изменённых коллекций.
- При повторном объединении добавляются только отсутствующие связи серий.
  Уже сохранённые сведения об исходных файлах не перезаписываются другим источником.

- Сохранённая книга в группе проверяется перед экспортом и записью личных сведений.
  Замена каталога не переносит оценку, отзыв или позицию чтения на другую книгу
  с тем же номером. Отметки пропущенных книг остаются на месте.
- Если отзыв не удаётся записать в карточку, полный текст сохраняется отдельным
  черновиком. При ошибке записи черновика редактор сохраняет введённый текст
  для повторной попытки.
- Настройки программы, позиции чтения и закладки записываются через готовый
  временный файл. Ошибка записи или блокировка файла сохраняет прежний профиль.
- Пауза очереди загрузок не помечает следующую, ещё не обработанную книгу
  завершённой. Отменённая книга остаётся в очереди, счётчик учитывает только
  действительно законченные загрузки.
- Строки сохранённой очереди читаются в пределах своей записи; старый формат
  поддерживается. При повреждённой загрузке исходный файл остаётся целым,
  а автозапуск пропускается на этот сеанс без изменения настройки.
- Сохранение очереди сначала полностью готовит данные, затем заменяет файл.
  Ошибка сериализации, блокировка и запрет записи сохраняют прежний файл.
- Повторное чтение личной карточки больше не добавляет авторов и жанры второй раз.

## Любимые авторы

- На вкладке «Авторы» появился спокойный переключатель «♥ Любимые» и добавление
  выбранного автора. Новые книги любимых авторов учитываются после обновления коллекции.
- Просмотр списка сам по себе не помечает новинки прочитанными или просмотренными;
  для этого предусмотрено отдельное действие.
- В поиске небольшое условие любимых авторов находится внутри поля автора.
  В фильтре столбца «Автор» есть соответствующий флажок. Эти условия можно сочетать
  с остальными фильтрами, не увеличивая панель поиска.

## Поиск, фильтры и кэш

- Добавлены поиск по издательству, необязательный столбец и его фильтр.
  Используются сведения каталога; файлы книг ради поиска не открываются.
- Кнопка скрытия удалённых книг и условие поиска используют один режим.
  Переключение сохраняет незавершённый ввод и повторяет только применённый поиск.
- Исправлено сохранение и удаление пресетов с введённым названием, в том числе
  кириллическим. Ошибка записи сохраняет прежний файл пресетов.
- Рядом со списком пресетов добавлено меню импорта и экспорта. Обычный XML
  можно редактировать; прежние сжатые файлы пресетов также принимаются.
  Импорт сохраняет старые пресеты и текущий ввод, а совпавшие названия получают
  отдельный номер. Повреждённый файл не импортируется частично.
- Вложенные окна фильтров работают с черновиком до общего «Применить».
  «Отмена» сохраняет прежние фильтры и отметки книг.
- Исправлены размеры кнопок фильтра и подписи «Аннотация» при увеличении интерфейса.
- При запуске на вкладке «Поиск» панель больше не прокручивается сама к полю
  даты, скрывая автора. Порядок перехода по категориям совпадает с их расположением.
- В настройках кэша можно быстро выбрать папку данных программы, временную папку
  Windows, локальные данные пользователя или свой путь. Полный путь виден и копируется.
  Перенос происходит только после применения настроек.

## Конвертация FB2 и EPUB

- Экспорт позволяет отдельно преобразовать FB2 в EPUB или EPUB в FB2.
  Книги внутри ZIP поддерживаются; главы, изображения и ссылки на сноски сохраняются.
- Исходная книга не меняется. Если имя результата уже занято, создаётся другое имя;
  существующий файл не заменяется.
- Предупреждения видны в журнале и полном отчёте. Большой список предупреждений
  больше не заставляет окно многократно перечитывать весь текст.
- Для остальных входных форматов преобразование в FB2/EPUB пока не добавлено.
  Обычный экспорт файлов продолжает работать.
- Конвертация рассчитана на текстовые книги до 64 МБ. Произвольная CSS-вёрстка
  может упрощаться; сложные SVG, формулы, аудио и видео отклоняются с объяснением.
  [Полные ограничения конвертера](tools/bookconvert/README.md).

## Встроенная читалка

- При одной выбранной книге команды получают её напрямую: скрытые фильтром
  строки большого списка больше не перебираются при каждом обновлении интерфейса.
- Исправлено сохранение выделенных строк при последовательном удалении,
  добавлении и снятии выделения внутри групповой операции.
- Оглавление обновляет подписи одним проходом. Исходные номера, вложенность
  и позиции глав сохраняются; добавленную нумерацию можно отключить.
- Исправлено чтение описания FB2, когда блок заканчивается внутри символа
  UTF-8 или UTF-16 уже в тексте книги. Повреждённые символы в самом описании
  продолжают отклоняться, чтобы названия серий и другие сведения не искажались.
- Перед выбором резервной копии проверяется исходная книга и происхождение её ID.
  Переиспользованный номер каталога не открывает чужой файл.
- Пустые служебные ID не объединяют кэш, позиции чтения и заметки разных книг.
  Для числовых ID без известной библиотеки история различает исходные файлы;
  совместимые известные ID сохраняют прежнюю историю.
  Старые неоднозначные записи сохраняются и доступны в общем экспорте заметок.

## Сторонние читалки

- Подготовленный файл получает понятное название книги и автора вместо
  технического имени. Короткий служебный суффикс различает одноимённые книги.
- Настройка перезаписи заголовка FB2 работает с копией для читалки.
  Открытие сохраняет исходную книгу даже при включённой перезаписи.
- Копия готовится в фоне, поддерживает отмену и повторное открытие из кэша.
  Исходники, внутренние имена истории чтения и заметок сохраняются.

Выпуск поставляется двумя полными архивами для Win32 и Win64. Компоненты находятся
внутри; проверка и автоматическое обновление компонентов используют ресурсы авторов.
Книги, коллекции, настройки, заметки и история в архивы поставки не включаются.
