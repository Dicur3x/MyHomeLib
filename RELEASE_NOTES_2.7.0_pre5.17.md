# HomeLib Ru 2.7.0_pre5.17

Версия программы: **2.7.0.1085**.

## Размер поставки и шрифты

- В общий архив входят четыре семейства для чтения: PT Serif, PT Sans, Noto Serif
  и Noto Sans. Они содержат латиницу и кириллицу, включая русский, английский,
  украинский и белорусский текст.
- Шрифты остальных письменностей предлагаются при чтении текста, для которого
  подходящего шрифта ещё нет. В предложении указаны язык и размер загрузки.
  Кнопка «Позже» позволяет продолжить чтение с доступным шрифтом Windows.
- Загрузка начинается только по кнопке «Скачать» и идёт в фоне. Проверяются
  размер и контрольная сумма каждого файла. Готовые шрифты сохраняются для
  следующих книг; прерванная загрузка не считается готовым комплектом.
- Применение скачанных шрифтов сохраняет текст книги и место чтения.

## Обновление компонентов

- Новые версии и списки изменений проверяются на официальных ресурсах авторов.
  Отдельные ZIP компонентов в assets HomeLib Ru больше не публикуются.
- Автоматическое обновление сохранено. Для DocSharp скачиваются два согласованных
  пакета из NuGet; для DjVuLibre — официальный выпуск Windows и соответствующие
  исходники; для 7-Zip — официальный архив автора. Установщики используются для
  извлечения нужных файлов и не запускаются.
- Перед заменой выполняются проверки разрядности, версии и совместимости с
  читалкой. При ошибке установки возвращаются прежние файлы компонента.
- Если официальный выпуск Windows подтвердить не удалось, окно сообщает об этом.
  Уже установленная внешняя читалка продолжает работать.

## Проверки компонентов чтения

- Проверка DjVu корректно сообщает об отсутствии или несовместимости библиотеки.
- Компонент DOC возвращает понятную ошибку при отсутствующей зависимости.
  Чтение DOC по-прежнему использует встроенный DocSharp и не требует LibreOffice.

Коллекции, книги, настройки, история чтения, закладки и заметки не включаются в
архив обновления и не заменяются файлами поставки.
