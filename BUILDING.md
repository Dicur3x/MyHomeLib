# Как собрать MyHomeLib в `exe`

Инструкция рассчитана на человека, который не пишет на Delphi. Основной и
самый простой вариант — собрать весь групповой проект в Delphi 13, затем
положить рядом с программой `sqlite3.dll` той же разрядности.

## Что получится

После сборки файлы находятся здесь:

- 64-битная версия: `Program\Out\Bin64\MyHomeLib.exe`;
- 32-битная версия: `Program\Out\Bin\MyHomeLib.exe`.

Рядом также должны находиться `sqlite3.dll`, `MHLMcpServer.exe`, каталог
`Icons` с `MHLIcons.dll` и каталог `Help`. Один `MyHomeLib.exe` без этих файлов
не является полной поставкой.

## 1. Установите инструменты

Нужны:

1. **Delphi 13 / RAD Studio 37.0** с компонентами VCL и платформами Windows
   32-bit и Windows 64-bit. Если установщик Delphi предлагает выбор платформ,
   отметьте обе.
2. **Virtual TreeView**. В Delphi откройте **Tools → GetIt Package Manager**,
   найдите `Virtual TreeView`, установите и перезапустите Delphi.
3. **Konopka Signature VCL Controls** (`BonusKSVC`, для официальной версии
   проекта указана ветка 8.0.x). Установите пакет через GetIt и снова
   перезапустите Delphi.
4. Официальная `sqlite3.dll` со [страницы загрузки SQLite](https://www.sqlite.org/download.html):
   архив `sqlite-dll-win-x64-...` для Win64 либо `sqlite-dll-win-x86-...` для
   Win32. Распакуйте DLL в отдельную папку.
5. **Node.js** — необязательно. Он нужен для встраивания дополнительных
   языковых каталогов. Без Node.js проект собирается, но использует только
   строки, находящиеся в исходниках.

Для обычного запуска OpenSSL отдельно не нужен: актуальная сетевая часть
использует системные средства Windows.

## 2. Соберите проект через Delphi

1. Запустите Delphi.
2. Выберите **File → Open Project**.
3. Откройте именно `Program\MHL.groupproj`.
4. В менеджере проектов выберите конфигурацию **Release**.
5. Выберите платформу **Windows 64-bit / Win64**. Это основной вариант для
   современных компьютеров. Для старой 32-битной Windows выберите Win32.
6. Выполните **Project → Build All Projects** (либо щёлкните правой кнопкой по
   группе `MHL` и выберите **Build All**).

Группа собирает четыре части в правильном порядке: компоненты MyHomeLib,
ресурсную DLL с иконками, основную программу и MCP-сервер. Не собирайте для
релиза только `Program\MyhomeLib.dproj`: такая сборка пропустит часть
обязательных файлов.

Если Delphi спрашивает, сохранять ли автоматически изменённые файлы проекта,
для первой сборки выберите **No**. Пользовательские настройки IDE не нужны в
репозитории.

## 3. Добавьте SQLite и проверьте комплект

Из корня репозитория откройте PowerShell. Сначала выполните проверку без
копирования (замените путь к DLL своим):

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\prepare-runtime.ps1 `
  -Platform Win64 `
  -SqliteDll "C:\Downloads\sqlite3.dll"
```

Если архитектура указана правильно и ошибок нет, повторите команду с `-Copy`:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\prepare-runtime.ps1 `
  -Platform Win64 `
  -SqliteDll "C:\Downloads\sqlite3.dll" `
  -Copy
```

Скрипт:

- проверяет, что `exe`, SQLite, MCP-сервер и DLL иконок имеют нужную
  разрядность;
- не перезаписывает отличающийся существующий файл;
- проверяет наличие справки и копирует штатные списки жанров;
- показывает SHA-256 основных исполняемых файлов.

Для Win32 замените `Win64` на `Win32` и используйте x86-версию SQLite.

После этого можно запускать:

```text
Program\Out\Bin64\MyHomeLib.exe
```

Чтобы перенести программу на другой компьютер, копируйте всю папку `Bin64`
(или `Bin`), а не только `exe`.

## 4. Сборка из командной строки

Этот способ удобен после того, как зависимости уже установлены через GetIt.
Откройте **RAD Studio Command Prompt** из меню «Пуск», перейдите в корень
проекта и выполните:

```bat
msbuild Program\MHL.groupproj /t:Build /p:Config=Release /p:Platform=Win64 /nologo /v:minimal
```

Для 32-битной версии укажите `/p:Platform=Win32`.

Не запускайте обычный MSBuild из случайного терминала: командная строка RAD
Studio заранее задаёт `BDS`, `BDSCOMMONDIR` и пути к компилятору и пакетам.

## 5. Как получить установщик

Для собственного использования достаточно папки с готовым `exe`. Если нужен
установщик:

1. Установите [Inno Setup 6](https://jrsoftware.org/isinfo.php) в стандартную
   папку.
2. Сначала успешно соберите и проверьте обе нужные платформы, как описано выше.
3. Убедитесь, что в выходных папках присутствуют файлы поставки, которые
   использует сценарий установщика (`sqlite3.dll`, настройки коллекций и ярлык
   сайта).
4. Запустите из корня проекта:

```bat
Installer\build_installer.cmd x64
```

Варианты: `x86`, `x64` или `all`. Результат появляется в `Installer\Out`.
Сценарий предназначен прежде всего для выпуска дистрибутива и повторно
собирает выбранную платформу.

## Частые ошибки

### Не найден `VirtualTrees`, `VirtualTreesD` или `VirtualTreesR`

Virtual TreeView не установлен для Delphi 13 либо его библиотечные пути не
подхватились. Установите пакет через GetIt, перезапустите Delphi и снова
соберите всю группу. Не подсовывайте готовые DCU/BPL от другой версии Delphi.

### Не найдены `RzPanel`, `RzCommon` или `RaizeComponentsVcl`

Не установлен `BonusKSVC` либо он установлен для другой версии Delphi.
Переустановите Konopka Signature VCL Controls через GetIt.

### Ошибка в `copy_help.cmd` или не найден `robocopy`

Добавьте `C:\Windows\System32` в `PATH` и повторите сборку. Обычно этот путь
уже присутствует в Windows.

### Программа сообщает, что не найдена `sqlite3.dll`

DLL не была скопирована рядом с `MyHomeLib.exe` или имеет другую разрядность.
Повторите шаг 3 и не переименовывайте файл.

### Интерфейс запускается без иконок

Отсутствует `Icons\MHLIcons.dll`. Такое бывает, если была собрана только
основная программа, а не `Program\MHL.groupproj`.

### Сборка из терминала не находит стандартные модули Delphi

Используйте **RAD Studio Command Prompt**. Если проблема появилась после того,
как IDE автоматически переписала `.dproj`, верните файл проекта из Git и
соберите групповой проект заново.

## Что не входит в обычную проверку

Конвертеры FB2 → MOBI/EPUB/PDF и некоторые программы чтения являются отдельными
сторонними продуктами. Они не нужны, чтобы собрать и запустить MyHomeLib; их
устанавливают позже только при необходимости соответствующей функции.
