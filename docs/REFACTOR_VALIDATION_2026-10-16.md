# Проверка исправлений повторного аудита

Это продолжение [повторного аудита](APP_PROPOSALS_AND_REAUDIT_2026-10-16.md),
а не повторная реализация обычного поиска и выражений. Девять замечаний из конца
предыдущего отчёта исправлены. Полный повторный прогон завершён: 48 автоматических
сценариев на каждую архитектуру, всего 96 PASS. Дополнительно пройдены пять ручных
сценариев на каждой архитектуре: поиск, метаданные и колонки, применение/отмена
старого импорта, отмена экспорта и предложение сменить тему.

| Замечание | Исправление и воспроизведение |
| --- | --- |
| Частичный старый импорт | Одна SQLite-транзакция на соединении с подключённым каталогом. Три настоящих SQL-триггера отдельно прерывают запись личной карточки, группы и каталога; обе базы и номера групп откатываются, уведомлений нет. Успешный импорт публикует уведомления после commit. Пустые поля не вызывают UPDATE. |
| Создание отсутствующего каталога при поиске заметок | Проверка существования файла до открытия коллекции. После отключения собственной тестовой базы оба пути поиска оставляют её отсутствующей; JSON заметок и INI побайтно сохранены. |
| Отправка старого ZIP при коллизии | Экспорт хранит фактически выбранный путь. Shell-приёмник получает новый архив с `(1)`, его содержимое и путь результата совпадают; старый архив остаётся неизменным. |
| Ошибка конструктора ZIP | Архиватор инициализирован до создания. Настоящая ошибка создания архива сохраняет исходный объект и корректно возвращает неуспех. |
| Отмена предварительной загрузки | Признак отмены передаётся активному HTTP-загрузчику, включая POST без отображения прогресса. Проверены медленные локальные GET/POST и отмена до запуска; частичный результат не публикуется. Дополнительно устранён пропуск завершения рабочего потока при ранней отмене. |
| Отмена старого конвертера | Отменяемое ожидание процесса и Windows job завершают также дочерние процессы. Проверено настоящее дерево из двух процессов; выход ERROR_CANCELLED, оба процесса завершены. |
| Поиск по одной заметке за запрос | Пакеты по 128 идентичностей вместо отдельных поисков. 10 000 заметок, включая неверные ID, кавычки и отсутствующие названия, дают ровно ожидаемую книгу. Измерены все SQL-операции, включая агрегированную строку профиля. |
| Медленная панель книги | Однократный сброс выделения аннотации, отложенная установка текста после окончательного размера, ограниченные кэши измерений и стабильная ширина коротких ссылок. Строгий предел 5000 мс на 100 переключений сохранён. |
| Медленное масштабирование Main | Синхронизация высоты шести панелей отложена до завершения общего масштабирования; скрытые вкладки измеряются при показе. Проверены фактические Font.PPI и высоты всех шести панелей при 96/144/192 PPI. |

Дополнительно исправлены два чтения за границей строки при разборе неполного
тега ссылки. Нативная проверка включает неполную разметку и Unicode.

Полный повторный прогон выявил несовместимость нового внешнего импорта с
внутренним переносом групп при объединении коллекций. Внутренний перенос
теперь использует уже открытые транзакции объединения. При проверке остальных
вызовов также выделено восстановление личных полей внутри полного обновления
каталога: оно работает на его текущем соединении; системные карточки и группы
сохраняются до последующего переназначения BookID после commit. Для этого пути
добавлена проверка отката с SQL-триггером, запрещающим преждевременное изменение
системных карточек. После этих изменений целевые проверки повторены успешно
на x86/x64; свежие GenreRegistryTest и MetabibImportTest также прошли, включая
настоящий полный переимпорт INPX и его откат.

## Завершённые целевые прогоны

Артефакты: `G:/HomeLibRu-refactor-pre5.22-2026-10-16`; `runs.json` хранит SHA-256
каждого фактического EXE и журнала, в том числе неудачных промежуточных прогонов.
Копии окончательных тестовых EXE находятся в `validated-tests-v2/Win32` и
`validated-tests-v2/Win64`; предыдущая пара сохранена в `validated-tests`.

Эти 96 результатов относятся к паре v2. Ручной осмотр после них обнаружил
дополнительный дефект: кнопка иллюстраций сохраняла размеры для 96 PPI при
шрифте 192 PPI. Галерея теперь измеряет фактический шрифт кнопки и пересчитывает
размеры после его изменения. Отдельная пара v3 прошла ещё 12 автоматических
проверок: галерея, панель книги, общий аудит исправлений, подписи фильтров,
состояния панели инструментов и сведения о книге — на обеих архитектурах.
Повторный ручной осмотр основного окна при 96/192 PPI в обеих темах также
завершён на x86/x64. Кнопка иллюстраций масштабируется до 56 пикселей при
192 PPI, текст помещается; нижняя кнопка сведений остаётся доступной.
EXE и журналы v3 сохранены отдельно; точные хеши всех результатов есть в
[JSON проверки](REFACTOR_VALIDATION_2026-10-16.json).

## Границы проверки

Собственные временные каталоги и HTTP/Shell-приёмники находятся на G. Личные базы,
рабочая установка Desktop и защищённые исходники соседнего checkout не менялись.
Проверка Shell-приёмника не заменяет испытание физического MTP-устройства. Искусственные
VCL PPI не заменяют переход между физическими мониторами. SQL-откат проверен при
ошибках записи; устойчивость общей транзакции двух WAL-файлов к отключению питания
этим набором не доказывается.
