# Проверки кандидата HomeLibre 3.0 beta 3

Кандидат ещё не опубликован. Версия EXE — `3.0.0.3`, обозначение выпуска —
`3.0.0_pre1.3`. Каталогизатор и Reader для x86/x64 пересобраны в Release
через лицензированную Delphi Community Edition после исправления отмены
сохранения; исходный коммит — `d547b08d`.

## Проверки текущих пакетов

- Состав и контрольные суммы всех файлов архивов каталогизатора проверены
  на обеих архитектурах. Проверены версии программы и установщика, архитектура,
  справка, сгруппированные списки жанров и метаданные компонентов.
- Минимальные архивы каталогизатора не содержат Reader, MCP, Zstandard,
  обработчиков DOC/DjVu/PDF, Python и других необязательных модулей.
- Текущие архивы Reader и девять других отдельных компонентов установлены
  штатным кодом установщика на x86/x64 в изолированные копии каталогизатора.
  Проверены все файлы по манифестам, сохранность личных данных, отсутствие
  посторонних обработчиков при установке базовых модулей и сохранение срока
  фактического использования при повторной установке.
- Нативный обработчик будущего списка компонентов принял 18 пар версий и
  ссылок для каждой архитектуры. Это локальная проверка подготовленного списка,
  а не подтверждение публичного скачивания ещё не опубликованных архивов.

Автономный пакет Reader пока содержит настоящую `libzstd.dll` и её лицензию:
этот файл требует прежний установщик компонентов. Переход к отдельной докачке
этой библиотеки остаётся незавершённым. Архивы каталогизатора её не содержат.

## Проверки обработки книг

- Автоматизированные проверки реального окна сохранения и рабочего потока
  прошли на x86/x64: успешное преобразование PDF в FB2, остановка кнопкой
  «Отмена» и закрытием окна без второго подтверждения. При отмене неполный
  результат не появляется, исходный PDF сохраняется без изменения.
- На обеих архитектурах проверены успешные, ошибочные и отменённые оценка
  размера и экспорт книг из архивов. Рабочие файлы удаляются, исходные книги
  и архивы не меняются. Проверены диагностический отчёт и версии установленных модулей;
  тестовые ключи, параметры URL и текст книги не попали в журнал.
- До последней пересборки проверены сохранение исходных FB2/EPUB/PDF/DjVu/DOC,
  смешанное преобразование в EPUB, оценка четырёх режимов изображений,
  совпадения имён и сохранность исходников. Проверки больших иллюстрированных
  FB2, выделения и копирования текста, шрифтов и эмодзи также сохранены
  в журнале работ. Эти результаты относятся к указанным в нём предыдущим
  EXE и архивам, а не подменяют проверки текущих пакетов.

В текущем архиве Reader x86 пользователь остановил оценку иллюстрированной
книги. Окно показало «Оценка остановлена»; исходный файл не изменился,
копия не появилась, процесс конвертера и его рабочие папки удалены.
В отдельном прогоне с 24 сканами сохранение успело завершиться: копия
записалась без ошибок, поэтому этот прогон не подтверждает отмену записи.
Оба прогона зафиксированы как частичные, тестовые папки удалены.

## Осталось перед публикацией

- [ ] Дополнить автоматические проверки отмены x86/x64 проверкой готовых
  архивов Reader. Остановка оценки x86 подтверждена; для отмены записи
  нужен прогон, в котором нажатие происходит до завершения записи.
- [ ] Проверить установку из окна программы и восстановление окон на новых
  пакетах. Штатный установщик обновил точные публичные архивы beta 2 до
  подготовленных архивов beta 3 на x86 и x64. В обоих случаях сверены 240
  файлов, семь записей тестового каталога и личные настройки. Графический
  прогон x86 закончился по тайм-ауту. Успешные проверки запуска установки
  из окна программы и перезапусков Reader относятся к предыдущим архивам.
- [ ] Подтвердить публичную докачку только нужных модулей, установку и возврат
  к сохранению выбранной книги с её параметрами.
- [ ] Опубликовать минимальные архивы x86/x64, проверить доступные файлы и
  контрольные суммы; затем применить подготовленные ссылки в четырёх README.

На текущей публичной beta 2 проверены получение метаданных GitHub, скачивание
и подготовка обоих архивов рабочим кодом программы. Проверочный скрипт теперь
принимает явно заданный тег, папку архивов, файл контрольных сумм и план
публикации компонентов. Такой же сетевой прогон для beta 3 возможен после
публикации её файлов.

Пользователь возобновил управление экраном после игры. Работа идёт
на отдельных тестовых профилях.

## Ограничения и журнал

Физическое устройство Kindle и реальное MTP-устройство в этих проверках
не использовались. Для PDF/DjVu без текстового слоя страницы сохраняются
изображениями; OCR не добавлен. Точные замеры быстродействия без фоновой
нагрузки не выполнялись.
Обработчик сжатия изображений ограничивает входную картинку 16 777 216
пикселями. Для тестовых сканов 4000 × 6000 он отказал в оценке; в сообщении
осталось техническое название XPS. Копия со сканами 3200 × 4800 сохранена.

Сжатие коллекций, SQL-дампы, дополнительные выходные форматы через fb2cng
и дальнейшие согласованные улучшения остаются отдельными пунктами цели.
Этот кандидат не означает завершения всей цели.

Подробные протоколы и контрольные суммы проверок указаны в
[журнале работ](WORK_PRE538.json), разделы `save_cancellation_20261103`,
`game_backend_preparation_20261103` и `current_catalogue_upgrade_20261103`.
Новые папки завершённых проверок удалены. Часть старых папок, для которых
очистка ранее была отклонена, остаётся
перечисленной в журнале и повторно не удаляется.
