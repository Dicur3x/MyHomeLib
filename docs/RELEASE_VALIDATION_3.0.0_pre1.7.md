# Проверки HomeLibre 3.0 beta 7

Тег выпуска `3.0.0_pre1.7`, версия файлов Windows `3.0.0.7`.

| Windows | Архив | SHA-256 |
| --- | --- | --- |
| x86 | `HomeLibre.zip` | `5c4eb950149143d22c7deacbb670013ae13c618204285d3c9ad1bbb272debb30` |
| x64 | `HomeLibre_x64.zip` | `b99b940b7a97dbf5088e11f6fec1b1bdab8264de6227f101094bc1cb3c0996ee` |

- **Минимальная поставка.** Сверены архитектура и версии EXE, содержимое архивов и контрольные суммы всех 240 устанавливаемых файлов на каждой архитектуре. Читалка и необязательные декодеры поставляются отдельно.
- **Обновление каталогизатора.** Штатное окно опубликованной beta 6 установило соответствующий архив beta 7 на x86 и x64. После перезапуска сохранились семь записей тестовой коллекции, личные данные и настройки. Оба окна обновления отобразили полный текст заметок из подготовленного пакета. Прогон использовал заранее подготовленный архив. Загрузка из GitHub проверяется отдельно после публикации.
- **Обновление читалки.** Штатное окно компонентов beta 6 установило отдельный пакет beta 7 на x86 и x64. В каждой установке после перезапуска вернулись два окна на позиции 3%, включая выбранную книгу внутри ZIP. Сверены исходники, установленные файлы и удаление свободной записи кэша при выходе.
- **Список изменений.** Все девять пунктов заметок присутствуют в `Help/CHANGES.txt` обоих архивов и в данных, которые оба штатных разборщика обновлений получили из проверочной копии записи GitHub.
- **Компоненты.** Четыре пакета Reader и BookProcessing 3.0.0.7 скачаны с GitHub и проверены штатным установщиком. Список содержит по 23 компонента для каждой архитектуры. Остальные 42 записи сохранились, в том числе ImageProcessing 3.0.0.5. Проверка отклонила изменённую контрольную сумму старого списка и неполный набор архитектур.
- **Докачка из «Сохранить как».** На x86 и x64 чистая читалка beta 7 загрузила с GitHub только BookProcessing 3.0.0.7 и ImageProcessing 3.0.0.5. После установки и одного перезапуска восстановились EPUB, сбалансированный режим, папка и маска имени. Читалка рассчитала размеры четырёх вариантов и сохранила EPUB с обеими главами и иллюстрацией. Сверены 166 файлов модулей на x86 и 167 на x64. Исходный FB2 сохранился побайтово.
- **Упаковка и экспорт.** Реальные выборки PDF, DjVu и смешанных ZIP, побайтовое сравнение, сохранение после установки модулей и ограничения режимов описаны в [проверках сжатия USR](collection-packing-usr.md). Копии исходной коллекции в этих проверках использовались отдельно от рабочего профиля.
- **Запуск и выдача.** На x86 и x64 проверены появление интерфейса до окончания фоновой загрузки, восстановление настроек, построение списка на 50 000 тестовых книг и отмена SQL-запроса. Это регрессионные проверки, замеры полного пользовательского каталога относятся к отдельным прогонам.

Профили прогонов обновления, копии книг и распакованные проверочные файлы удалены.
