# Проверка HomeLib Ru pre5.31 / 2.7.0.1099

Выпуск содержит исправления после pre5.30: независимые проверки компонентов,
обычный поиск по названию, общий список любимых авторов, постоянный источник
AlReader и необязательный 7-Zip 26.05.

До повышения версии выполнены 22 проверки сценариев x86/x64 на последних
нативных сборках. Они охватывают режимы поиска, первую загрузку списка,
независимую готовность компонентов, ошибки источников, отмену и закрытие окна,
пересоздание оконного дескриптора, первую установку библиотек без распаковщика,
восстановление минимального комплекта, сохранность личных файлов, любимых
авторов и быстрый отложенный запуск с ранним закрытием.
Оба готовых основных EXE дополнительно открыты с отдельным синтетическим
профилем: поиск дал три ожидаемые книги, приложения закрылись с кодом 0,
временные профили и распакованные исходные комплекты удалены.
Подробности: [итоговый нативный аудит](audits/2026-10-22-post530-final-native.json).

На реальной объединённой коллекции из 1 856 990 записей выполнены только
защищённые от записи SQL-замеры. Все результаты и метаданные до/после,
а также между x86/x64 совпали. Медианное время SQL-поиска по названию
«привет» с фильтром удалённых записей изменилось с 1,966 до 0,447 с на x86
и с 1,548 до 0,381 с на x64. Без фильтра: с 1,294 до 0,431 с и с 1,001 до
0,382 с соответственно. Это повторные замеры с общим системным кэшем,
а не время всего интерфейса или холодного запуска. Первый проход x86
с ожиданием ввода-вывода не использован как доказательство ускорения.
Отчёты: [x86](audits/2026-10-22-title-search-confirmation-x86.json),
[x64](audits/2026-10-22-title-search-confirmation-x64.json).

Минимальный комплект не содержит исполняемых файлов AlReader/SumatraPDF,
декодеров DjVuLibre/DocSharp и 7-Zip. Маленькие мосты HomeLib Ru и обязательные
лицензии сохранены. Установка необязательных компонентов требует явного
действия пользователя; отсутствие компонента не включает уведомления и
не требует восстановления всей программы. Установленные компоненты и
настройки при обновлении сохраняются.

Для AlReader используется один фиксированный архив с закреплёнными размером
и SHA-256. Остальные компоненты загружаются из источников авторов.
Архивов компонентов в приложенном наборе выпуска нет.

После повышения версии основные EXE и помощники обновления пересобраны через
Delphi CE GUI для x86/x64. У ресурсов изменена только версия; остальные данные
и иконки сверены. Повторно прошли 16 проверок: режимы поиска, независимые
компоненты, любимые авторы, запуск и раннее закрытие, жизненный цикл обновлятора,
первая установка библиотек и восстановление программы из окончательных ZIP.
Оба ZIP проверены по CRC и полному манифесту. Программы из этих архивов
запущены отдельно: поиск дал три ожидаемые книги, версия в окне — 2.7.0.1099,
штатное закрытие завершилось с кодом 0. Профили, распаковки и новые временные
пакеты для проверки восстановления удалены автоматически.

Хеши EXE, архивов, журналов и результаты сохранены в
[аудите готового выпуска](audits/2026-10-22-pre531-final.json).
Пользовательская коллекция при подготовке и тестировании не изменялась
и в архивы не включена.
