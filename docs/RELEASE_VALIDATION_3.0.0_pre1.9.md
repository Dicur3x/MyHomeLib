# Проверки HomeLibre 3.0 beta 9

Тег выпуска `3.0.0_pre1.9`, версия файлов Windows `3.0.0.9`.

| Windows | Архив | SHA-256 |
| --- | --- | --- |
| x86 | `HomeLibre.zip` | `c0faee15ed829e0826291f0dc922bd1fc80b36143e7e33502425e894bfda6e2e` |
| x64 | `HomeLibre_x64.zip` | `3793be41301c35d69499699f7fd7ff6b85d92a3c1236cb2134256ac8c0e7e7c1` |

- **Каталогизатор.** Оба минимальных ZIP проверены по составу, разрядности и версии. Опубликованные x86 и x64 копии beta 8 показали список изменений и установили точные пакеты beta 9 через обычное окно. После перезапуска открылась прежняя коллекция. На каждой разрядности сверены 240 файлов поставки, семь записей каталога и личные настройки. Пакеты были подготовлены локально до запуска обновлятора.
- **Автономная читалка.** Опубликованные beta 8 x86 и x64 установили точные пакеты beta 9 через «Настройки → Компоненты». Проверены все шесть файлов пакета, перезапуск процесса и сохранение открытой книги на 3%. Пакеты не содержат дополнительные декодеры.
- **BookProcessing.** Новые пакеты установлены на чистые копии опубликованной beta 8. Сверены 162 файла на x86 и 163 на x64, личные данные и остальные модули. На каждом пакете прошли пять проверок оценки и выбора формата изображения. На книге «Привет! Это я…» расчёт по новой выборке занял около пяти секунд. Погрешность на проверенных выходах составила менее 1% для FB2 и около 4% для EPUB.
- **Удаление дополнительных копий.** На тестовых коллекциях x86 и x64 проверен выбор 5 000 копий по конкретному источнику. Полный ZIP удалён, частичный ZIP сохранил 100 соседних файлов побайтово, а 5 000 основных карточек остались в каталоге. На отдельной копии реального архива FLibrary удалены только выбранная книга, её обложка и две иллюстрации. Хеши исходных архивов совпали.
- **Скачивание после публикации.** Штатный обновлятор на x64 нашёл beta 9, скачал опубликованный ZIP и подготовил его к установке. Лента компонентов и четыре обновлённых ZIP читалки и BookProcessing прошли проверку по опубликованным ссылкам. Архив каталогизатора x86 скачан через GitHub CLI, его SHA-256 совпал с пакетом из прогона установки. Проверка скачивания x86 штатным обновлятором остаётся открытой из-за повторяющихся ответов HTTP 504. В том же интервале наблюдались отдельные ответы 504 от ссылки ленты компонентов. [Сообщение GitHub об инциденте](https://www.githubstatus.com/incidents/c9px7cw2ghrs).
- **Очистка.** Тестовые установки и профили удалены. Просмотр на физических Kindle и Kobo, повтор с активным Kaspersky и исследование сбоя завершения RAD Studio остаются отдельными проверками.
