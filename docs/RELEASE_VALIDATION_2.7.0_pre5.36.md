# Проверка HomeLib Ru pre5.36

Каталогизатор 2.7.0.1104 собран в Delphi Community Edition в конфигурации
Release для Win32 и Win64. Исправление ограничено установкой и проверкой
пакетов обновлений; незавершённые функции сжатия коллекции в выпуск не включены.

## Пакеты читалки

Проверены шесть реально опубликованных архивов: HomeLib Reader 2.7.0.1103,
BookConverter 2.7.0.1103 и PDFium 157.0.8086.0 для обеих архитектур.
У обоих пакетов Reader поле `release` было равно `2.7.0_pre5.35`, хотя
клиент получает эти архивы из постоянного выпуска
`optional-alreader-2.5.1009.25` и проверяет совпадение с ним.

Исправлено только это поле двух архивов Reader. Все остальные поля манифеста
и каждый файл содержимого побайтно сохранены. Архивы конвертера и PDFium
уже имели правильное поле и не заменялись.

Нативный сценарий `published-components` прошёл на x86 и x64:
разбор метаданных реального выпуска и описания компонентов, проверка архива,
подготовка, повторная проверка и установка каждого из трёх компонентов.
Сохранность файлов настроек, заметок и существующего приложения проверяется
после установки. Новая проверка упаковщика отклоняет тег приложения до
обращения к runtime или создания выходных файлов.

## Архивы каталогизатора

Оба окончательных ZIP прошли проверку CRC, архитектуры, всех 244 файлов
манифеста и отсутствия необязательных читателей и обработчиков форматов.
Сценарий чистой минимальной установки прошёл для обеих архитектур, включая
последующую установку необходимых адаптеров DOC и DjVu.

Установка обоих окончательных ZIP поверх соответствующих настоящих архивов
pre5.34 прошла через нативный установщик. Все файлы нового манифеста
совпали после установки; 35 файлов тестовых профилей, коллекции, книг,
избранных авторов, заметок и настроек сохранились в каждом случае.
Изолированные каталоги этих проверок удалены автоматически.

Отдельно неизменённая опубликованная pre5.34 x64 успешно скачала и
подготовила обновление только каталогизатора до pre5.35. Ошибка этого
сценария без компонента Reader не воспроизведена. Ошибочный пакет Reader
также мог прервать общую очередь обновлений; исправление опубликованных
архивов устраняет эту подтверждённую причину.
