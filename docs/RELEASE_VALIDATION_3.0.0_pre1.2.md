# Проверки HomeLibre 3.0 beta 2

Версия EXE: `3.0.0.2`. Выпуск: `3.0.0_pre1.2`.
Каталогизатор, Reader, установщик обновлений и сервер MCP собраны
в Release через лицензированную Delphi Community Edition для x86 и x64.

## Что проверено

- На исходной книге «Инженер Петра Великого» проверены открытие, иллюстрации,
  перелистывание, изменение размера шрифта и скрытие/возврат панелей.
  Изображения сохраняют исходные сжатые данные; повторного сжатия нет.
  Проверки изменения размера и панелей заняли примерно 0,3–0,5 секунды,
  включая обработку сообщений. Это локальные результаты под нагрузкой,
  а не гарантия времени для любого компьютера и любой книги.
- Исходный сбой ручного открытия окна обновлений воспроизведён проверкой
  до исправления. После исправления проверены оба варианта повторного
  открытия, отсутствие повторных рабочих потоков и видимость настоящего
  окна в рабочей области монитора на x86 и x64.
- Окончательные архивы каталогизатора прошли проверку подготовки обновления,
  допуска штатного установщика, версий, архитектуры, состава и всех хешей.
- Окончательные архивы девяти отдельных компонентов установлены штатным
  кодом установщика на обеих архитектурах. Проверены сохранность личных
  данных и отсутствие посторонних модулей.
- Проверены оба обработчика списка компонентов, отклонение неверной
  контрольной суммы и устаревшего пакета Reader.
- Две настоящие читалки на каждой архитектуре прошли согласованную замену
  EXE через штатный установщик. Восстановлены обе книги, вторая книга внутри
  ZIP и её позиция 3%; проверена очистка тестового кэша при выходе.
  Для принудительной замены исполняемого файла использована безвредная
  добавка к тестовой установленной копии. Это проверка согласования процессов,
  а не перехода между разными номерами версий.

## Границы проверки

Согласованное обновление читалок проверено на Reader-r2. В окончательном
Reader-r3 добавлены только диагностические записи окна обновлений; его
архивы отдельно прошли проверку установки и списка компонентов.

Установку нажатием кнопки в окне обновлений через Computer Use завершить
не удалось: отдельное немодальное окно недоступно этому инструменту.
Журнал настоящей программы подтверждает видимость окна в Windows.
Успешная сетевая загрузка через интерфейс старой опубликованной программы
этими проверками не утверждается.

В отдельном Reader пока сохранена `libzstd.dll`: её требует проверка
обязательных файлов в прежнем установщике компонентов. Архив каталогизатора
этой библиотеки и обработчиков дополнительных форматов не содержит.

Сжатие коллекций, импорт SQL-дампов и дальнейшие улучшения интерфейса
не входят в этот выпуск. Ошибка времени ожидания при загрузке отзывов
остаётся в очереди; повторная попытка ранее завершалась успешно.
