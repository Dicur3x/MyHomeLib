# Пограничные книги USR и частичный экспорт

Дополнительная выборка содержит 1000 файлов из 200 архивов USR. В неё вошли 125 старых офисных документов, 125 EPUB, 120 вложенных архивов, 100 CHM, 90 книг Kindle, 86 HTML, 75 RTF, 74 DOCX, 60 комиксов, 54 DjVu, 49 PDF и 42 текстовых файла. Исключены записи и побайтовые дубликаты из предыдущей выборки. При отборе учитывались редкие расширения, размеры, особенности имён, позиции внутри архивов и записи с несколькими копиями.

Чтение и преобразование проверяются отдельно через штатные обработчики HomeLibre x64 в изолированных профилях. Читалка загружает текст и показывает первый и последний кадры постраничных книг. Для экспорта выбирается формат, отличный от исходного. В полученных EPUB и FB2 проверяются открываемость структуры, порядок элементов чтения и ссылки на иллюстрации. Для нескольких изображений каждого EPUB независимо проверяется заголовок. Такая проверка не сравнивает каждую строку или пиксель с оригиналом.

После проверки сверены размеры и время изменения 214 исходных архивов, включая резервные файлы выборки.

## Исправления

1. Читалка показывает отметку на месте нечитаемой страницы или иллюстрации. Доступные страницы и соседний текст можно продолжать читать.
2. Перед сохранением частичного результата HomeLibre показывает список обнаруженных потерь по книге. Для сканов выводятся номера страниц, для иллюстраций — номера и, где они известны, имена файлов. Можно пропустить книгу и продолжить пакетный экспорт. Существующий файл назначения сохраняется. При согласии читаемая часть сохраняется с отметками и предупреждением в итогах. При отсутствии читаемых данных программа объясняет, почему сохранение невозможно.
3. DjVu повторяет чтение отдельных страниц после ошибки группы. Затронутые страницы сохраняются с текстом или изображением, если один из слоёв доступен. При повреждении обоих слоёв сохраняется отметка с исходным номером страницы. Нечитаемые страницы ZIP-комиксов также оставляют отметку на своём месте.
4. При отсутствующей сноске DOCX или цели ссылки EPUB сохраняется доступный текст. Для неподдерживаемых рисунков, диаграмм и формул DOCX доступен частичный экспорт с отметками. Для тяжёлых DOC рабочий процесс получает дополнительное время и память в пределах существующих ограничений.
5. CHM сохраняет порядок разделов и локальные переходы. Некоторые повреждённые ресурсы можно пропустить после подтверждения. Общие упакованные данные распаковываются в частную временную папку, чтобы не читать весь блок заново для каждой иллюстрации.
6. Для RTF распознаётся нулевой байт после конца документа. Нечитаемые символы в RTF и HTML отмечаются в тексте. При создании большого EPUB текст распределяется по нескольким XHTML-файлам. Порядок чтения и переходы между ними сохраняются.
7. В двух MOBI цитаты внутри заголовков теперь сохраняются в FB2 сразу после соответствующей части заголовка. Для CBZ с файлом контрольных сумм SFV проверен экспорт всех 23 страниц.

## Проверка частичного экспорта

- На x86 и x64 проверен экспорт реального ODT с пятью недоступными иллюстрациями. Диалог получает все пять номеров и имена ресурсов. Отказ оставляет существующий файл назначения побайтно прежним. Согласие сохраняет EPUB с текстом и отметками.
- Для DjVu с повреждённой страницей 4 независимо подтверждены все 510 номеров. Страница 4 отмечена, остальные 509 сохранены. Для другого DjVu сохранены доступные страницы 1–520 и отметки для страниц 521–872. На странице 520 доступное изображение заменяет нечитаемый текстовый слой. В обоих EPUB проверено отсутствие пропусков нумерации.
- В комиксе с пустым вложением и обрезанным PNG сохранены доступные страницы 1 и 4. Отметки на страницах 2 и 3 совпадают с номерами в сообщении перед сохранением.
