# HomeLibre после 3.0 beta 7

Изменения отдельного аудита относительно `3455d96a`, где зафиксирован опубликованный выпуск beta 7. Это список изменений рабочего дерева для следующей поставки.

## Сжатие коллекций и архивы

- Упаковка USR принимает необычные расширения, например `.3-pdf`, и имена без расширения. Если имя нельзя безопасно создать на диске Windows, упаковщик может перенести исходный архив целиком с точным именем записи внутри.
- Дополнительные копии одной книги включаются в упаковку по имени файла, даже если поле расширения пустое или отсутствует. После упаковки каждая доступная копия указывает на файл внутри новой коллекции.
- Для небольших отдельных файлов сохраняется исходный файл, если архив получился бы больше. Уже сжатые элементы учитываются при выборе метода упаковки, а неудачная перекомпрессия не заменяет более компактный источник.
- Нулевой элемент архива считается недоступной книгой. Её карточка и исходное расположение сохраняются, чтобы после восстановления файла повторить упаковку. Экспорт такого элемента сообщает о проблеме и не создаёт пустую книгу.
- Чтение точнее сопоставляет полные пути внутри архива, учитывая регистр, разделители и конечные точки или пробелы. Для старых записей FLibrary, где импорт обрезал часть имени, требуется совпадение исходной позиции и однозначное совпадение имени.
- EPUB из FLibrary восстанавливает все пути к иллюстрациям, включая несколько ссылок на одну картинку. В манифесте EPUB указывается фактический формат восстановленного изображения. Старая неполная копия в кэше пересоздаётся.

Гарантия относится к размеру полезных данных, для которых можно сравнить новый архив с исходным архивом или отдельным файлом. Итоговая папка отдельной коллекции включает каталог, журнал и служебные файлы. Повторная упаковка может сохранять прежние поколения, на которые ещё ссылаются каталоги. Выигрыш зависит от исходных форматов и режима. Обратимые режимы проверяются по байтам, а режимы с изменением изображений могут менять внешний вид.

## Каталог, поиск и импорт

- Поиск и карточка книги остаются доступными, если у жанра отсутствует родитель или ссылки между жанрами образуют цикл. У книги сохраняется её жанр, а верхний раздел считается неизвестным. То же правило применяется при определении раздела для импорта FB2.
- Импорт распознаёт EPUB по содержимому, когда файл ошибочно назван `.fb2`. Проверены отдельные файлы, пакеты, архивы и импорт через Проводник.
- Файл контрольных сумм `.md5` больше не открывается и не преобразуется как текст книги. Если под этим расширением лежит обычный текст, он по-прежнему открывается и преобразуется.
- Для небольших FB2 программа может исправить однозначные ошибки разметки во временной копии при импорте, чтении или преобразовании. Например, экранировать одиночный амперсанд, убрать лишний закрывающий тег заголовка или добавить отсутствующее объявление `xlink`. Оборванные документы и повреждённые нулевыми байтами книги получают отдельное сообщение. Текст, которого в исходном файле уже нет, восстановить таким способом невозможно.

## Чтение, сохранение и преобразование

- Стрелки работают в читалке, даже когда фокус остался в другом элементе окна. Плавная прокрутка сохраняет движение при переходе между страницами в обе стороны. В постраничном режиме колёсико по-прежнему перелистывает страницы.
- Поддерживаемые TIFF открываются напрямую через декодер Windows. Страницы читаются по мере просмотра. Для TIFF, которые этот декодер не открывает, сохранён прежний способ подготовки.
- При обработке большого PDF программа запрашивает нужные блоки файла, а изображения сканов обрабатывает небольшими порциями. При сохранении книги из архива выбор формата уточняется по выбранному вложению и его содержимому.
- Если растр скана уже состоит из оттенков серого, PNG хранит один канал вместо трёх одинаковых. Пиксели и разрешение сохраняются. Конвертер проверяет структуру готового FB2 по частям и пропускает в этой проверке уже записанные изображения. При открытии большого FB2 декодированное изображение заменяет его текстовое представление в памяти.
- Для крупных RTF до 256 МиБ HomeLibre использует обновлённый модуль обработки книг. Для чтения создаётся временный EPUB. Конвертер сохраняет основные изображения Word, пропускает дублирующие изображения и исключает служебные стили из текста. Отдельные старые изображения WMF обрабатываются через DocSharp. Обычные RTF по-прежнему открываются напрямую.
- В «Сохранить как» добавлены «Максимальная экономия» и отдельный переключатель «Оттенки серого» для растровых изображений. Выбор учитывается в оценке размера, обработке разворотов и продолжении после установки модуля. Режимы зависят от формата назначения. Для непрозрачных исходных форматов копирование остаётся доступно, а возможности обработки показываются после выбора подходящего формата.
- Оценка размера ограничивает время работы с каждой книгой. На больших PDF со сканами она измеряет выборку из разных частей книги и показывает диапазон и процент разброса. Диапазон расширяется, если страницы в выборке заметно отличаются. Результат может выйти за пределы диапазона, а при недостаточной выборке предел погрешности неизвестен.
- Преобразование EPUB в FB2 один раз составляет список ресурсов изображений. Это сокращает повторную работу при обработке книг с большим числом иллюстраций, в том числе RGO после подготовки в EPUB.
- При преобразовании FB3 сохраняются переносы строк. Старые HTML-страницы с пропущенными закрывающими тегами списка обрабатываются без ложной ошибки о глубине вложения. Внешние изображения размером 1 × 1 без подписи пропускаются с примечанием. Книги USR 740323 и 754524 открылись, сохранились в FB2 и EPUB и прошли повторное чтение на x86 и x64.
- В «Сохранить как» есть отдельная настройка «Пропускать повреждённые изображения». Она выключена по умолчанию. Для проверяемого случая, когда FB2 обрывается внутри изображения после целого текста, копия сохраняет текст и остальные иллюстрации, а на месте пропуска появляется пометка. Если обрывается обложка, пометка появляется в начале книги. Итог экспорта показывает примечание и путь к `export_report.log`. При повреждении текста копия не создаётся.
- При преобразовании EPUB в MOBI и AZW3 повторная страница обложки исключается из порядка чтения, когда она действительно дублирует обложку и на неё нет ссылок из текста. Начало чтения указывает на следующую страницу, а при ошибке Kindling показывает её даже в длинном отчёте с предупреждениями.

## Обновление программы и компонентов

- После прерванной установки откат удаляет временный файл текущей операции и восстанавливает предыдущие файлы. Повторный запуск уже завершённого отката сохраняет более свежую установку.
- Одну папку может менять только одна операция установки или отката. Вторая попытка получает сообщение и может быть повторена после завершения первой. Для разных папок операции независимы.
- «Повторить проверку» заново проверяет выбранный компонент, у которого был сбой. Результаты проверки остальных компонентов сохраняются. Сбой фоновой проверки остаётся в диагностике и не прерывает работу всплывающим окном.
