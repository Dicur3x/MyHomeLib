# Проверки HomeLib Ru pre5.17 / 2.7.0.1085

Основная программа, обработчик обновлений и нативные тесты собраны в RAD Studio
для Win32 и Win64. Все операции установки проверялись в отдельных каталогах на G.

## Поставка

В выпуске только два полных ZIP и SHA256.txt. Компоненты уже находятся внутри.
Win32: 50 788 981 байт; Win64: 56 191 136 байт. Проверены CRC, точный состав,
размеры и SHA256 каждого из 414/423 файлов манифеста, отсутствие личных баз.
В обоих архивах 16 файлов шрифтов четырёх семейств, лицензии и манифест.
Из прежней поставки убрано 82 072 527 сжатых байт дополнительных шрифтов.

## Проверки

- 13 сценариев официальных компонентов в каждой разрядности: адрес автора,
  согласованная пара DocSharp, реальная DOC с точным сопоставлением XML,
  несовместимая разрядность, проверка DjVu, ошибка установки и восстановление,
  сохранность восьми файлов профиля, манифест и кэш дополнительных шрифтов.
- Реальный поток скачивания двух пакетов DocSharp через рабочий обновлятор:
  обе контрольные суммы совпали с проверенными пакетами автора. Установка,
  неправильный размер второго пакета и отмена проверены отдельно в обеих
  разрядностях; книги, настройки, заметки и история сохранились побайтно.
- Окно обновлений: официальные адреса, автоматическая установка, вкладка
  изменений, светлая/тёмная темы и масштабы 100/150/200%.
- Установка полных ZIP поверх pre5.16: все файлы поставки проверены;
  по 105 прежних файлов вне манифеста сохранены побайтно. В это число входят
  старые дополнительные шрифты, которые общий установщик не удаляет.
- Дополнительные шрифты: обычный текст RU/EN/UK/BE не вызывает предложения;
  установленный в Windows шрифт тоже. Недостающая бенгальская письменность
  вызывает предложение с размером; «Позже» не скачивает; «Скачать» применяет
  полный проверенный комплект без изменения текста и места чтения.
- Читалка: фактическая геометрия выделения, продолжение абзаца, точное
  копирование, оглавление, поиск, цвета, буквицы, EPUB CSS, заметки и экспорт
  повторно проверены в обеих разрядностях. Повреждённые открытия убирают свои окна.

Официальные проверки версий подтвердили SQLite, SumatraPDF, DjVuLibre,
7-Zip и DocSharp. На сайте AlReader не удалось подтвердить доступный выпуск
для Windows; программа сообщает это и сохраняет установленную читалку.
Масштабирование моделировалось в интерфейсе, это не проверка другого монитора.

## Отдельный откат

1. **Шрифты по необходимости:** unit_ReaderFontDownloads, ReaderFonts,
   ReaderFontFallback, предложение в frm_BuiltinReader и фильтр шрифтов в
   package-release. Книги и заметки не изменяются; загруженные шрифты — кэш.
2. **Официальные обновления:** ComponentUpdates, ProgramUpdates,
   ProgramUpdateInstaller, frm_ProgramUpdate и проверки обработчиков DOC/DjVu.
   Установщик делает резервную копию заменяемых файлов и восстанавливает её
   при ошибке. Не восстанавливайте устаревшую пользовательскую базу ради отката EXE.
3. **Правила публикации:** package-components остановлен; package-component
   разрешён только с явным TestFixture для старых тестов. Публикуются полные ZIP.

Конвертация FB2 ↔ EPUB не входит в этот выпуск: это следующий этап разработки.
