# Проверка pre5.22 / 2.7.0.1090

Основная программа и комплектный помощник обновления собраны через Delphi IDE
для x86/x64. Сервер и проверка установки также пересобраны для обеих архитектур.
Метаданные основной программы: 2.7.0.1090 / pre5.22, Common Controls 6,
PerMonitorV2; архитектура EXE и комплектных DLL проверена упаковщиком.

## Результаты

- Полный повторный набор: 96 автоматических сценариев, 48 на архитектуру — PASS.
- После дополнительной правки масштаба галереи: ещё 12 автоматических сценариев — PASS.
- Ручные сценарии: пять на архитектуру и повторный осмотр галереи/основного окна
  в светлой и тёмной теме при 96/192 PPI — всего 12 завершённых осмотров.
- Оба настоящих ZIP установлены поверх полных официальных архивов pre5.21 в
  отдельных временных папках. Проверены CRC ZIP и SHA-256 всех файлов
  манифеста (529 в x86, 538 в x64); 19 файлов библиотек и профилей сохранены побайтно, включая заметки,
  избранное, черновик, положение чтения и настройки читалок.
- Комплектные PDF/DOC/DjVu/Kindle/Office, шрифты, конвертер и справка прошли
  проверки закреплённых версий, состава и контрольных сумм. В ZIP нет Data/Presets.
- Упакованные HomeLibRu.exe обеих архитектур отдельно запущены с собственной
  библиотекой из шести книг: главное окно, авторы, список книг и сведения
  отображаются, строка состояния показывает 2.7.0.1090. Оба приложения штатно закрыты.
