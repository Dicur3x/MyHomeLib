# Проверки HomeLibre 3.0 beta 10

Тег выпуска `3.0.0_pre1.10`, версия файлов Windows `3.0.0.10`.

| Сценарий | Что проверено |
| --- | --- |
| Карточка книги | Описание использует свободную ширину при свёрнутой галерее. Развёрнутая галерея размещается справа и показывает более крупные иллюстрации. |
| Значки панели | На пользовательском скриншоте обнаружен светлый набор на тёмном фоне. Проверка воспроизвела рассинхронизацию при смене темы. Исправление проверено на x86 и x64 по фактически отрисованным пикселям при 96, 144 и 192 DPI. Недоступная кнопка остаётся различимой. |
| Последний INPX | После обновления доступны именно новые записи. Повтор без новых книг даёт пустую выдачу. Отмена и ошибка сохраняют предыдущий список. Проверено штатное обновление и дозапаковка. В локальной Flibusta для обновления до `20261101` сверены 3 138 новых записей по исходному INPX и каталогу. |
| Серии | Распознаются варианты записи скобок и знаков препинания. Для «Аллоды (АСТ)» проверены издатель и общая книга. Похожее название без подтверждения остаётся отдельным. |
| Дубли | Порядок известных источников работает для двух и трёх копий. Проверены ручные отметки, конфликты личных данных и фильтр неотмеченных групп. На каждой архитектуре подготовлена выборка из 100 003 копий в 22 партии. Физическое удаление проверено отдельно на меньших тестовых архивах с побайтовой сверкой соседних книг. |
| Фоновое удаление | На x86 и x64 проверен обычный сценарий из «Групп». При удалении книги из другой коллекции отмеченная книга в текущем списке остаётся отмеченной. При возврате в «Группы» удалённая карточка исчезает. Соседний файл в ZIP сохраняется побайтово. |
| Сноски и поиск | Подсказки проверены при листании и прокрутке. Нижние сноски переключаются независимо, закрытие поиска очищает подсветку, процент виден в обоих режимах. |
| Засечки | Оглавление с более чем сотней глав проверено на x86 и x64. У отметок есть минимальный интервал, при совпадении приоритет у частей. Глубокие подглавы доступны в оглавлении. Проверен пользовательский цвет полосы. |
| «Вид» | На FB2 «Инженер Петра Великого» с 340 иллюстрациями первое открытие окна заняло 0,97 с на x86 и 0,87 с на x64. Повторное открытие заняло около 0,4 с на обеих архитектурах. В одном сопоставимом прогоне прежней рабочей сборки x64 первое открытие заняло 2,74 с. Замеры относятся к этому компьютеру и файлу. |
| Плавная прокрутка | Проверены движение вниз и вверх на реальной FB2, стыки длинных изображений в CBZ, PDF, DjVu и TIFF, а также EPUB, TXT и RTF. Обычное листание колесом сохранено. |
| Ручная проверка обновлений | Закрытое окно не всплывает после получения результата. Повторное открытие показывает найденную версию. Отдельно штатным загрузчиком скачаны и сверены уже опубликованные ZIP beta 9 на x86 и x64. |
| Версии в обновляторе | HomeLibre показывает «3.0 beta 10», сторонний SQLite сохраняет собственный номер, например `3.53.0`. На x86 и x64 проверены порядок beta 9 и beta 10, версии компонентов, окно обновления при 96, 144 и 192 DPI и ошибки источника обновлений. |
| Подготовка и сохранение | По 19 проверок с поставляемым Python каждой разрядности. В том числе FB2 и EPUB без изображений, одинаковый выбор кодирования при оценке и сохранении, PDF через PDFium и раздельность модулей. |

Подготовка партии из 100 003 дублей проверена на тестовом каталоге. Физическое удаление проверено на отдельных тестовых архивах. Книги пользователя использовались для замеров и сверки данных, без изменений исходной коллекции. Экспорт на физических устройствах Kindle и Kobo и поведение Kaspersky требуют отдельной проверки на соответствующих устройствах и в этой среде.

Каталогизатор beta 9 на x86 и x64 установил подготовленное обновление через обычное окно, показал список изменений и перезапустился. В каждом прогоне сверены 240 установленных файлов, семь книг тестовой коллекции, личные данные и настройки. Дополнительно проверены занятая `sqlite3.dll` с совпадающим и отличающимся содержимым, а также откат при сбое установки.

Отдельная читалка beta 9 на x86 и x64 установила подготовленный пакет из «Настройки → Компоненты». После перезапуска открылась та же книга на 3%. Контрольные суммы файлов пакета и исходных книг совпали. Временные установки удалены.

## После публикации

Штатный загрузчик HomeLibre скачал и подготовил оба опубликованных ZIP каталогизатора. Оба пакета читалки скачаны по HTTPS и прошли проверку контрольных сумм и штатную подготовку. Парсер каждой разрядности прочитал 23 записи публичной ленты компонентов. Временные загрузки удалены.
