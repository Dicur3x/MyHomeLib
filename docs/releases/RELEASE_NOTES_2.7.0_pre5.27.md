# HomeLib Ru pre5.27 — 2.7.0.1095

- Главное окно появляется до загрузки каталога. Списки авторов, серий и начальная подборка книг подготавливаются в фоне; сохранённая книга, вкладка и язык восстанавливаются после загрузки.
- Убрано предварительное чтение всех названий источников книг. Нужные значения выбираются вместе с отображаемыми книгами, включая объединённые коллекции и поиск.
- Ускорено получение списка авторов при полном фильтре: проверка наличия подходящих книг больше не разворачивает все библиографии.
- Во время начальной загрузки недоступны действия, которым нужен готовый каталог. Закрытие окна отменяет фоновую работу, в том числе ожидание блокировки SQLite; исправлена обработка команд при ещё не открытой коллекции.
- Подготовка скрытого окна выбора жанров отложена до появления главного окна. Сокращены повторные выравнивания панелей при запуске.

На проверенной копии каталога из 1,86 млн книг главное окно появлялось за 2,6–2,8 с вместо примерно 7 с. Это внутренние диагностические замеры на одной машине; проверка Windows до входа в программу и холодный дисковый кэш в них не измерялись. При размещении готовых списков возможны короткие паузы интерфейса.
