# HomeLib Ru pre5.35 — 2.7.0.1103

Исправлены сохранение книг, состав минимальных архивов, запуск читалки и
обновление из старых версий. Переработано окно «Сохранить как…» для одной
книги и наборов книг разных форматов.

Скачивание: `HomeLibRu.zip` для x86 или `HomeLibRu_x64.zip` для x64.
Читалка и дополнительные модули устанавливаются по необходимости.
Автономная HomeLib Reader доступна в
[постоянном выпуске компонентов](https://github.com/Dicur3x/MyHomeLib/releases/tag/optional-alreader-2.5.1009.25).

## Сохранить как

- Исправлена ошибка «нужен модуль конвертации» при обычном сохранении FB2
  или EPUB. Если выбраны исходный формат и изображения «Как есть», программа
  копирует книгу без повторного преобразования. Это относится и к PDF, DjVu,
  DOC и другим исходным форматам.
- Для преобразования в списке оставлены FB2 и EPUB. Если выбрана одна FB2
  или несколько FB2, отдельного преобразования в FB2 нет; аналогично для EPUB.
  Упаковка каждой сохранённой книги в ZIP выбирается отдельно и не требует 7-Zip.
- Для набора разных форматов можно сохранить каждую книгу как есть, привести
  все книги к FB2 или EPUB либо оставить имеющиеся FB2/EPUB, преобразовав
  только остальные книги в выбранный формат.
- Изображения имеют четыре режима: «Как есть», «Сбалансированный»,
  «Экономный» и «Без изображений». Обработка изображений в исходном формате
  доступна для FB2 и EPUB; для других форматов нужно выбрать преобразование.
  Настройки разделения сканированных разворотов сохраняются.
- Размер обычной копии показывается сразу. Кнопка «Оценить размер»
  оценивает результат для всех четырёх режимов изображений. Для нескольких
  книг видны размеры по каждой книге и общий итог. Расчёт показывает ход
  работы и допускает отмену; ошибки и недоступные оценки обозначаются явно.
  Это приблизительные размеры: итог может отличаться.
- Для крупных результатов появляется предложение уменьшить изображения.
  Качество меняется только по выбору пользователя.
- Маска имени теперь редактируется прямо в этом окне, рядом показан пример
  пути сохранения. Можно складывать книги в одну папку или задавать подпапки
  своей маской. Последняя принятая папка и настройки запоминаются.
- Если для операции нужен модуль, небольшое окно объясняет его назначение
  и показывает размер загрузки. Например, DocSharp нужен для чтения исходного
  DOC, PDFium — для PDF; общий модуль преобразования создаёт FB2/EPUB
  и обрабатывает изображения. После установки и необходимого перезапуска
  восстанавливается окно с параметрами оставшейся операции.

## Читалка

- При открытии выбранной книги из каталогизатора сразу появляется книга;
  промежуточное стартовое окно скрыто. При отдельном запуске читалки без книги
  окно открытия остаётся доступным.
- Каталогизатор и автономная читалка портативны по умолчанию: данные хранятся
  рядом с программой в `Data`, файл `uselocaldata` не нужен. Явно переданная
  папка профиля имеет приоритет. Старые данные из AppData автоматически
  не переносятся — при переходе на новую папку их нужно перенести отдельно.
- Кнопка «Скрыть интерфейс» убирает панели и меню во время чтения.
  Размер окна при этом не меняется: можно читать и в небольшом окне.
  Вернуть их можно небольшой кнопкой у верхнего края или клавишей Escape.
  Это работает также при просмотре PDF, DjVu, изображений и интерактивных книг.
- Полный экран включается отдельно небольшой кнопкой ⛶ или клавишей F11.
  Эти режимы можно сочетать: возврат панелей не выводит из полного экрана,
  а возврат к обычному окну не включает скрытые панели.
- В оформлении «Объёмная книга» добавлены обложка, сгиб у корешка и боковые
  блоки страниц. Их толщина меняется вместе с положением в книге.
  Оформление доступно для одной страницы и разворота, во всех темах.

## Компоненты и обновление

- Из минимальных архивов каталогизатора и читалки удалены папки DOC и DjVu.
  Соответствующие обработчики загружаются вместе с нужными модулями при
  первом обращении к книге этого формата. Ранее установленные модули сохраняются.
- Исправлена ошибка «Недопустимое приложение для обновления» при обновлении
  из старых выпусков, передававших запрос без имени программы. Разный регистр
  букв в штатных именах EXE тоже больше не мешает установке.
- При восстановлении копии каталога сохраняются сведения о подключении
  коллекции, включая адрес, сценарий загрузки и примечания.
- Исправлена отметка постоянного выпуска компонентов на GitHub, из-за которой
  не проходила проверка WebP 1.6.0. Исправление доступно и старым версиям
  программы. Постоянные пакеты WebP и JPEG XL для x86/x64 остаются в одном
  выпуске компонентов и не дублируются в каждом выпуске программы.
