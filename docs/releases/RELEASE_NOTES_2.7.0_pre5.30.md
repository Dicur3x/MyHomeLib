# HomeLib Ru pre5.30 — 2.7.0.1098

Изменения после pre5.29: повторы книг, объединение серий, резервные копии,
необязательные компоненты и исправления интерфейса.

- Добавлен поиск повторных записей книг после объединения коллекций. Сравниваются
  ID исходной библиотеки, язык и формат; одинаковый номер в разных библиотеках
  не считается совпадением. Можно сравнить копии, выбрать основную запись и явно
  отметить книги для объединения. Отметки сами по себе ничего не меняют.
- При объединении сохраняются пути ко всем физическим копиям, связи с источниками,
  авторами, жанрами и обеими разновидностями серий. Файлы книг не удаляются.
  Записи с личными данными и историей чтения защищены. Перед изменением создаётся
  резервная копия; устаревший предпросмотр отвергается, ошибка или отмена откатывает
  изменения. Большой список кандидатов показывается страницами по 50 книг.
- Окно повторов получило последовательные шаги, пояснение звёздочки основной
  записи, источники файлов, авторов и размеры в КБ. Явно показано, сколько книг
  отмечено для итогового объединения.
  Оно открывается кнопкой «Объединить повторы книг» в окне «Источники и объединение
  коллекции», рядом с объединением серий.
- Улучшено объединение вариантов названий серий с пометками `[a]`, `[p]`, `[m]`
  и межавторских циклов. Для спорных издательских и межавторских вариантов
  проверяются общие книги, авторы, библиотека, язык и формат. Значимые авторские
  уточнения сохраняются. Объединение названий серий не удаляет записи книг.
- Добавлено восстановление коллекции из резервной копии с предварительной
  проверкой и отменой. Копия восстанавливается и открывается в этой же программе
  как отдельная коллекция; прежняя остаётся доступной в меню «Коллекция».
  Личные карточки и группы восстанавливаются отдельно от текущего состояния.
- В списке копий видны дата, время и операция. Для старых копий время берётся из
  стандартного имени папки с соответствующей пометкой. Список обновляется с диска;
  исчезнувшие папки убираются, неполные копии явно обозначаются. Можно выбрать
  несколько копий и удалить их после просмотра полных путей и общего размера.
  По умолчанию в подтверждении выбрана отмена.
- При объединении каталогов резервирование больше не дублирует неизменяемые
  каталоги-источники: сохраняются изменяемый каталог и личное хранилище.
- Окно статистики появляется до подсчёта: статистика загружается в фоне,
  предыдущий запрос отменяется при смене коллекции или закрытии. Длинные пути
  и пояснения доступны полностью.
- Исправлены чёрные прямоугольники вместо иллюстраций с прозрачностью, в том
  числе палитровых PNG и JPEG XL. Исправлен пробел между номером и названием
  главы в оглавлении встроенной читалки.
- Во встроенной читалке добавлены режимы «Одна страница», «Две страницы» и
  «Автоматически по ширине» для всех поддерживаемых форматов, включая PDF,
  DjVu, TIFF и комиксы. Разворот перелистывается парами по умолчанию; можно
  выбрать сдвиг на одну страницу. Настройки сохраняются, позиция чтения
  остаётся на месте при смене режима. Большие растровые страницы готовятся
  в фоне с ограничением памяти для одновременного показа двух страниц.
- Добавлено оформление «Объёмная книга» с мягкими тенями, краями бумаги и
  затемнением у корешка. В меню «Вид» можно вернуть плоские страницы; выбор
  сохраняется. Оформление работает для текста и сканов, не меняя разметку,
  выделение и позицию чтения.
- Убрана пометка «beta» из названия встроенной читалки, окна выбора и справки.
- Добавлена запоминаемая папка синхронизации в меню экспорта книг. Можно указать
  локальную папку Dropbox, OneDrive или другого клиента и отправлять книги туда;
  синхронизацию с устройствами выполняет установленный облачный клиент.
- Базовые архивы стали меньше: AlReader, SumatraPDF, DjVuLibre и DocSharp
  устанавливаются отдельно по запросу. При первом открытии формата, которому
  нужна отсутствующая библиотека, показываются её назначение и размер загрузки;
  скачивание начинается по кнопке. После установки требуется перезапуск программы.
- Необязательные компоненты по умолчанию не вызывают автоматических уведомлений
  об обновлениях. Для каждого можно отдельно включить уведомления; ручная проверка
  доступна всегда. Отсутствие необязательной читалки не запускает восстановление
  всего комплекта. Обновление поверх полной установки сохраняет её компоненты.
- Компоненты загружаются из официальных источников авторов: сайта SumatraPDF,
  проекта DjVuLibre и пакетов DocSharp в NuGet. Отдельные зеркала компонентов
  в релизе HomeLib Ru не публикуются. Если официальный источник AlReader
  недоступен или не подтверждает Windows-выпуск, автоустановка недоступна;
  уже установленная читалка продолжает работать.
- В окне источников исправлены обрезанные пояснения и прокрутка колёсиком при
  небольшой высоте окна. Высота текстовых блоков учитывает переносы строк;
  основные кнопки остаются доступными внизу.
- Исправлено обновление программы с диска, подключённого к папке Windows без
  отдельной буквы: настоящая точка подключения тома больше не принимается за
  обычную ссылку. Перенаправления внутри папок установки и очистки отвергаются.
- Новые временные профили проверок автоматически очищаются после завершения,
  включая неудачные прогоны. Пользовательские базы и настройки в архивы не входят.

Для установки выберите `HomeLibRu.zip` (x86) или `HomeLibRu_x64.zip` (x64).
При обновлении закройте программу и распакуйте основной архив
поверх существующей установки. Сохраните свою папку `Data` и настройки.
Если старая версия отказывается обновляться из папки подключённого диска
с сообщением «Папка обновления содержит ссылку», этот выпуск нужно один раз
распаковать вручную: проверку выполняет ещё старый обновлятор.

Совпадение исходного ID — повод сравнить копии, а не доказательство одинакового
содержимого. Старые резервные копии могут не содержать отдельных заметок и
закладок читалки; восстановление каталога не заменяет все глобальные настройки.
