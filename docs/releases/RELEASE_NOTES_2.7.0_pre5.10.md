# HomeLib Ru 2.7.0_pre5.10

EXE **2.7.0.1077**. Обычные сборки Win32 и Win64.

## Изменения

- При выходе очищаются подготовленные для чтения FB2 из подпапки
  `webp-png` во временной папке программы. Прежняя очистка пропускала подпапки.
- Команда **«Инструменты → Очистить папку “Для чтения”»** также очищает
  `webp-png`, в том числе в отдельно настроенной папке для чтения.
- Постоянная пользовательская папка для чтения сохраняется при выходе.
  Исходные книги и архивы не удаляются. Файл, занятый внешней читалкой,
  может остаться до следующей очистки; очистка не прерывает её работу.
- Очистка не обходит посторонние подпапки и не следует по ссылкам/junction
  на другую папку. Временные файлы очищаются после остановки фоновой очереди.

Проверено на Win32 и Win64: очистка вручную и при выходе, занятый файл,
сохранность исходников и постоянной папки, чтение, импорт/экспорт и загрузка книг.

Все изменения pre5.09, поддержка LightLib/FLibrary, преобразование изображений,
OPDS и проверка обновлений сохраняются. Подробные результаты проверки —
в [BUILDING.md](https://github.com/Dicur3x/MyHomeLib/blob/master/BUILDING.md).

Название HomeLib Ru, адрес репозитория и авторство оригинала
Олексій Пеньков / Oleksiy Penkov сохранены.
