# AlReader 2.5.1009.25 — постоянный необязательный компонент

Сохранённый Windows-выпуск AlReader из ранее использовавшегося комплекта HomeLib Ru.
Это прежняя версия AlReader, а не новый выпуск автора и не обновление HomeLib Ru.
Автор AlReader — Alan; условия некоммерческого использования сохранены в `Readers/AlReader/readme.txt`.

Один архив подходит для HomeLib Ru x86 и x64: AlReader для Windows — 32-разрядная программа.
Распаковка вручную: содержимое архива помещается в папку HomeLib Ru. При существующей установке
сохраните свой `$savevtut.ini`; встроенный обновлятор HomeLib Ru сохраняет этот файл автоматически.

Архив опубликован один раз и не дублируется в последующих выпусках программы.
