## Каталог

- **Обновление INPX.** В поиске появился фильтр «Последний INPX». Он показывает книги, добавленные последним завершённым обновлением. Обычные периоды по-прежнему используют даты книг в источнике. Список пополняется при штатном обновлении и при дозапаковке сжатой коллекции.
- **Карточка книги.** Описание занимает всю свободную ширину. Если раскрыть иллюстрации, они появятся справа и будут крупнее, а текст займёт оставшееся место.
- **Тёмная тема.** Панель инструментов переключается на контрастные значки вместе с цветом окна.
- **Названия серий.** Лучше распознаются различия в знаках препинания и записи имён авторов. Вариант с пометкой издателя, например «Аллоды (АСТ)», предлагается объединить с обычным названием, если каталог подтверждает издателя и у серий есть общая книга.

## Повторные записи

- В «Приоритете источников» можно задать порядок для всей коллекции. В группе из двух, трёх или большего числа известных источников основная копия выбирается по этому порядку. Уже отмеченные вручную группы сохраняют свой выбор.
- Фильтр «Только группы без отметки» помогает найти копии, требующие ручной проверки. Сюда попадают случаи с повтором внутри одного источника, неизвестным источником или личными данными у другой копии.
- Удаление большой выборки идёт последовательными партиями в одном фоновом окне. Можно остановить операцию между записями в архивы. Уже выполненные изменения сохраняются. Основные копии и соседние книги проверяются перед записью.
- После фонового удаления другая открытая коллекция сохраняет выдачу и отметки. Группы, в которых были удалённые карточки, обновляются при открытии.

## HomeLibre Reader

- Подсказка с текстом сноски появляется при наведении на её номер и при перелистывании, и при плавной прокрутке. Нижняя панель сносок при перелистывании включается отдельно в «Виде».
- Закрытие поиска убирает подсветку. Внизу отображается процент чтения в обоих режимах. На полосе остаются редкие отметки частей и глав с достаточным промежутком между ними. Цвет полосы настраивается для каждой темы.
- Окно «Вид» открывается поверх читалки и быстрее показывает текущие настройки. Все варианты размеров и полей загружаются при раскрытии списка. Цвета собраны в «Виде → Цвета темы», форматы и необходимые компоненты перечислены в «Помощи».
- Плавная прокрутка мягче набирает скорость. При движении вверх читалка сохраняет остаток прокрутки, когда предыдущая страница подгружается на стыке.

## Обновления

- Если закрыть окно ручной проверки в каталогизаторе или читалке, оно остаётся закрытым после завершения проверки. Результат доступен при следующем открытии.
- В списке изменений версии сторонних компонентов сохраняют номер автора. Например, SQLite 3.53.0 отображается полностью.
