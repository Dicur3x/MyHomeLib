# HomeLibre 3.0 beta 2

Исправления после 3.0 beta 1. Программа, HomeLibre Reader и наши модули
используют обозначение **3.0 beta 2**. Номера сторонних библиотек остаются авторскими.

## Обновление и установка модулей

- Исправлен отказ обновления из-за занятой `sqlite3.dll`, когда новая DLL
  побайтово совпадает с установленной: такую библиотеку больше не заменяем.
  Если занята действительно изменившаяся DLL, обновление сохраняет защиту
  от частичной установки и возможность отката.
- При обновлении согласованно закрываются и возвращаются связанные окна этой
  установки. Читалка восстанавливает выбранную книгу, вложение внутри архива
  и место чтения; окна другой установки не закрываются.
- Исправлено восстановление отложенной установки модуля после перезапуска
  читалки. Уже скачанный подходящий пакет сразу показывается готовым
  к установке и не требует повторного поиска в сети.
- Название и версия готового пакета видны в списке компонентов. Неподходящий
  пакет читалки не удаляет подготовленное обновление программы или SQLite.
- Окна предложения установить недостающий модуль остаются видимыми
  при самостоятельном запуске Reader. После установки чтение или сохранение
  продолжается с выбранной книгой и её параметрами.
- Уточнены ссылки на источники компонентов и повтор проверки после сетевой
  ошибки. Состав минимальной поставки сохраняется: обработчики форматов
  загружаются по необходимости.

## Большие иллюстрированные книги

- Исправлено открытие книг с большим количеством иллюстраций, в том числе
  «Инженер Петра Великого». Читалка хранит сжатые исходные изображения
  и распаковывает изображения текущей страницы или разворота по мере чтения.
  Повторного сжатия с потерей качества нет; исходный файл не изменяется.
- Устранено зависание этой книги при увеличении и уменьшении размера шрифта,
  скрытии и возврате панелей. Для этих действий больше не обрабатывается
  заново вся книга.
- Ошибки подготовки книги записываются в диагностический журнал.

Архивы каталогизатора в этой переходной версии сохраняют имена
**HomeLibRu.zip** для x86 и **HomeLibRu_x64.zip** для x64, чтобы их нашли
установленные обновляторы прежних версий. Программа называется HomeLibre.
Новый обновлятор также понимает имена HomeLibre; они будут использоваться
для архивов следующих версий.
