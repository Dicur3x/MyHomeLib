# HomeLibre 3.0 beta 3

## Читалка

- Исправлена потеря отдельных букв и пробелов рядом с некоторыми символами
  при загрузке книги. Ошибка зависела от языковой настройки Windows;
  исправление проверено на x86 и x64, в том числе на большом FB2
  «Беги за мёртвым кроликом» с 369 изображениями.
- Исправлен подбор шрифта для эмодзи. Проверены выделение слова двойным
  щелчком, обычное выделение мышью и копирование текста в FB2, EPUB, TXT
  и PDF с текстовым слоем, при одной и двух страницах и в обеих темах.
- У читалки появился собственный значок для EXE, окна и панели задач.
- Журнал ошибок доступен из отдельной читалки: «Помощь → Журнал ошибок…».
  Там можно открыть папку журнала или сохранить ZIP для отчёта об ошибке.
- Дополнительные шрифты показывают размер загрузки даже при отсутствии
  отдельного файла со сведениями о них. Сами шрифты скачиваются после
  нажатия пользователя; повторная загрузка уже сохранённых файлов не нужна.
  Неизвестный размер больше не выдаётся за «0 КБ». При загрузке сохраняется
  файл лицензии шрифта, а текст книги и позиция чтения остаются на месте.

## Сохранение книг

- Вернулось сохранение текста в TXT. Для старых Kindle добавлен MOBI,
  для устройств с поддержкой KF8 — AZW3. Модуль записи Kindle предлагается
  скачать только при первом использовании. Исходная EPUB при этом
  не переводится через FB2.
- В MOBI и AZW3 можно сохранять подготовленные книги из других поддерживаемых
  форматов, включая PDF и DjVu со сканами. Доступны выбранное качество
  изображений, разделение разворотов и оценка размера. Для сканов страницы
  остаются изображениями; это преобразование не заменяет распознавание текста.
- Исправлены обнаруженные при проверках проблемы со служебными данными JPEG
  и GIF, пространствами имён SVG и ссылками на иллюстрации при записи Kindle.
  Текст, сноски, оглавление и изображения проверялись независимым декодером;
  физическое устройство Kindle в этих проверках не использовалось.
- Экономный режим для EPUB и FB2 в ZIP учитывает сжатие конечного контейнера:
  выбирается меньший результат, а при равном размере — более качественный.
- Настройки «Папки/Устройства» и «Сохранить как» используют одну папку
  назначения и общие маски имени и подпапок. Изменения видны при следующем
  открытии окна; отключённая маска подпапок сохраняется для повторного включения.
- В настройках можно выбрать исходный формат, FB2, FB2 в ZIP, EPUB, TXT,
  MOBI или AZW3 как начальный вариант. Окно сохранения учитывает этот выбор;
  повторное преобразование в уже исходный формат не предлагается.
- Параметры сохранения восстанавливаются после установки необходимых модулей.
  Модули посторонних форматов при этом не устанавливаются.
- Уточнён флажок выбора папки перед внешними инструментами. Он действует
  для всех скриптов экспорта; при отмене отметки книг сохраняются.
- Обновлена справка по сохранению, устройствам и скриптам на четырёх языках.
  Убран неработавший выбор скрипта по умолчанию; внешние скрипты запускаются
  отдельными командами из меню.

## Необязательные модули

- В окне обновлений появилась кнопка «Модули…». Здесь можно посмотреть
  установленные необязательные модули, занимаемое ими место и удалить ненужные.
  Книги, коллекции и настройки при этом сохраняются.
- Программа учитывает фактическое использование модулей при чтении,
  конвертации и обработке изображений. Просмотр списка компонентов
  не считается использованием. Обычное обновление модуля не обнуляет этот срок.
- Раз в месяц программа предлагает убрать модули, которые не использовались
  месяц. Они собраны в одном окне и не выбраны для удаления заранее.
  Предложение можно отложить или отключить; ручное удаление остаётся доступным.
  Для уже установленных модулей отсчёт начинается с первого запуска beta 3.
- Удалённый модуль снова предлагается скачать, когда он потребуется для книги.

## Остальные исправления и поставка

- При удалении выбранных книг общий ZIP или 7z с другими книгами сохраняется
  целиком. Уточнены подтверждение, проверка источника и сообщение об ошибках.
- Ограничено общее время попыток загрузки отзывов. Ошибка сети или отмена
  не заменяет ранее сохранённые отзывы неполным ответом.
- Исправлено распознавание документов Microsoft Works со служебным потоком
  CONTENTS, в том числе при неверном расширении. Проверено чтение и сохранение
  в FB2 и EPUB на реальных книгах для x86 и x64.
- Архивы каталогизатора теперь называются **HomeLibre.zip** и
  **HomeLibre_x64.zip**. Обновлятор beta 2 уже поддерживает эти имена.
  Имена EXE сохраняются для совместимости с прежними установками.
- Каталогизатор сохраняет минимальную поставку: читалка и дополнительные
  обработчики форматов устанавливаются отдельно по необходимости.

Сжатие коллекций, SQL-дампы и новые выходные форматы через fb2cng пока
в разработке и в этот выпуск не включены.
