# HomeLib Ru 2.7.0_pre5.04

Версия EXE: **2.7.0.1071**. Небольшое исправление ссылок и источника обновлений.

- «Сайт программы» и ссылка в окне «О программе» ведут на
  [Dicur3x/MyHomeLib](https://github.com/Dicur3x/MyHomeLib).
- Проверка новой версии получает сведения о HomeLib Ru из этого репозитория,
  а не номера выпусков оригинального MyHomeLib. Старое значение `update_server`
  в настройках больше не влияет на проверку версии программы.
- Настройка `update_server` сохранена для обновлений коллекций. Сервер INPX,
  пути к книгам и сами коллекции не менялись.
- Ссылки для сообщений об ошибках в справке перенесены в репозиторий форка.
- Авторство в EXE и окне «О программе» уже восстановлено в pre5.01:
  **Oleksiy Penkov (Олексій Пеньков)**. Исправлено также оставшееся неверное
  написание в старом, неиспользуемом файле проекта Delphi 2007.

Название **HomeLib Ru**, имя **HomeLibRu.exe** и пустое поле LegalTrademarks
сохранены. Оригинальные `LICENSE` и `NOTICE` не изменены.
Исправление кодировки FB2 из pre5.03 и быстрые книжные серии включены.

Закройте программу перед обновлением. Архивы: **HomeLibRu.zip** (x86) и
**HomeLibRu_x64.zip** (x64). Рекомендуется резервная копия профиля и коллекций.

По просьбе владельца выполнены только сборка и адресные проверки этого
исправления; полный прогон тестов коллекций и индексации не повторялся.
