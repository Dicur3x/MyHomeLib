# HomeLib Ru pre5.31 — 2.7.0.1099

Ускорен поиск по названию, исправлено ожидание в окне обновлений,
добавлено управление всеми любимыми авторами. Необязательные компоненты
скачиваются только при необходимости.

- Результаты проверки обновлений появляются отдельно для каждого компонента.
  Готовую строку можно использовать, пока другой сайт ещё отвечает. Медленный
  или недоступный источник не задерживает остальные результаты; закрытие окна
  корректно завершает проверки и загрузки.
- Ускорен обычный поиск по названию, в том числе со «Скрывать удалённые».
  Сохраняются буквальный поиск специальных символов, поиск с Е/Ё и остальные
  режимы запросов. Новых индексов и обработки всей коллекции при запуске нет.
- На вкладке «Авторы» в меню ⋮ добавлено окно «Все любимые авторы…».
  Оно показывает и авторов, которых нет в текущей коллекции. Можно найти запись
  и удалить лишние отметки штатными средствами, без редактирования SQLite.
  Похожие имена автоматически не объединяются.
- AlReader 2.5.1009.25 доступен из одного постоянного проверенного архива
  [в отдельном выпуске](https://github.com/Dicur3x/MyHomeLib/releases/tag/optional-alreader-2.5.1009.25).
  Программа проверяет размер и SHA-256. Этот архив не дублируется с каждым
  выпуском HomeLib Ru; настройки уже установленной читалки сохраняются.
- 7-Zip стал необязательным компонентом. Обычные ZIP и чтение FB2 работают
  без него. Когда операция требует внешнего распаковщика, программа объясняет
  причину и предлагает установить компонент; автоматической загрузки нет.
- Поддерживаемый 7-Zip обновлён до 26.05. Загрузка идёт из официального проекта
  автора, с проверкой контрольных сумм. Первая установка работает и без прежнего
  распаковщика. Установщик 7-Zip используется как архив, а не запускается.
- Если 7-Zip нужен при заполнении метаданных или книжных серий, проход
  останавливается с одним запросом установки вместо повторных ошибок по книгам.
  Уже сохранённые изменения учитываются, файлы книг не изменяются.
- Необязательные компоненты по умолчанию не вызывают автоматических уведомлений
  об обновлении. Минимальное обновление сохраняет ранее установленные компоненты,
  личные данные и настройки.

В файлах этого выпуска только `HomeLibRu.zip` (x86), `HomeLibRu_x64.zip` (x64)
и `SHA256.txt`. SumatraPDF, DjVuLibre, DocSharp и 7-Zip программа получает из
источников авторов; AlReader — из постоянного архива, указанного выше.

При ручном обновлении закройте программу и распакуйте подходящий основной
архив поверх существующей установки. Сохраните папку `Data` и свои настройки.

[Проверки и ограничения выпуска](https://github.com/Dicur3x/MyHomeLib/blob/2.7.0_pre5.31/docs/RELEASE_VALIDATION_2.7.0_pre5.31.md).
