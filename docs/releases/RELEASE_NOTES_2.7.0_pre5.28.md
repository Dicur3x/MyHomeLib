# HomeLib Ru pre5.28 — 2.7.0.1096

- Сортировки и фильтры столбцов сохраняются отдельно для каждой вкладки и коллекции, включая порядок нескольких столбцов, направление сортировки, выбранные значения и диапазоны.
- При следующем запуске программа по умолчанию спрашивает, восстановить ли сохранённые сортировки и фильтры. Галочка «Больше не спрашивать» запоминает выбранное «Да» или «Нет» для последующих запусков.
- В настройках появился раздел «Списки книг»: автоматическое восстановление, вопрос при запуске или запуск без восстановления. Режим можно изменить в любой момент.
- Сброс сортировок и фильтров тоже сохраняется. Исправлены фокус при пустом результате фильтрации и указатели сортировки при смене представления списка.
- Восстановление начинается после появления главного окна; скрытые вкладки заранее не загружаются. Быстрый показ окна сохранён.

Проверено на x86 и x64. Файл сохранённого состояния `book-views.ini` хранится в рабочей папке данных и не входит в дистрибутив.
