## Каталог

- Поле быстрого поиска по названию теперь на панели. Результат открывается в поиске. Сочетание F3 по-прежнему доступно.
- Описание FB2 видно в нижней карточке, даже если включён показ дополнительных сведений FB2. Таблица сведений появляется, когда описание отсутствует или скрыто. Под описанием показываются ключевые слова из каталога, если они заполнены.
- Команды чтения, сохранения, редактирования и обслуживания коллекции сгруппированы по назначению. Сжатие книг в копии коллекции и обслуживание базы имеют разные названия. Книги из готовой копии можно открыть прямо из окна результата.
- Фильтр «Последнее обновление коллекции» показывает новые книги из последнего завершённого обновления INPX или metabib. Обычные периоды используют даты добавления из источника.
- Столбец «Прочитано» можно сделать уже. Подсказка списка показывает активные фильтры, включая фильтры скрытых столбцов.
- Улучшено сопоставление вариантов названий серий. При объединении учитываются читаемые пробелы, скобки, регистр аббревиатур и значащие знаки препинания.
- Подписи разделов настроек можно менять через контекстное меню. Имя запоминается после сохранения настроек. Пустое поле возвращает исходную подпись.

## Читалка

- Для длинных страниц комиксов в режиме прокрутки рядом с «Вписать» появилась кнопка «100%». По правому клику можно перейти на весь экран иа твернуться в обычное окно, в том числе при скрытом интерфейсе. Прокрутка на экран и перелистывание изображений имеют отдельные команды, клавиши можно настроить.
- В просмотре иллюстраций книги можно листать изображения колесом. Внешнюю читалку для EPUB можно выбрать при открытии, даже если уже задана программа по умолчанию.
- Недавнюю книгу можно открыть клавишей Enter. Из общего списка закладок и заметок можно перейти сразу к нужной книге и позиции. Если книга была открыта из архива, читалка запоминает выбранное вложение.
- Исправлено открытие EPUB с незакрытыми тегами переноса строки и отдельных книг из глубоко вложенных папок. При закрытии во время распаковки или подготовки страницы читалка запрашивает остановку операции.

## Сохранение и архивы

- Оценка больших PDF со сканами и обычным текстом учитывает выбранный режим изображений. Для приблизительной оценки показывается диапазон. «Оттенки серого» применяются и к иллюстрациям на текстовых страницах.
- Улучшено сохранение больших DOCX и PDF, распознавание книжных файлов с необычными расширениями и экспорт EPUB с отдельной страницей обложки в форматы Kindle. Для части изменений HomeLibre предложит обновить BookProcessing.
- В окне повторных записей точнее описаны основная копия, привязки к исходным файлам и причины, по которым отдельным группам требуется ручная проверка.

## Установка

- Каталогизатор и HomeLibre Reader доступны для Windows x86 и x64. Дополнительные компоненты скачиваются по мере необходимости.
