# HomeLib Ru pre5.37 — 2.7.0.1105

Исправлены обновление программы и лишние загрузки при работе с книгами.

- Исправлена ошибка «Версия EXE не совпадает с версией обновления».
  Программа и её установщик теперь собираются с одной версией; это проверяется
  также внутри готовых архивов x86 и x64.
- Компоненты обработки книг разделены. Конвертация обычной FB2 в EPUB и расчёт
  размера больше не устанавливают Kindle, Office и XPS. Общая среда обработки
  загружается при необходимости; PDFium, DjVuLibre, DocSharp и остальные
  декодеры запрашиваются только для соответствующей книги. Сжатие изображений
  использует отдельный небольшой обработчик.
- Исправлена конвертация FB2 с изображениями, обозначенными как `image/jpg`:
  такие иллюстрации распознаются как JPEG и сохраняются в EPUB.
- Проверены сохранение нескольких книг разных форматов, расчёт размера,
  установка нужного компонента и возврат к сохранению после перезапуска.
- MCP-сервер исключён из минимальной поставки. Его можно установить через
  «Инструменты → Подключить AI», если такая интеграция нужна.
- Библиотека Zstandard для сжатых каталогов Metabib `.jsonl.zst` вынесена
  в отдельный компонент. Обычному каталогу INPX она не требуется.

Скачивание: `HomeLibRu.zip` для x86 или `HomeLibRu_x64.zip` для x64.
Минимальные архивы содержат каталогизатор без читалки и дополнительных
декодеров. Уже установленные компоненты и личные данные сохраняются.

Если старая версия не может установить обновление из программы, закройте её
и распакуйте подходящий архив поверх папки программы. После этого следующие
обновления можно устанавливать штатно. Не удаляйте папку `Data` и свои коллекции.

Читалка и дополнительные компоненты находятся в
[постоянном выпуске компонентов](https://github.com/Dicur3x/MyHomeLib/releases/tag/optional-alreader-2.5.1009.25).
