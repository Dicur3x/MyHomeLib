# HomeLibre 3.0 beta 13

Изменения после beta 12.

## Удаление дублей

- Сохранённый порядок источников применяется ко всем копиям книги, включая файлы, ранее объединённые под одной строкой в каталоге. HomeLibre оставляет доступную книгу из выбранного источника и удаляет лишние копии. Размер файлов может различаться.
- Книги удаляются и из общих архивов 7z, которым требуется перепаковка. Обработка идёт в фоне после общего подтверждения. Остальные книги в архиве сохраняются.
- Исправлен отказ удаления с 7-Zip 26.06: программа ошибочно требовала перепаковку архивов FLibrary. Теперь оставшиеся книги в таких архивах сохраняются без лишнего пересжатия.
- Исправлено удаление из крупных ZIP64, в которых нужные файлы расположены за границей 4 ГБ. Ускорены подготовка таких архивов и запись журнала восстановления.
- Итоги удаления показываются в отдельном прокручиваемом окне. Оно сообщает, сколько копий удалено и что осталось, и позволяет продолжить работу с каталогом.
- Текущий архив показан обычной строкой без поля ввода и мигающего курсора. Полный путь можно скопировать отдельной кнопкой. Вместо «перемещения данных» программа пишет, что уменьшает архив после удаления книг.
- В самом окне удаления видны накопительная сумма освобождённого места и итоги по каждому диску; отдельное окно открывать не нужно. Суммы накапливаются по завершённым изменениям книг, архивов, обложек и иллюстраций; при невозможности измерения программа сообщает об этом.
- Ускорено обновление каталога после удаления: при очистке источников больше не требуется заново просматривать миллионы строк для каждой книги. Во время обновления виден отдельный счётчик прогресса.
- Проверка соседних книг выбирает записи только из затрагиваемых архивов, вместо повторного чтения всех книг между партиями. Старые сторонние каталоги без нужных индексов проверяются полностью.
- В окне дублей один список книг: справа видны все найденные копии, их источники, пути и размеры. Не требуется различать повторные строки каталога и файлы, оставшиеся после объединения. Можно выбрать сохраняемую копию вручную или по порядку источников; отдельно доступны удаление лишних файлов и объединение в каталоге без удаления файлов.

- Окно результата удаления появляется поверх остальных окон; его можно открепить отдельной кнопкой.

### Как пользоваться очисткой

Найдите дубли, задайте порядок источников и проверьте, какая копия остаётся.
Совпадение исходного ID библиотеки, языка и формата помогает найти кандидатов;
одно название не является основанием для удаления. Разные издания могут иметь
один ID, поэтому список показывает пути и размеры для проверки.

«Удалить лишние файлы» освобождает место на диске, а «Объединить в каталоге»
оставляет файлы на месте. Из общих архивов удаляются выбранные книги, соседние
книги сохраняются. Перед изменениями проверяются сохраняемая копия, точные пути,
актуальность записей и использование файлов другими книгами. Остановка заканчивает
текущий архив; для прерываний предусмотрен журнал восстановления. Это защитные
меры, а не абсолютная гарантия: для незаменимых книг нужна отдельная резервная копия.

## Поиск и карточка книги

- На пустой вкладке поиска при запуске не подсчитывается вся большая коллекция: для подготовки фильтров достаточно небольшой выборки. Поиск книг выполняется после «Применить».

- «Очистить» во вкладке поиска сбрасывает также фильтры столбцов. Исправлен случай, когда сохранённый фильтр скрывал книги найденного автора.
- Из результатов поиска можно добавить автора в любимые или убрать его оттуда. Для книги с несколькими авторами показывается выбор имён.
- «Изменить описание» сразу открывает текст описания с кнопками «Сохранить» и «Отмена». Название, авторы и остальные поля доступны через «Изменить сведения о книге…».

- Заголовки статистики стали читаемыми в тёмной теме; исправлены белые полосы и обрезание при крупном шрифте.

## Цвета каталогизатора

- В «Настройки → Интерфейс» добавлено «Цвета оформления…»: фон окна, списки и поля, текст, ссылки и заголовки, выделенная строка. Для светлой и тёмной темы сохраняются отдельные палитры. Есть образец результата, отмена и возврат к исходным цветам выбранной темы.
- Исправлен цвет текста выделенных книг: он больше не подменяется встроенной тёмной темой вопреки выбранному цвету.

## HomeLibre Reader

- В «Настройки → Открытие файлов в Windows…» можно добавить читалку в список приложений для книг, документов, изображений и архивов, а затем выбрать её в настройках Windows. После переноса портативной папки повторная настройка обновляет путь. Свою регистрацию можно убрать; прежние приложения по умолчанию не заменяются без выбора пользователя.

- При отдельном запуске без файла сразу открывается окно читалки. Сверху расположены кнопка открытия и область перетаскивания, ниже — недавние книги с названием, автором и небольшой обложкой. Сведения и обложки прежних записей дополняются при следующем открытии книги.
- Книгу или архив можно перетащить на начальную страницу либо на уже открытую книгу. Перед открытием показывается подтверждение.
- В меню «Недавние книги» при запуске из каталогизатора доступна его история. При отдельном запуске используется история самой читалки. Повторное открытие сохраняет выбранную книгу внутри архива и место чтения.
- Колёсико над книгой работает после закрытия меню и настроек без дополнительного щелчка по странице.
- Добавлена «Моя тема» с отдельными цветами фона, текста, заголовков и полосы чтения. Для выбора произвольного цвета открывается полная палитра.
- В основном выборе шрифта остались шрифт по умолчанию и добавленные гарнитуры. Шрифты Windows можно найти по названию в отдельном окне, а свои — добавить из TTF/OTF. Ненужные гарнитуры можно убрать из списка читалки и вернуть; шрифт по умолчанию защищён. Выбор сохраняется для следующих книг.
- Набор для чтения включает PT Serif, PT Sans, Noto Serif и Noto Sans с кириллицей и латиницей, по четыре начертания. Недостающие гарнитуры загружаются по запросу; можно восстановить одну гарнитуру или весь набор.
- В конце архива манги читалка может предложить следующую главу из той же папки. При чтении из каталогизатора доступно предложение следующего тома серии. Подсказку можно отключить в настройках.
- Исправлено открытие EPUB «Маг на полную ставку» и «Древняя техника усиления», содержащих ошибки разметки.
- Исправлены обрезанные подписи в окнах вида страниц и цветов темы при крупном масштабе Windows.

## Экспорт и журнал ошибок

- Исправлена запись навигации в KFX/AZW8 при экспорте из FB2. Оглавление и сноски проверены независимым декодером.
- Журнал ошибок в каталогизаторе и читалке показывает русский текст и переносы строк в читаемом виде. Выгрузка журнала в ZIP сохраняет исходный файл.

## Проверка перед выпуском

Изменения проверены на Windows в сборках x86 и x64. Массовое удаление проверялось на копиях реальных ZIP и 7z трёх источников, включая книги, обложки и отдельные иллюстрации. На пяти крупных архивах общим размером 21,42 ГиБ каждая сборка освободила 6,21 ГиБ с одинаковым результатом в каталоге. Исходные архивы сверены по контрольным суммам.

В пользовательском прогоне удалены все 557 735 отмеченных копий; программа сообщила об освобождении около 192 ГБ. Открытие экспортированных книг на физических Kindle и Kobo ещё ожидает проверки владельцами устройств. Проверенные диалоги прошли программную проверку раскладки при масштабе до 300%.
