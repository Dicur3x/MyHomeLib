# HomeLib Ru pre5.22 — 2.7.0.1090

## Каталог и интерфейс

- В шести книжных списках доступны колонки «Переводчики», «Город издания», «Год издания» и ISBN: сортировка, фильтры столбцов и сохранение вида работают как у остальных колонок.
- Существующий выбор формата ФИО на вкладке авторов согласован с добавлением автора в поиск: идентичность автора и смысл уже введённого запроса сохраняются. Для обычного поиска и выражений уточнены переключение, подсказки и переходы с клавиатуры.
- Подсказка о тёмной теме Windows размещена справа рядом с действием переключения темы.
- Ускорены обновление панели книги и масштабирование главного окна. Короткие ссылки сохраняют свой размер, длинные переносятся; аннотация обновляется после окончательного выравнивания. При смене масштаба высоты шести панелей больше не синхронизируются повторно на промежуточных размерах.
- Кнопка иллюстраций и галерея учитывают фактический масштаб шрифта, включая 192 PPI.

## Заметки и перенос данных

- Общий список заметок ищет по книге, заголовку, тексту, цитате и месту записи. При ошибке сохранения или конфликте редактор сохраняет черновик и показывает актуальную запись. Отложенный запрос применяется до удаления или экспорта показанных заметок.
- Фильтр «Книги с заметками» обрабатывает идентичности пакетами. Поиск не создаёт заново отсутствующий файл каталога.
- Старый перенос пользовательских данных показывает предпросмотр перед применением. Ошибки SQL при применении откатывают изменения каталога, личных карточек и групп; интерфейс получает обновления после успешного commit.
- Крупные INP читаются построчно через временный файл; отмена и повреждённые записи не оставляют частично опубликованный импорт.

## Экспорт и обновления

- После экспорта отметки снимаются только с успешно обработанных книг. Ошибка или отмена сохраняют отметки оставшихся книг.
- При совпадении имени ZIP отправляется именно новый архив; старый файл сохраняется. Исправлена обработка ошибки создания архива.
- Отмена прерывает активную предварительную HTTP-загрузку, включая запрос без отображения прогресса, и старые внешние конвертеры вместе с дочерними процессами.
- Доработаны клавиатурная навигация окна обновлений, восстановление ссылок на источники компонентов и сообщения об ошибках проверки.

История выпусков перенесена из корня репозитория в [docs/releases](README.md).
Архивы остаются полными: `HomeLibRu.zip` для x86 и `HomeLibRu_x64.zip` для x64.
