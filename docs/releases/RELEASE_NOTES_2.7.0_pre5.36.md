# HomeLib Ru pre5.36 — 2.7.0.1104

Срочный выпуск для исправления установки HomeLib Reader и обновления
программы вместе с читалкой.

- Исправлены архивы читалки x86 и x64, из-за которых появлялось сообщение
  «Манифест обновления не подходит этой версии программы». Читалку теперь
  можно докачать и из pre5.34/pre5.35: исправление внесено также в постоянный
  выпуск компонентов, повторно скачивать весь каталогизатор для этого не нужно.
- Если одновременно обновлялись каталогизатор и читалка, ошибка пакета
  читалки могла прервать всю загрузку. Исправленные пакеты устраняют эту причину.
- При несовпадении выпуска или разрядности пакет по-прежнему отклоняется;
  сообщение теперь объясняет причину и называет компонент.
- Упаковщик компонентов проверяет выпуск назначения до создания архивов,
  чтобы ошибка манифеста не повторялась.

После неудачной попытки нажмите «Проверить всё» и повторите загрузку.
Если окно продолжает показывать прежнюю ошибку, закройте и снова откройте
программу перед повторной проверкой.

Скачивание: `HomeLibRu.zip` для x86 или `HomeLibRu_x64.zip` для x64.
В этих архивах нет читалки и модулей DOC, DjVu, PDF, Kindle и конвертации;
они устанавливаются при необходимости. Ранее установленные модули сохраняются.

Пакеты автономной читалки находятся в
[постоянном выпуске компонентов](https://github.com/Dicur3x/MyHomeLib/releases/tag/optional-alreader-2.5.1009.25).
