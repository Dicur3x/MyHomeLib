# HomeLibre 3.0 beta 4

## Сохранение книг

- «Ещё форматы» открывает дополнительные варианты в окне «Сохранить как». Из FB2 доступны EPUB 2, EPUB 3, KEPUB, KFX, AZW8, PDF и Markdown. EPUB можно преобразовать напрямую в KEPUB или PDF. Для смешанного набора из FB2 и EPUB программа выбирает нужный модуль для каждой книги.
- Для PDF из EPUB нужен Microsoft WebView2 Runtime. Если его нет, HomeLibre предложит установку из официального источника. При переходе к страницам расположение текста и иллюстраций может измениться.
- Оценка размера создаёт пробные копии в выбранном формате. KEPUB сохраняется с расширением `.kepub.epub`. Для KFX и AZW8 нужна обложка, поэтому режим без изображений для них недоступен.

## Каталог и читалка

- Кнопка «Отзывы» в нижней панели книги открывает сохранённые отзывы. Здесь же их можно загрузить или обновить с сайта коллекции. Рядом с отзывами указан источник.
- Если изменить высоту панели «Сведения о книге» мышью, программа запомнит размер. Автоподбор можно вернуть через «Вид → Дополнительно».
- В «Моих авторах» можно поставить личную оценку или скрыть автора. Фильтр по оценке и список скрытых авторов можно изменить в любое время.
- F11 разворачивает читалку на весь экран, в том числе из уже развёрнутого окна. Скрытие элементов управления остаётся отдельной кнопкой.

## Обновление программы

- Исправлена установка компонентов с длинными путями. На x86 и x64 проверены распаковка, установка двух модулей вместе, восстановление прежнего файла при сбое и очистка. Защита от ссылок за пределы папки обновления сохранена.
- Описание выпуска отображается в обновляторе, даже если текст начинается с повторного заголовка версии.

Минимальные архивы каталогизатора для 32- и 64-разрядной Windows называются `HomeLibre.zip` и `HomeLibre_x64.zip`. Читалку и дополнительные модули программа предлагает скачать по мере необходимости.
