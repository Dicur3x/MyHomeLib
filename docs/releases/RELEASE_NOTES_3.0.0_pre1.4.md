# HomeLibre 3.0 beta 4

## Сохранение книг

- «Ещё форматы» открывает дополнительные варианты в окне «Сохранить как». Из FB2 доступны EPUB 2, EPUB 3, KEPUB, KFX, AZW8, PDF и Markdown. EPUB можно преобразовать напрямую в KEPUB или PDF. Для смешанного набора из FB2 и EPUB программа выбирает нужный модуль для каждой книги.
- Вёрстка PDF из EPUB использует установленный Microsoft Edge или Google Chrome. При преобразовании в страницы расположение текста и иллюстраций может отличаться от EPUB.
- Оценка размера создаёт пробные копии в выбранном формате. KEPUB сохраняется с расширением `.kepub.epub`. Для KFX и AZW8 нужна обложка, поэтому режим без изображений для них недоступен.

## Сжатая копия коллекции

- В меню «Коллекция» появилась команда «Сжать коллекцию…». Она создаёт отдельную копию локальной библиотеки и сохраняет исходные книги в прежних папках. Поддерживаются смешанные коллекции.
- По умолчанию упаковка обратимая. Содержимое книг сохраняется побайтно. Для FB2 и EPUB можно отдельно выбрать сбалансированное или экономное сжатие иллюстраций. Оно может снизить детализацию. PDF, DjVu и другие форматы сохраняют исходное содержимое. Архивы FBD и комплекты FLibrary с отдельными иллюстрациями копируются целиком.
- Перед запуском видны объём исходных файлов, размер рабочей копии каталога и свободное место. После обработки программа показывает фактический размер и предлагает открыть результат как отдельную коллекцию. При отмене готовые архивы можно использовать повторно, выбрав ту же папку.
- Для сжатой коллекции команда «Обновить коллекцию из файла…» принимает INPX и папку с книгами обновления. Программа упаковывает новые и изменённые книги с сохранённым профилем, а готовые архивы использует повторно.
- Недостающие компоненты предлагаются в одном окне с размером загрузки. Модуль обработки изображений нужен для выбранного режима сжатия иллюстраций.

## Обновление программы

- Исправлена установка компонентов с длинными путями. На x86 и x64 проверены распаковка, установка двух модулей вместе, восстановление прежнего файла при сбое и очистка. Защита от ссылок за пределы папки обновления сохранена.
- Описание выпуска отображается в обновляторе, даже если текст начинается с повторного заголовка версии.

Минимальные архивы каталогизатора для 32- и 64-разрядной Windows называются `HomeLibre.zip` и `HomeLibre_x64.zip`. Читалку и дополнительные модули программа предлагает скачать по мере необходимости.
