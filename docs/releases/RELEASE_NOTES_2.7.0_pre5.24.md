# HomeLib Ru pre5.24 — 2.7.0.1092

- В небольшом главном окне карточка книги оставляет место для заголовка и трёх полных строк списка. Это действует на всех шести вкладках при изменении размера окна, масштаба и положения разделителя.
- Карточка получает окончательный размер обложки и нижней кнопки за один проход. Длинная надпись на кнопке сразу меняет её ширину; дополнительное изменение размера окна больше не требуется.
- Убрано повторное полное чтение подготовленного файла для вычисления его контрольной суммы, пока файл удерживается открытым для чтения. Для файла 8 МБ двенадцать повторных проверок занимают 0–16 мс вместо 672–1219 мс в контрольном замере x86/x64. Первичная проверка по-прежнему читает файл полностью. После закрытия последнего читателя сумма вычисляется заново; изменения зависимостей и отмена операции проверяются при каждом обращении.
- Повторно проверены x86 и x64, компактные окна, темы и масштабирование, фильтры, чтение, экспорт и сохранность личных данных. В отчёт добавлены отдельные замеры списка на 50 тысяч книг и объяснение влияния средства проверки интерфейса на результаты нагрузочного теста карточки.
- В оба архива включена SQLite 3.54.1, как и в pre5.23.
