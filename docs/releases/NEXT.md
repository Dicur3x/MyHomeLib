# Изменения после HomeLibre 3.0 beta 6

Рабочий список для следующего выпуска. Перед публикацией его нужно сверить с кодом, составом обоих архивов и итоговыми проверками.

## Упаковка коллекций

- Для смешанных ZIP с книгами HomeLibre сохраняет выигрыш от уже сжатых файлов. Текстовые книги могут быть перепакованы с PPMd, а двоичные файлы сохраняют сжатие там, где оно экономит место. Если готовый архив не меньше исходного, программа сохраняет исходный архив.
- В режиме JPEG XL программа умеет обратимо упаковать подходящие JPEG внутри PDF. Если новый архив меньше, HomeLibre использует его и при открытии восстанавливает исходный PDF с проверкой контрольной суммы. Остальные PDF проходят обычную обратимую упаковку.
- Такой PDF можно открыть из каталога или отдельно из созданного 7z, передать на конвертацию, сохранить в исходном формате и получить через OPDS. При обновлении из INPX уже упакованные архивы используются повторно, когда книги в них не изменились.
- Для новой упаковки PDF нужен обновлённый модуль подготовки книг. Для чтения и выгрузки упакованного PDF нужен декодер JPEG XL. При сохранении в исходном формате получается обычный PDF, совпадающий с исходником побайтово.
- «Максимальная экономия» уменьшает детализацию фона подходящих сканов DjVu. Размеры страниц, отдельный слой с буквами, распознанный текст и оглавление сохраняются. Мелкие детали фона могут измениться. Экономия относится к архиву коллекции, размер отдельного распакованного DjVu остаётся прежним. Для этого режима нужен обновлённый модуль подготовки книг.
