## Удаление книг

- **Правый клик по книге → «Удалить».** В подтверждении видно, сколько книг выбрано. Галочка «Удалить файлы книг с диска» определяет, удалятся ли вместе с записями сами файлы.
- **Отбор по языку и формату.** В фильтре столбца «Язык» или «Тип» можно включить «Исключить отмеченные». Например, отметьте FB2 и EPUB, чтобы увидеть книги остальных форматов. Проверьте результат, затем в меню книги выберите «Отметки и выделение → Отметить все». Отметятся книги из отфильтрованного списка.
- **Одно подтверждение для нескольких архивов.** При первом подтверждении удаления из общего архива можно нажать «Для всех архивов». Решение применяется к оставшимся архивам этой операции. Файлы по-прежнему проверяются, а операцию можно остановить.

## Дубли и серии

- **«Коллекция → Найти дубли книг…».** «Отдельные записи» — одна книга внесена в каталог несколько раз. «Файлы одной записи» — у книги одна запись и несколько файлов. В обоих списках можно отметить лишние копии перед общим удалением. Основная копия сохраняется.
- **Результат удаления дублей.** Теперь видно, почему часть отмеченных копий осталась. Например, запись изменилась после поиска, у неё есть личные данные или к ней привязаны неотмеченные файлы. Если 7z требует перепаковки, программа сохраняет этот архив и его записи, продолжает обработку остальных и указывает имя архива в итогах.
- **Длинные пути.** Исправлена обработка длинных путей к журналам удаления. Эти журналы нужны HomeLibre, чтобы продолжить прерванную операцию.
- **«Коллекция → Источники коллекции… → Объединить названия серий…».** Исправлены пробелы возле скобок, например «5-я волна (Азбука)». Перед объединением можно сохранить резервную копию и отчёт в выбранную папку.

## Карточка книги

- **«Изменить описание».** У книги из библиотечной коллекции теперь можно сохранить свой текст в HomeLibre. Начать можно с текущего описания, текста из файла или аннотации с сайта, если источник доступен.
- **«Отзывы».** В нижней панели книги кнопка «Загрузить» или «Обновить» теперь находится слева над отзывами.
- **Сведения об авторах FLibrary.** Достаточно один раз выбрать папку во вкладке «Об авторе». HomeLibre использует этот путь по умолчанию в новых коллекциях. Папка, заданная для отдельной коллекции, имеет приоритет.

## Обновление и модули

- **Скачивание и установка разделены.** После скачивания окно показывает «Установить и перезапустить». Enter сам по себе установку не запускает. Если нажать «Позже», готовый пакет можно снова открыть через меню обновлений. Пока идёт удаление книг, HomeLibre предложит дождаться его завершения.
- **«Помощь → Обновления программы и компонентов… → Модули…».** В окне удаления модулей можно отметить все позиции или снять все отметки одной кнопкой. Размер и состояние показаны в отдельных столбцах. Если в строке указано «Сверить состав», выберите модуль и нажмите «Проверить состав…». HomeLibre сверит установленные файлы с архивом модуля. Исправлен случай, когда файл AI-ассистента считался изменённым из-за устаревших сведений о его установке.

## Проверка выпуска

Обновление с beta 11 и скачивание с GitHub проверены для Windows x86 и x64. Отдельно проверено обновление HomeLibre Reader. Сценарии удаления из нескольких общих архивов с одним подтверждением и переноса ранее выбранной папки FLibrary в новую коллекцию ещё предстоит проверить от начала до конца.
