# HomeLib Ru pre5.26 — 2.7.0.1094

- История изменений первоначально показывает три выпуска. Кнопка «Показать ещё 3» добавляет следующую тройку; последняя порция может быть меньше. Уже раскрытые записи и положение чтения сохраняются. Заголовки и текст остальных выпусков создаются по мере запроса, что уменьшает начальную работу окна обновлений.
- Установленные версии компонентов показываются в принятом у автора виде: например, SumatraPDF 3.6.1 и 7-Zip 26.04. Сравнение версий для обновления по-прежнему использует полные числовые значения файлов.
- История DjVuLibre разделена на выпуски. При наличии сведений добавлена дата из каталога Windows-пакета SourceForge с явным указанием её источника; неизвестная дата не подменяется датой другой платформы или соседней версии.
- Окно обновления создаётся при обращении к нему, без скрытой подготовки во время обычного запуска программы. Подготовленное обновление по-прежнему обнаруживается при запуске, чтобы сохранить аварийное восстановление.
- Кэш истории записывается атомарно через уникальный временный файл. Ошибка записи сохраняет прежний кэш и не затрагивает чужой временный файл.
- При добавлении выпусков с клавиатуры фокус переходит к первой новой записи. Раскрытые разделы сохраняются при изменении масштаба и темы; загрузка истории в скрытом окне не вызывает ошибку установки фокуса.
- При смене масштаба главного окна перерисовка элементов откладывается до завершения выравнивания. При применении темы таблицы сразу получают окончательный цвет фона.
- Выбор компонента в обновляторе не пересчитывает неизменившуюся таблицу версий и не обновляет сводку повторно.

- Исправлено наложение области текста на обложку при уменьшении и увеличении нижней панели книги. Обложка и текст получают согласованные размеры за один расчёт.
- Колёсико прокручивает длинную аннотацию без смены фокуса, а у края текста — общую область сведений. Нижняя кнопка остаётся на месте.
- Кнопка «Сбросить фильтры столбцов» расположена слева от подписи «Язык» и списка выбора.
- Убрано повторное выравнивание уже размещённых элементов панели книги. Исправлена команда копирования при отсутствии выделенной строки или значения.
