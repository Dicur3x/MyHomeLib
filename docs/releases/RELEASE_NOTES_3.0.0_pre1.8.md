## Каталог и импорт

- **Добавляйте книги без копирования.** В окне импорта выберите «Оставить файлы на месте». Если книгу перенесли, откройте «Информация о книге → Файл» и нажмите «Указать новый путь…». Прогресс, описание и группы сохранятся. Удаление такой записи оставляет исходный файл на диске.
- **Включите столбец «Прочитано»**, чтобы видеть процент и сортировать книги по нему. Ключевые слова видны в карточке книги. Описание можно вписать вручную или взять из файла либо с сайта. Оно появится в нижней панели.
- **Импорт комиксов.** ZIP или 7z с изображениями страниц добавляется как одна книга. Повторный импорт сохраняет одну запись. В архиве с несколькими книгами по-прежнему можно выбрать нужный файл.
- **Исправления импорта и поиска.** EPUB с ошибочным расширением `.fb2` открывается по содержимому. Настоящие файлы контрольных сумм `.md5` пропускаются, а текстовые файлы с таким расширением можно читать. Каталог с относительными путями к файлам работает и при запуске из другой папки. Карточка и поиск открываются даже при ошибках в списке жанров, а назначенный книге жанр сохраняется.

## HomeLibre Reader

- **Плавная прокрутка.** При прокрутке колёсиком движение продолжается на стыке страниц. Стрелки работают после перехода между элементами окна.
- **Манга и сканы.** Длинная страница комикса подгоняется по ширине, а следующая подготавливается заранее. Поддерживаемые TIFF открываются постранично. Повторное открытие крупных FB2 с иллюстрациями требует меньше памяти.
- **Открытие книг.** Исправлено чтение текста, начинающегося со знака `<`, в том числе в «Анекдоты.7z». Крупные RTF открываются и сохраняются с иллюстрациями.
- **Окно компонентов.** Если закрыть его во время проверки обновлений, результат будет доступен при следующем открытии окна. Раньше окно могло появиться снова само. Открыть его вручную можно через «Настройки → Компоненты…».

## Сохранение книг

- **Меньше места на диске.** В «Сохранить как…» появился режим «Максимальная экономия». Отдельная галочка «Оттенки серого» убирает цвет из иллюстраций и сканов в выходной копии. Это может дополнительно уменьшить размер. «Оценить размер» учитывает галочку, поэтому после её переключения запустите оценку заново. Выбранные параметры сохраняются при установке необходимых модулей.
- **Размер больших сканов.** Для PDF со сканами оценка смотрит на часть страниц и показывает примерный диапазон. Если данных мало, программа указывает, что точность неизвестна. Сохранение PDF и DjVu обрабатывает страницы порциями и требует меньше памяти. Для уже серых сканов программа сохраняет оттенки в PNG без изменения пикселей.
- **Повреждённые FB2.** В небольших файлах программа исправляет однозначные ошибки разметки в рабочей копии. Если в конце отсутствуют закрывающие теги, она сохраняет доступный текст и предупреждает о возможном обрыве. Повреждённую картинку можно пропустить с вашего согласия. На её месте будет подпись, а подробности попадут в отчёт.
- **Форматы и оформление.** При экспорте FB3 сохраняются переносы строк. В старых HTML точнее переносятся вложенные списки. При преобразовании EPUB в FB2 быстрее обрабатываются книги с большим количеством иллюстраций. Из EPUB в MOBI и AZW3 переносится одна обложка, если вторая страница только дублирует её и на эту страницу нет ссылок.
- **FLibrary и PDF.** В EPUB из FLibrary восстанавливаются иллюстрации, в том числе когда одна картинка встречается несколько раз. Неполная копия в кэше создаётся заново. Исправлено создание PDF из EPUB, когда временная папка находится глубоко внутри других папок. Диалог установки WebView2 отображается по-русски, временные данные WebView2 удаляются после экспорта.
- **Понятнее причины ошибок.** При сбое DjVu видно, на каком этапе и на каких страницах он произошёл. При сбое записи MOBI или AZW3 причина остаётся видна даже в длинном отчёте.

## Архивы и удаление

- **Упаковка коллекций.** Лучше обрабатываются книги с необычными именами, без расширения и с дополнительными копиями. Если Windows не может создать файл с таким именем, программа может перенести архив целиком и сохранить точное имя книги внутри. Небольшие файлы и архивы сохраняются как есть, когда переупаковка увеличивает размер.
- **Поиск файлов внутри архивов.** Исправлено сопоставление имён с разным регистром, разделителями и завершающими символами. Для старых записей FLibrary дополнительно сверяется исходная позиция книги в архиве. Если внутри архива пустой файл, программа считает книгу недоступной и запоминает, где её искать после восстановления.
- **Удаление отдельных книг.** Перед изменением общего архива видно, сколько данных нужно перенести и сколько места займут временные данные для восстановления. Соседние книги сохраняются. Для FLibrary учитываются отдельные архивы обложек и иллюстраций. Для крупных 7z уменьшилось число отдельных записей данных для восстановления.
- **Удаление книги, которая сама является ZIP или 7z.** Такой архив удаляется целиком после изменения записи в каталоге. Если он нужен ещё одной записи, программа оставит его на диске.

## Обновление

- После прерванной установки обновлятор восстанавливает прежние файлы. Повтор старого отката сохраняет более свежую установку. Если эту же папку уже обновляют, вторую операцию можно повторить после завершения первой.
- Команда «Повторить проверку» проверяет только выбранный компонент. Ошибки фоновой проверки можно найти в диагностическом журнале. Каталогизатор для x86 и x64 можно скачать отдельно от читалки и обработчиков форматов.
