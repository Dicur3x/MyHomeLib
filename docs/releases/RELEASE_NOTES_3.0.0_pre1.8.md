## Каталог и импорт

- При импорте книги можно оставить файл на месте и сохранить в каталоге ссылку. Если файл переместили, в карточке книги на вкладке «Файл» можно указать новый путь. Сохраняются прогресс, описание и принадлежность к группам. Удаление записи-ссылки сохраняет исходный файл.
- В таблице книг можно включить столбец «Прочитано» и отсортировать книги по проценту. Ключевые слова видны в карточке книги. Описание можно ввести вручную или взять из файла либо с сайта, после чего оно появится в нижней панели.
- ZIP и 7z с изображениями страниц импортируются одной записью как комикс. Повторный импорт сохраняет одну запись. В смешанных архивах сохраняется выбор книги по вложениям.
- EPUB с ошибочным расширением `.fb2` распознаётся по содержимому. Файл контрольных сумм `.md5` отделяется от книги, а обычный текст с таким расширением можно прочитать. Исправлено разрешение относительных путей к коллекциям при запуске из другой папки.
- Если в списке жанров пропущен родитель или возник цикл, карточка и поиск открываются. Присвоенный книге жанр сохраняется.

## Чтение и сохранение

- Колёсико в режиме плавной прокрутки сохраняет движение на стыке страниц. Стрелки работают и после смены фокуса внутри окна. Длинные страницы комикса подгоняются по ширине, а следующая страница готовится заранее. Поддерживаемые TIFF читаются постранично средствами Windows.
- Закрытое окно компонентов читалки остаётся закрытым после завершения проверки. Команда доступна в «Настройках».
- Исправлено распознавание текстовых файлов, начинающихся со знака `<`, в том числе «Анекдоты.7z». Крупные RTF можно открыть и сохранить с иллюстрациями. При экспорте FB3 сохраняются переносы строк, а вложенные списки старых HTML обрабатываются корректнее.
- Для небольших FB2 однозначные ошибки разметки исправляются в рабочей копии. Если недостаёт завершающих тегов, сохраняется доступный текст с предупреждением о возможном обрыве. Для повреждённых изображений есть отдельное согласие на пропуск с пометкой в книге и записью в отчёте экспорта.
- В «Сохранить как» добавлены «Максимальная экономия» и отдельный переключатель «Оттенки серого». Доступные варианты зависят от формата назначения. Настройки сохраняются при докачке компонентов.
- Оценка большого PDF со сканами использует выборку страниц и показывает диапазон. Его ширина зависит от разброса размеров в выборке. При недостаточной выборке точность остаётся неизвестной. При сохранении PDF и DjVu память используется по частям, а PNG для уже серых сканов хранит один канал с теми же пикселями.
- Большие FB2 с иллюстрациями повторно открываются с меньшей нагрузкой на память. При преобразовании EPUB в FB2 список иллюстраций строится один раз. При ошибке DjVu показываются этап, страницы и код завершения декодера.
- В EPUB из FLibrary восстанавливаются точные пути к иллюстрациям, включая несколько ссылок на одну картинку. Фактический формат картинки записывается в манифест EPUB, старая неполная копия кэша пересоздаётся.
- При сохранении EPUB в MOBI или AZW3 обработчик убирает повторную страницу обложки, когда она действительно дублирует обложку и на неё нет ссылок. Причина сбоя Kindling видна даже в длинном отчёте.
- Экспорт EPUB в PDF через WebView2 работает и при глубоко вложенной временной папке. Исправлены русские надписи при установке среды. Временный профиль браузера удаляется после экспорта.

## Архивы и удаление

- Упаковка коллекций обрабатывает имена без расширения, необычные расширения и дополнительные копии одной книги. При слишком сложном для Windows имени возможен перенос исходного архива целиком с точным именем записи. Для небольшого файла или архива сохраняется исходный вариант, если новая упаковка занимает больше места.
- Сопоставление путей внутри архивов учитывает регистр, разделители и знаки в конце имени. У старой записи FLibrary проверяются имя и исходная позиция. Пустая запись архива считается недоступной, её расположение сохраняется для повторной обработки после восстановления файла.
- При удалении из общего архива программа показывает объём данных для переноса и ожидаемое место под журнал. Соседние книги сохраняются. В FLibrary учитываются отдельные архивы иллюстраций. Запись журнала крупных 7z выполняется более крупными порциями.
- Книга, хранящаяся целым ZIP или 7z, удаляется как отдельный файл после записи в каталоге. Если архив одновременно нужен другой записи, физическое удаление останавливается.

## Обновление

- После прерванной установки обновлятор восстанавливает прежние файлы. Повторный запуск завершённого отката сохраняет более свежую установку. Одну папку может обновлять только одна операция. Вторую можно повторить после её завершения.
- «Повторить проверку» заново проверяет выбранный компонент. Ошибки фоновой проверки записываются в диагностику. Каталогизатор для x86 и x64 по-прежнему поставляется отдельно от читалки и дополнительных обработчиков.
