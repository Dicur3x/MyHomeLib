## Каталог

- **Последнее открытие.** В меню заголовка списка можно включить столбец с датой и отсортировать книги по нему. Дата сохраняется при открытии из каталога во встроенной или внешней читалке. В поиске фильтр «Дата» теперь называется «Дата добавления».
- **Карточка книги.** Описание сразу видно под основными сведениями. Двойной щелчок по описанию больше не открывает пустую таблицу. Иллюстрации можно листать колёсиком.
- **Названия серий.** Программа лучше находит варианты одной серии, которые различаются скобками, тире или написанием «е/ё». При сопоставлении проверяется, есть ли у серий общие книги.

## Повторные записи и файлы

- После объединения записей можно нажать «Найти дополнительные копии» и выбрать, какие связанные файлы удалить с диска. Основная книга со звёздочкой остаётся в каталоге вместе с её личными данными. За одну операцию можно отметить до 5 000 копий.
- Массовая отметка дополнительных копий выбирает файлы только указанного источника. Источники с одинаковым названием различаются по папке. При поиске ещё не объединённых записей автоматическая отметка действует на пары из двух известных источников. Для групп с тремя и более копиями выбор делается вручную.
- Из общего архива удаляются выбранные книги. Если в архиве не осталось файлов, программа удаляет его целиком. При обработке архивов FLibrary учитываются отдельные обложки и иллюстрации.

## HomeLibre Reader

- **Манга и комиксы.** Для длинных страниц доступен исходный масштаб 100%. При плавной прокрутке вверх на стыке страниц больше не теряется часть изображения.
- **Полный экран.** Когда интерфейс скрыт, подведите указатель к верхнему краю, чтобы вернуть его, или к нижнему, чтобы перейти к нужному месту по полосе прогресса. Команда «Показать интерфейс» также доступна по правому щелчку.
- **Открытие архивов.** При запуске читалки с архивом отмена выбора вложенной книги закрывает запущенное для него окно.

## Сохранение и обновление

- **Оценка размера.** Для иллюстрированных FB2 и EPUB расчёт учитывает сочетание JPEG и PNG. Разные режимы сжатия теперь дают разные оценки там, где размер копии действительно меняется. Исправление входит в обновление модуля BookProcessing.
- **Проверка обновлений.** Если закрыть окно обновлений каталогизатора во время проверки, оно больше не появится само после её завершения. Результат виден при следующем открытии окна.
