# HomeLib Ru 2.7.0_pre5.05

Версия EXE: **2.7.0.1072**.

Исправлена онлайн-загрузка книг по [issue #8](https://github.com/Dicur3x/MyHomeLib/issues/8).
После перехода на новую сетевую библиотеку программа ошибочно кодировала
адрес целиком: `http://...` превращался в `http%3A%2F%2F...`, что вызывало
`Invalid URL` ещё до отправки запроса.

- Исправлены оба способа загрузки: GET и POST.
- Сохранены подстановка макросов, перенаправления и `GET %RESURL%`.
- Уже закодированные части адреса не кодируются повторно; кириллицу и
  пробелы обрабатывает штатный HTTP-клиент.
- **Менять `collection.info`, пересоздавать INPX или переимпортировать
  коллекцию для этого исправления не требуется.** Достаточно обновить программу.

Проверка воспроизводит сценарий из приложенного `collection.info` на локальном
сервере, без загрузки чужих книг и без изменений пользовательской коллекции.
Доступность самой Флибусты из сети пользователя не проверялась: её ограничения,
недоступный домен или настройки прокси могут вызывать отдельные ошибки.

Закройте HomeLib Ru перед обновлением. Архив **HomeLibRu.zip** предназначен
для x86, **HomeLibRu_x64.zip** для x64. Рекомендуется резервная копия профиля
и коллекций. Предыдущие исправления и совместимость баз сохранены.
