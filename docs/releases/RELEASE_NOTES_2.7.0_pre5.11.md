# HomeLib Ru 2.7.0 pre5.11

Полноценное обновление внутри программы, обычные Win32/Win64, EXE 2.7.0.1078.

- Автоматическая проверка GitHub Releases по расписанию: «Никогда», 15 минут,
  час, 6/12 часов, сутки, 3 дня, неделя или свой интервал в минутах, часах и днях.
  Последняя попытка сохраняется между запусками. Ручная проверка принудительная
  при любом расписании: сообщает об актуальной версии или ошибке; автоматическая
  проверка в этих случаях остаётся тихой.
- Одно окно с текущей версией и описаниями выпусков с GitHub, новые первыми.
  Если пропущено несколько версий, объединены изменения всех пропущенных
  выпусков. До ответа сервера видна сохранённая история либо история из поставки.
- Скачивание начинается по кнопке. Видны полоса прогресса и «Скачано: 12,4 / 28,0 МБ».
  Загрузку можно отменить; после проверки доступны «Установить и перезапустить»
  и «Позже». Отложенный готовый архив сохраняется между запусками.
- При установке заменяются только файлы поставки, в том числе SQLite, читалки
  и справка. Настройки, коллекции, пресеты, portable-маркеры и история чтения
  сохраняются. Проверяются SHA-256, содержимое архива, версия и разрядность EXE;
  перед заменой создаются резервные копии, при ошибке выполняется откат.
  Вспомогательный EXE ждёт штатного выхода и запускает прежний профиль;
  отдельного мастера установки нет.
- Независимая проверка SQLite и SumatraPDF на официальных источниках авторов:
  установленная и новая версия, изменения автора, скачивание по кнопке и
  установка с перезапуском. Выбирается разрядность запущенного HomeLib Ru;
  для SumatraPDF исключены предварительные версии. SQLite проверяется по
  SHA3-256 автора, SumatraPDF — по цифровой подписи издателя. Настройки и
  история читалки сохраняются. Обновление всей программы не понижает версии
  компонентов, уже обновлённых отдельно.
- Ошибки источников разделены: недоступность одного компонента не мешает
  остальным. Ручная проверка показывает причину, фоновая остаётся тихой.
  Отдельная проверка AlReader отключена по решению владельца: официальный
  Windows-источник недоступен. Встроенная читалка сохранена в полной поставке.

Закройте читалки перед установкой. Папка программы должна быть доступна для
записи; если это невозможно, используйте ZIP со страницы выпуска. Механизм
применяется к следующим выпускам с манифестом обновления. pre5.10 и более ранние
версии для перехода на pre5.11 требуют обычного скачивания ZIP.

Встроенные читалки в этом выпуске не заменены. SumatraPDF 3.6.1 совпадает
с текущей стабильной версией на официальной странице. Получить официальный
Windows-архив AlReader и подтвердить его версию не удалось; Android-версии
не являются заменой Win32.

Русский интерфейс, название HomeLib Ru и оригинальное авторство Олексій Пеньков
сохранены. Личные библиотеки не индексировались; предыдущие ZIP не изменялись.
