## Читалка

- В меню «Вид → Режим чтения» появилась «Плавная прокрутка». Колесо мыши и стрелки вверх и вниз плавно сдвигают содержимое, в том числе при переходе на следующую или предыдущую страницу. Страницы идут в одну колонку. В режиме перелистывания колесо и стрелки по-прежнему меняют страницу.
- В меню «Настройки → Цвета темы» можно выбрать цвет текста и фона. Цвета сохраняются отдельно для каждой темы, там же можно вернуть исходные цвета.

## Поиск

- Кнопка «Применить» при пустых полях показывает книги текущей коллекции. Настройка «Скрывать удалённые» учитывается. Раньше при выключенной настройке появлялось сообщение о синтаксической ошибке.

## Импорт книг

- Одну книгу или несколько файлов можно перетащить из Проводника в список книг HomeLibre. Перед импортом программа показывает, в какую локальную коллекцию добавит файлы, и ждёт подтверждения.
- Исправлено русское название ярлыка «Отправить → Добавить в HomeLibre». Если ярлык уже создан в beta 5, повторное включение через «Коллекция → Импорт → Ярлык импорта в меню „Отправить“» исправит имя существующего ярлыка для этой установки.
