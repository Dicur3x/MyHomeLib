## Сжатие коллекций, включая USR

- Команда «Сжать коллекцию…» лучше упаковывает смешанные ZIP. Текстовые книги сжимаются отдельно, а двоичные файлы сохраняют сжатие там, где оно экономит место. Если новый архив получился таким же или больше, программа берёт исходный архив для копии коллекции.
- Для DOC, PPT, TIFF и ряда других форматов программа пробует LZMA. Для MHT, MOBI, AZW3 и PDB она пробует PPMd. При малом выигрыше выбирается обычная упаковка. Оба метода сохраняют файлы побайтово. Для чтения таких записей HomeLibre использует компонент 7-Zip.
- Режим «JPEG XL» теперь может обратимо сжимать подходящие JPEG внутри PDF. Программа использует этот вариант, если архив становится меньше. При открытии она восстанавливает обычный PDF и сверяет его с контрольной суммой исходника. PDF без подходящих изображений проходят обычную обратимую упаковку.
- «Максимальная экономия» теперь уменьшает детализацию фона подходящих сканов DjVu. Размеры страниц, отдельный слой с буквами, распознанный текст и оглавление сохраняются. Мелкие детали фона могут измениться. Выигрыш виден в размере архива коллекции, а размер распакованного DjVu остаётся прежним.
- При обновлении коллекции из INPX неизменившиеся готовые архивы можно использовать повторно. Исходные книги остаются на месте, упакованная коллекция создаётся отдельно.

## Открытие и сохранение книг

- PDF из новой упаковки JPEG XL можно открыть из каталога или отдельно из 7z, сохранить в исходном формате и получить через OPDS. Для восстановления HomeLibre предложит декодер JPEG XL, если он ещё отсутствует.
- Преобразование упакованного PDF в режиме «Без изображений» тоже сначала восстанавливает исходный PDF, чтобы прочитать текст и структуру страниц. При повторном открытии читалка обновляет старую запись кэша для такого PDF.

## Установка и обновление

- Для новой упаковки HomeLibre предложит обновить модуль подготовки книг BookProcessing до 3.0.0.7. Модуль изображений и кодеки докачиваются по необходимости выбранного режима. После установки программа восстанавливает выбранные параметры упаковки.
- Каталогизатор и отдельная читалка читают новые архивы коллекций. Читалка устанавливается отдельно. Обновлённый каталогизатор и читалка доступны для Windows x86 и x64.
