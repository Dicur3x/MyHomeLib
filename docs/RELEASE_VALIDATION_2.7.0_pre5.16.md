# Проверки HomeLib Ru pre5.16 / 2.7.0.1084

Проверена сборка Win32 и Win64 от 13 октября 2026 года. Delphi-проекты
собраны через RAD Studio. Проверки работают в отдельных профилях; книги
и рабочие пользовательские каталоги не входят в публикуемые архивы.

## Установка и обновления

| Проверка | Результат |
| --- | --- |
| Автоматическая установка шести отдельных компонентов | 25 сценариев в каждой разрядности |
| Обновление программы, отмена, занятые файлы, ошибки и восстановление | 47 сценариев в каждой разрядности |
| Настоящий архив поверх pre5.15 | Win32: 502 файла поставки; Win64: 511; по 17 файлов профиля и библиотек сохранены побайтно |
| Основная программа вместе с шестью компонентами; только компоненты; ошибка посреди операции | Все три сценария прошли для обеих разрядностей |
| Официальные сведения о версиях компонентов | 10 проверок в каждой разрядности |
| Таблица компонентов и большая вкладка изменений | Светлая и тёмная темы, повторное открытие, выбор компонента, масштаб, сохранение размеров и истории |

Выпуск включает два основных ZIP, двенадцать ZIP компонентов, общий файл
`HomeLibRu.components.json` и `SHA256.txt`. Проверены CRC, все файлы манифеста,
их размеры и SHA256, разрядность EXE/DLL и версия основной программы.
Личные настройки, базы, книги, заметки и история исключены из поставки.

Проверка новой версии у автора и установка совместимого пакета различаются.
Например, сообщение о более новой DocSharp не означает, что её DLL можно
без проверки заменить по отдельности. Устанавливается согласованный пакет
обработчика, двух библиотек и лицензий. Более новый независимо установленный
компонент не заменяется старой версией из архива программы.

## Читалка и общий интерфейс

- Реальное выделение и копирование FB2, EPUB, TXT и Unicode/эмодзи в обеих
  темах. Продолжение абзаца сверено по нарисованным буквам отдельным эталоном.
- PDF: одинаковая полупрозрачная подсветка всех затронутых пикселей, точная
  цитата, контраст текста 10,50 в светлой теме и 6,87 в тёмной.
  В каждой разрядности выполнены 384 полных открытия PDF. После прогрева
  оконные ресурсы остаются в установленном диапазоне, окна читалки не остаются.
- PDF обрабатывается отдельным процессом с ограниченным кэшем. На проверенном
  скане максимальная задержка обработки интерфейса была 96 мс в Win64
  и 125 мс в Win32; двенадцать повторных отрисовок — 9–12 мс суммарно.
- Большая FB2: 40 перелистываний — максимум 30 мс; 40 случайных переходов
  и 40 переходов по поиску — максимум 46 мс в последнем замере Win64.
  Первое открытие остаётся отдельной операцией и не объявляется мгновенным.
- DOC: текст из 579 196 символов совпал с независимым эталоном. Подготовка
  около 1,7–1,8 с; повторная подготовка использует кэш. LibreOffice для
  этого пути не нужен. Защищённые, повреждённые и неподдерживаемые старые
  документы завершаются понятной ошибкой.
- DjVu: корректная пустая страница сверена с официальным `ddjvu`;
  40 страниц — среднее 13 мс, максимум 51 мс в отдельной проверке обработчика.
- Оглавление открывается одним деревом через кнопку, стрелку и клавиатуру;
  собственные номера книги сохраняются. Проверены родительский контекст,
  поиск, текущий раздел и навигация по полосе прогресса.
- Приближение: удержание/отпускание, потеря захвата мыши, выход за окно,
  повторный щелчок, отмена и смена темы.
- Заметки: сохранение, цитаты, TXT/HTML/DOCX, четыре оформления экспорта,
  резервная копия, повреждённый файл и параллельные изменения.
- Основное окно: отменённое и повреждённое открытие возвращает доступное
  главное окно; исходные файлы сохраняются. Сортировка автора/названия,
  края столбцов, явные флажки фильтра и размеры его окна проверены.
- На 50 000 строках повторные действия главного окна не обходят каталог.
  Общий путь проверен для 52 расширений; PDF, DjVu, EPUB, TXT, FB2 и DOC
  дополнительно открывались из главного окна с фильтром и без него.

Полный офлайн-набор нативных проверок прошёл в обеих разрядностях.
Win32 дополнительно перепроверен после финального изменения номера выпуска;
Win64 полный набор выполнен на окончательном графе исходников pre5.16.
Размеры интерфейса 100/150/200% моделировались вызовами масштабирования;
после смены темы Windows сообщает 96 PPI. Это не измерение на физическом
мониторе с другой плотностью.

## Объединение и сохранность

На отдельных копиях обработаны 2 146 189 записей из трёх источников.
Исходная цель содержала 1 465 776 книг; итог — 1 856 990 книг.
Применение заняло 638,407 с вместо 756,421 с; обновление существующих
карточек — 95,239 с вместо 188,236 с. Предпросмотр в этом полном запуске
занял 305,250 с, поэтому его общее время не стало лучше. Причина различия
времени чтения отдельно не установлена.

После удаления повторных запросов предпросмотр на прогретых данных занял
39,344 с: 391 214 новых записей, 1 754 975 повторных, 0 конфликтов.
Повторный предпросмотр актуальных каталогов сохранил все четыре файла
побайтно. Эти разные измерения не следует складывать в обещание одинаковой
скорости на любом компьютере.

Итог сопоставлен по всем 32 содержательным полям каждой книги. Проверены
исходные таблицы, существующие ID, дополнительные серии, связи, группы,
настройки и пользовательский прогресс. Непустые личные отзывы, оценки,
групповые карточки, отмена и ошибки записи покрыты отдельными случаями.
В большом исходном наборе таких непустых личных карточек не было.

Исправление открытия базы сравнивает точное определение трёх служебных
триггеров. Актуальное определение не переписывается, старое исправляется
один раз внутри savepoint. Проверены четыре повторных открытия,
`schema_version`, `data_version`, целостность и все пользовательские поля.

## Группы изменений для отдельного отката

| Группа | Основные исходники |
| --- | --- |
| Установка компонентов и вкладки обновлений | `frm_ProgramUpdate`, `unit_ComponentUpdates`, `unit_ProgramUpdates`, `unit_ProgramUpdateInstaller`, сценарии упаковки компонентов |
| Быстрый DOC | `unit_ReaderDOC`, маршруты ReaderOffice/ReaderFormats/ReaderLaunch, `Utils/HomeLibDoc`, DOC_RUNTIME и лицензии |
| PDF в отдельном процессе | `unit_ReaderPDFAsync`, `unit_ReaderPDFWorker`, `unit_PDFProtocol`, `unit_ReaderPDF`, `Utils/HomeLibPDF` |
| Выделение текста | `unit_ReaderPageSelection`, `unit_ReaderRichEdit`, подключение в `frm_BuiltinReader` |
| Дерево оглавления, приближение и подписи | соответствующие классы и обработчики `frm_BuiltinReader` |
| Скорость действий отфильтрованного списка | `BookTreeView.ActionVersion`, кэш `UpdateBookAction` в `frm_main` |
| Изменённые поля карточки и предпросмотр | интерфейс delta-updater, `unit_CollectionMerge`, реализация SQLite |
| Служебные триггеры | `EnsureTrigger` в `unit_Database_SQLite` |
| Источники и проверка серий | `frm_CatalogSources`, `unit_SeriesAliases` |

При откате кода пользовательские базы и профили остаются текущими.
Резервные копии данных не следует автоматически возвращать поверх более
новых заметок, истории или изменений коллекции.
