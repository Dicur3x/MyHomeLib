# Проверки HomeLibre 3.0 beta 4

Выпуск `3.0.0_pre1.4`, версия файлов Windows `3.0.0.4`.

| Windows | Архив | SHA-256 |
| --- | --- | --- |
| x86 | `HomeLibre.zip` | `ee30e3a4caf5d04e3d11279bfa99bf4a3c430d81dc223f9ce4cc6249ce29f0c8` |
| x64 | `HomeLibre_x64.zip` | `439b1f6cb317dc91017215343917bde65125cf948b618f8e0bc8a0fdd403b312` |

- На x86 и x64 помощник из опубликованной beta 3 установил итоговый минимальный архив и запустил beta 4. Проверены содержимое установленной папки, тестовый каталог, личные данные и настройки. Читалка, MCP и дополнительные обработчики устанавливаются отдельно. Сжатие коллекций отложено до следующего этапа.
- На обеих разрядностях проверены ручная высота сведений о книге, возврат к автоподбору, загрузка и обновление отзывов в нижней панели, оценки и скрытие авторов. Высота сохраняется после перезапуска, отзывы берутся с сайта коллекции.
- Проверены прямой OPDS HTTPS и доступ через внешний HTTPS-прокси. Тестовый клиент получил каталог и результаты поиска и скачал книгу побайтно. Остановка закрыла порт. Прямой режим использует пользовательский сертификат и ключ в PEM. Прокси работает с заданным публичным HTTPS-адресом и локальным HTTP-подключением к HomeLibre.
- Удаление проверялось на временных книгах и архивах, включая сохранность соседних записей и восстановление после прерывания. Прогон через обычное окно подключённой локальной коллекции не подтвердил доступность команды удаления в этом сценарии. Реальная коллекция пользователя не менялась.
- Финальные тестовые программы из исходников выпуска на x86 и x64 проверили обычное сохранение FB2/EPUB/PDF/DjVu/DOC, ZIP, оценку, смешанные наборы, настройки, отмену, замену файлов, TXT, MOBI, AZW3, KEPUB и PDF. Для конвертации использованы итоговые архивы модулей. Проверены побайтовые копии и неизменность оригиналов.
- KEPUB, KFX и AZW8 проверялись по созданным файлам. Физические Kobo и Kindle в проверках не участвовали. Для PDF из EPUB проверен отказ от установки WebView2 с сохранением настроек. Установка самого WebView2 на чистой Windows остаётся непроверенной.
- Замеры скорости делались отдельно на общем компьютере и с прогретым дисковым кэшем. Они не подтверждают ускорение относительно предыдущего выпуска.
