# Проверки HomeLibre 3.0 beta 6

Тег выпуска `3.0.0_pre1.6`, версия файлов Windows `3.0.0.6`.

| Windows | Архив | SHA-256 |
| --- | --- | --- |
| x86 | `HomeLibre.zip` | `7db156f66c9bada64a3c0aa5824ab24cf14ad7c84bf20a1a756f034a4db7a63d` |
| x64 | `HomeLibre_x64.zip` | `deaca14a447b36c1f55354ce1315413b2d11dbb41456bbfd979bc988d4681b1b` |

- **Обновление.** Обе сборки beta 5 приняли соответствующий архив beta 6 через окно обновлений, перезапустились и открыли прежнюю тестовую коллекцию с сохранёнными настройками. После публикации штатный код обновлятора скачал оба архива с GitHub и проверил их по манифестам. Список изменений отображается в окне обновлений на x86 и x64.
- **Читалка.** Проверены плавная прокрутка колёсиком и клавишами, положение чтения, выделение текста и отдельные цвета тем. Для PDF, DjVu, CBZ, TIFF, EPUB, TXT и RTF проверены промежуточные положения при прокрутке. На обеих архитектурах проверены отдельное обновление Reader и докачка PDFium при первом открытии PDF в чистой установке.
- **Поиск и импорт.** Проверены пустой запрос с обеими настройками видимости удалённых книг, импорт двух файлов через системный обработчик перетаскивания, выбор коллекции и отказ от импорта. На x64 отдельно проверено «Отправить → Добавить в HomeLibre» из Проводника. Ручной жест перетаскивания между окнами и ярлык из Проводника на x86 отдельно не подтверждены.
- **Ограничения проверки.** Сценарий «Сохранить как» с установкой сразу двух модулей и продолжением операции не удалось повторить через интерфейс beta 6. Срабатывание мониторинга Kaspersky на beta 4 удалось сопоставить с опубликованным EXE по контрольной сумме. Причину и повторяемость срабатывания на beta 6 не проверяли в Kaspersky.
