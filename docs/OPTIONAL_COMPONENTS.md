# Необязательные компоненты HomeLib Ru

Базовые `HomeLibRu.zip` и `HomeLibRu_x64.zip` собираются без AlReader,
SumatraPDF, сторонних декодеров DjVuLibre и DocSharp и набора шрифтов.
Каталог, встроенная читалка, PDF и средства распаковки/конвертации остаются
в базовом комплекте. Для полностью автономной установки предусмотрен
параметр `-Full` у `scripts/package-release.ps1`: имена архивов получают
суффикс `_full`.

Отсутствующая необязательная библиотека не означает повреждение установки
и не запускает восстановление полного комплекта. По умолчанию она также
не проверяется в автоматическом цикле. На строке каждого из четырёх
компонентов есть собственный переключатель «Сообщать об обновлениях этого
компонента». Уведомления действуют для установленного исправного компонента.
Ручная кнопка «Проверить всё» позволяет проверить доступность всех компонентов.

При открытии DjVu либо старого бинарного DOC/PPT/XLS встроенная читалка
проверяет только необходимые для этого формата файлы. Если библиотеки нет,
открывается её строка обновлятора с объяснением, размером загрузки и кнопкой
«Скачать компонент». Автоматического скачивания нет. Установка выполняется
существующим механизмом с проверкой архива, журналом и откатом; после неё
нужно перезапустить HomeLib Ru и снова открыть книгу. FB2/EPUB/TXT и офисные
XML-форматы не требуют DocSharp. В меню «Открыть с помощью» отсутствующие
AlReader и SumatraPDF можно выбрать для отдельной установки; этот выбор
не сохраняется как путь к исполняемому файлу.

## Источники и публикация

Для доступных выпусков используются прежние официальные источники.
Резервное зеркало — только проверяемые assets репозитория
`Dicur3x/MyHomeLib`. Произвольные сторонние сайты не принимаются.
Для AlReader зеркало содержит ту же Windows-версию, которая уже входила
в проверенные полные архивы. Это не объявляется новым выпуском автора.

После сборки обоих runtime:

```powershell
./scripts/package-components.ps1 -Release <новый-тег> -OutputDirectory <папка>
```

Скрипт проверяет исходные runtime, создаёт восемь ZIP (четыре компонента
для двух архитектур) и `HomeLibRu.components.json`. В feed записываются
точные версии из созданных ZIP. Сохраняются лицензии; файлы пользовательских
профилей читалок не копируются. При публикации нужно добавить все девять
файлов в тот же выпуск, где доступны базовые архивы, и включить их SHA-256
в список контрольных сумм. Этот документ и сборка не выполняют публикацию.

Клиент принимает URL, размер и SHA-256 ZIP только из соответствующего
актуального GitHub asset. Проверяются репозиторий, тег, точное имя архива,
платформа, перечень файлов, контрольные суммы и идентичность бинарных файлов.
Описание feed само по себе не может указать сторонний адрес или хеш.

## Нативная проверка

`native_collection_tests.js --views-mode=optional-components` требует
`--optional-fixtures=<папка созданных пакетов>`. Дополнительный
`--minimal-fixture=<базовый ZIP той же архитектуры>` проверяет установку
базового обновления поверх уже установленных четырёх компонентов с
сохранением их файлов, настроек читалки и личной книги. Проверки используют
только помеченную временную установку. Реальные пользовательские коллекции
не являются целью установщика в этих сценариях.

Проверки выполнены 21.10.2026 для x86 и x64: реальные ZIP, откат после
искусственной ошибки, сохранение личных файлов и настроек читалок,
уведомления по выбору, запрос библиотеки и явное подтверждение загрузки,
светлая/тёмная тема при 96/144/192 PPI и проверка адресов зеркала.
Восстановление обязательных файлов и отложенный запуск также прошли.
Оба минимальных архива запущены как настоящая программа и закрыты обычным
способом; временные профили и распакованные исходники удалены автоматически.
Подробные результаты, хеши сборок и ограничения сохранены в
`audits/2026-10-21-optional-components.json`. Минимальные комплекты и восемь
архивов компонентов опубликованы в [pre5.30](https://github.com/Dicur3x/MyHomeLib/releases/tag/2.7.0_pre5.30).
Проверки готовых архивов и установки: `audits/2026-10-21-pre530-final.json`.
