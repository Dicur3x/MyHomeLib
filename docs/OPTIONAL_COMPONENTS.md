# Необязательные компоненты HomeLibre

Компактная и полная поставки готовятся отдельно для Win32 и Win64.
Начиная с beta 16 компактные архивы называются `HomeLibre_compact.zip` и
`HomeLibre_x64_compact.zip`. Из них можно запустить HomeLibre после распаковки.
Эти же ZIP использует встроенное обновление. Читалки, декодеры, конвертеры и
шрифты устанавливаются по выбору пользователя.

В beta 14 и beta 15 компактные архивы имели суффикс `_portable`. В выпуске
beta 14 также есть `HomeLibre.zip` и `HomeLibre_x64.zip` для перехода со старых версий.

Для автономной установки `scripts/package-release.ps1 -Full` готовит
`HomeLibre_full.zip` и `HomeLibre_x64_full.zip`. Полный комплект требует
явного списка пакетов модулей с SHA-256 (`-OfflineComponents`) и закреплённых
полных установщиков Microsoft (`-OfflinePrerequisiteInputs`); при необходимости
задаётся штатный нативный проверяющий (`-OfflineVerifier`). Пакеты и общие runtime
проверяются до сборки. Произвольные файлы установленной программы в полный ZIP
не добавляются. Большие временные данные направляются через `-WorkingDirectory`.

Оба комплекта доступны в [последнем выпуске HomeLibre](https://github.com/Dicur3x/MyHomeLib/releases/latest).
Окончательные приложения, установка системных сред на чистой Windows, работа
без сети, лицензии и обновление прежней установки проверяются отдельно.

Отсутствующая необязательная библиотека не означает повреждение установки
и не запускает восстановление полного комплекта. По умолчанию она также
не проверяется в автоматическом цикле. На строке каждого
компонентов есть собственный переключатель «Сообщать об обновлениях этого
компонента». Уведомления действуют для установленного исправного компонента.
Ручная кнопка «Проверить всё» позволяет проверить доступность всех компонентов.

При открытии DjVu либо старого бинарного DOC/PPT/XLS встроенная читалка
проверяет только необходимые для этого формата файлы. Если библиотеки нет,
открывается её строка обновлятора с объяснением, размером загрузки и кнопкой
«Скачать компонент». Автоматического скачивания нет. Установка выполняется
существующим механизмом с проверкой архива, журналом и откатом; после неё
может потребоваться перезапуск HomeLibre. FB2/EPUB/TXT и офисные
XML-форматы не требуют DocSharp. В меню «Открыть с помощью» отсутствующие
AlReader и SumatraPDF можно выбрать для отдельной установки; этот выбор
не сохраняется как путь к исполняемому файлу.

## Источники и публикация

Компоненты скачиваются из официальных источников авторов: SumatraPDF —
с сайта SumatraPDF, DjVuLibre — из проекта автора на SourceForge,
DocSharp — из официальных пакетов автора в NuGet. SQLite и 7-Zip также
используют официальные источники. Если источник недоступен, установленный
компонент сохраняется, а ошибка проверки не подменяется чужим выпуском.

Основные архивы и контрольные суммы публикуются в выпуске программы.
Пакеты модулей и их описание находятся на отдельной постоянной
[странице компонентов](https://github.com/Dicur3x/MyHomeLib/releases/tag/optional-alreader-2.5.1009.25).
Они не дублируются при каждом выпуске каталога. Историческое имя тега и
`HomeLibRu.components.json` сохраняют адреса для прежних клиентов; оно
не означает, что страница содержит только AlReader.

Для новых клиентов версия Reader находится в ветке `minimal_reader` описания.
Основная запись `HomeLibReader` может сохранять совместимый пакет для прежних
обновляторов. Видимое название HomeLibre Reader и файл `HomeLibreReader.exe`
не требуют механического переименования прежнего ID протокола. До удаления
старого архива проверяются действующее описание, резервные описания и ссылки
прежних клиентов. Наличие более новой версии само по себе не доказывает,
что старую можно удалить.

Для AlReader по явному запросу владельца предусмотрено одно постоянное зеркало:
`optional-alreader-2.5.1009.25/AlReader-2.5.1009.25.zip` на GitHub проекта.
Это сохранённый Windows-выпуск 2.5.1009.25 из прежней проверенной поставки,
не новая версия автора. Один архив с платформой `AnyWindows` допускается
только для AlReader; установщик проверяет версию x86 EXE/DLL на обоих хостах,
список файлов, размеры и все хеши. SHA-256 всего архива фиксирован в коде.
Личные настройки существующей читалки сохраняются. Архив не повторяется
в релизах программы, общий поиск зеркал по релизам не используется.

7-Zip нужен для 7z, PPMd ZIP, RAR/CAB и сжатых метаданных; обычный ZIP
распаковывается встроенными средствами. Первая установка скачивает с GitHub
автора установщик и небольшой 7zr.exe из того же выпуска. Обе контрольные
суммы проверяются до запуска 7zr; скачанный установщик не запускается.
Полный 7z.exe имеет приоритет над оставшимся от прежних выпусков 7za.exe.
Для подготовки DjVuLibre без распаковщика сначала предлагается установить
7-Zip с понятным объяснением зависимости. При заполнении сведений и индексации
книжных серий отсутствие декодера останавливает весь проход и передаёт один
запрос установки после завершения потоков и закрытия модальных окон; оно
не превращается в ошибку каждой книги. Уже сохранённые изменения учитываются.

`scripts/package-components.ps1` готовит ограниченный набор прежних пакетов
AlReader/SumatraPDF/DjVuLibre/DocSharp. Он не заменяет полный список входов
автономной поставки и окончательную проверку всех выпускаемых модулей.

## Исторические нативные проверки (21 октября 2026)

`native_collection_tests.js --views-mode=optional-components` требует
`--optional-fixtures=<папка созданных пакетов>`. Дополнительный
`--minimal-fixture=<базовый ZIP той же архитектуры>` проверяет установку
базового обновления поверх уже установленных четырёх компонентов с
сохранением их файлов, настроек читалки и личной книги. Проверки используют
только помеченную временную установку. Реальные пользовательские коллекции
не являются целью установщика в этих сценариях.

Проверки выполнены 21.10.2026 для x86 и x64: реальные ZIP, откат после
искусственной ошибки, сохранение личных файлов и настроек читалок,
уведомления по выбору, запрос библиотеки и явное подтверждение загрузки,
светлая/тёмная тема при 96/144/192 PPI и проверка адресов зеркала.
Восстановление обязательных файлов и отложенный запуск также прошли.
Оба минимальных архива запущены как настоящая программа и закрыты обычным
способом; временные профили и распакованные исходники удалены автоматически.
Подробные результаты, хеши сборок и ограничения сохранены в
`audits/2026-10-21-optional-components.json`. В [pre5.30](https://github.com/Dicur3x/MyHomeLib/releases/tag/2.7.0_pre5.30)
оставлены только два основных архива и контрольные суммы. Исторические аудиты
фиксируют первоначальную проверку до удаления зеркала.
Проверки готовых архивов и установки: `audits/2026-10-21-pre530-final.json`.
