# Проверки HomeLib Ru pre5.27 — 2.7.0.1095

Выпуск посвящён ускорению запуска. Программа и помощник обновления заново собраны через Delphi 13 GUI для x86/x64. Версии EXE, архитектуры и совпадение упакованных файлов с этими сборками проверены.

- Девять связанных нативных режимов на каждой архитектуре: фоновый запуск, восстановление издательской вкладки, запасная коллекция, закрытие при загрузке, первый запуск и его отмена, источники книг, окно обновлений и восстановление компонентов. Проверки включают обе темы и 96/144/192 PPI там, где это предусмотрено соответствующим режимом.
- Оба фактических ZIP установлены поверх опубликованной pre5.26. Во всех случаях сохранены 19 контрольных файлов профиля и библиотеки.
- По восемь случаев восстановления/сохранения компонентов на каждом архиве: отсутствующие компоненты, сохранение полной более новой поставки 7-Zip и восстановление её неполной поставки.
- Проверены CRC, безопасные уникальные пути, полный манифест, размеры и SHA-256 всех 529/538 файлов, архитектура основных EXE/DLL и история восьми выпусков. AlReader без изменений.
- Оба EXE из ZIP отдельно запущены через обычный интерфейс с собственной искусственной библиотекой. Показаны авторы, выбранная книга и панель информации; штатное закрытие проверено.

[Итоговые результаты, попытки и SHA-256](audits/2026-10-20-pre527-final.json).

Первый запуск проверки восстановления Win64 остановился до запуска нативного теста: не был подготовлен файл новых тестовых компонентов. После подготовки из проверенного ZIP режим повторён без изменения исходников и порогов; обе попытки сохранены в отчёте.

Предыдущая проверка самого ускорения — [отдельный отчёт](audits/2026-10-20-startup-fix.json): 34 прогона связанных сценариев и 12 заключительных проверок запуска, затем обычные Release-сборки обеих архитектур. Исходники ускорения совпадают с этим проверенным коммитом; новый выпуск меняет номер версии и поставку. Это не новый полный аудит всех функций программы.

На копии каталога из 1 856 990 книг диагностическое время появления окна уменьшилось с 6,9–7,2 до 2,6–2,8 с; начальная фоновая загрузка завершалась примерно за 4,7–5,1 с от входа в программу. Замеры сделаны внутри процесса на одной машине, без отдельного холодного кэша; проверка образа Windows до входа в программу в них не входит. Создание и привязка VCL-элементов остаются в основном потоке: измеренные короткие паузы около 0,5–0,8 с ещё возможны.

Временные развёртывания установщика удалены после успешных проверок. Отдельное удаление временных папок ручного запуска и тестовых компонентов отклонено автоматической проверкой выполнения («blocked by policy»); эти папки остались локально и в поставку не входят.

Выпуск [опубликован на GitHub](https://github.com/Dicur3x/MyHomeLib/releases/tag/2.7.0_pre5.27) и отмечен актуальным. Все три вложения скачаны потоково и проверены по полному размеру и SHA-256; повторные ZIP на диске не создавались. [Подтверждение публикации и скачивания](audits/2026-10-20-pre527-published.json).
