# Проверки HomeLibre 3.0 beta 8

Тег выпуска `3.0.0_pre1.8`, версия файлов Windows `3.0.0.8`.

| Windows | Архив | SHA-256 |
| --- | --- | --- |
| x86 | `HomeLibre.zip` | `bb6b98e8d8f744a5181a547eaca33eb7789d56d62649d13744f5e43ae3e256fe` |
| x64 | `HomeLibre_x64.zip` | `86060e8e0255c973fdb52b954e4a4e000d8dbd3c492a322ec1727fb8314094d7` |

- **Минимальные архивы.** Сверены версии и разрядность каталогизатора и обновлятора. Для каждого ZIP проверены состав и SHA-256 240 устанавливаемых файлов. Читалка, MCP, Zstandard и дополнительные обработчики форматов поставляются отдельно.
- **Переход с beta 7.** Через обычное окно опубликованной beta 7 установлены точные архивы beta 8 на x86 и x64. Оба окна показали список изменений, после перезапуска открылась та же коллекция. Сохранились семь тестовых записей, личные данные и настройки. В этом прогоне пакет был заранее подготовлен локально.
- **Отдельные компоненты.** Reader, BookProcessing, ImageProcessing, KindleExport и EpubPdfExport прошли штатную подготовку и локальную установку на обеих разрядностях. Сверены файлы компонентов, отсутствие посторонних декодеров и сохранность тестовых личных данных.
- **Публичная загрузка.** После публикации штатные разборщики нашли beta 8, скачали оба основных архива с GitHub и подготовили обновление. Отдельно сверены публичная лента, загрузка, SHA-256 и штатная подготовка всех десяти обновлённых модулей. Временные загрузки удалены.
- **Функциональный аудит.** Проверки форматов USR, чтения, сохранения, импорта через Проводник, удаления, темпа загрузки и WebView2 описаны в [протоколе аудита](audits/2026-11-08-post-beta7.md). На x86 из итогового архива дополнительно проверены открытие и отмена системного диалога выбора нового пути книги. Само переназначение TXT и ZIP проверено в нативном тесте x86/x64.

Просмотр на физических Kindle и Kobo и повтор с активным Kaspersky остаются отдельными проверками. Расследование ошибки закрытия RAD Studio отложено. Тестовые установки обновления и компонентов удалены.
