# Структура переносимого комплекта

Минимальный архив содержит каталогизатор. Читалка и модули дополнительных форматов устанавливаются по запросу; шрифты приходят с читалкой.

| Путь | Для чего нужен |
| --- | --- |
| `HomeLibRu.exe` | Каталогизатор |
| `HomeLibRuUpdater.exe` | Замена файлов программы после её закрытия, журнал и откат обновления |
| `sqlite3.dll` | Чтение и изменение каталогов SQLite |
| `LICENSE`, `NOTICE` | Условия использования и сведения о стороннем коде |
| `HomeLibRu.update.json` | Проверка содержимого архива: версия, разрядность, размеры и SHA-256 файлов |
| `Icons/` | Значки интерфейса |
| `Help/` | Справка на поддерживаемых языках |
| `Help/CHANGES.txt` | Локальная история выпусков для окна обновлений |
| `tools/genres/genres_*.glst` | Справочники жанров для FB2 и прочих коллекций; варианты без суффикса, `_en`, `_uk`, `_bg` |
| `tools/updates/COMPONENTS.json` | Начальные сведения и история обновлений дополнительных компонентов; файл не устанавливает их |

`HomeLibRu.update.json` остаётся в корне **архива**, потому что ранее выпущенные программы ищут его там до запуска нового механизма обновления. В список устанавливаемых файлов этот транспортный манифест не входит. При ручной распаковке он появляется рядом с EXE. Менять его вручную для исправления ошибки обновления не нужно.

Папки `tools/fonts`, `tools/doc`, `tools/djvu`, `tools/kindle`, `tools/office`, `tools/pdfium` и другие дополнительные модули в минимальный архив каталогизатора не входят. Папка `tools` в базовой поставке содержит только справочники жанров и сведения об обновлениях.

Для совместимости программа также читает справочники жанров, `COMPONENTS.json` и `CHANGES.txt` из старого расположения в корне, если соответствующего файла нет в новом. Уже имеющиеся корневые файлы автоматически не удаляются: среди них могут быть изменённые пользователем справочники. Чистый новый архив содержит только новое расположение.

Пользовательские данные создаются после запуска и не входят в поставку: `Data/`, настройки, заметки, кэш, журналы и каталоги коллекций. Перенос справочников поставки не переносит и не заменяет эти данные.
