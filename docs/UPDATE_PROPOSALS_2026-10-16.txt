Доработки окна обновлений — 16 октября 2026

Реализовано

1. Заголовки выпусков — стандартные кнопки Windows/VCL вместо TLabel.
Tab обходит заголовки и открытый текст. Enter и пробел используют штатную
обработку кнопки, поэтому нет дополнительного второго обработчика клавиш.
В имени кнопки есть номер выпуска и «развёрнуто»/«свёрнуто», в подсказке —
действие. При фокусе заголовок прокручивается в видимую область. При закрытии
сфокусированного текста фокус переходит к его заголовку; при обновлении истории
восстанавливается тот же выпуск, а при его удалении — ближайший заголовок.
Высота кнопки учитывает перенос строки, масштаб текста и масштаб VCL.

2. Проверка AlReader сохранена. Доступный официальный сайт без подтверждаемой
версии Windows даёт отдельное состояние «Версия не подтверждена» с объяснением,
что установленная читалка продолжает работать. Недоступный сайт остаётся ошибкой.

3. Частичная ошибка перечисляется в общем результате вместе с независимыми
доступными обновлениями. Выбор проблемного компонента сохраняет его объяснение
и кнопку «Повторить проверку». Эта кнопка повторяет проверку, а не скачивает
пакеты из прежнего результата. При ошибке пакета очищается весь непроверенный
набор URL/размеров/контрольных сумм; история изменений при этом сохраняется.
Автоматические ошибки не открывают окно и не оставляют Retry выключенным.

4. Исключения транспорта больше не попадают непосредственно в основной UI.
Показывается короткое сообщение с дальнейшим действием. Диагностика ограничена
4096 символами и доступна только через явное контекстное действие
«Копировать сведения об ошибке» для выбранной строки.

5. component_updates_tests.js теперь выполняет контролируемые проверки без
внешнего HTTP и без установки по умолчанию. AlReader не пропускается; проверяются
прямые официальные пакеты DjVuLibre/7-Zip и все четыре библиотеки DocSharp.
--live-check явно включает только живые запросы метаданных, не загрузку программ.
Старый прогон архивной установки сохранён отдельно за --install-fixtures;
он в этой задаче не запускался.

Папки fixtures содержат HomeLibRu-update-test-; дочерний процесс получает TEMP/TMP

Новый нативный сценарий использует production TComponentUpdateThread.Execute;
только транспорт заменён на фиксированные ответы. Проверка HEAD обращается
лишь к собственному серверу 127.0.0.1. Неизвестный URL отвергается. Проверяются:
недоступность всех источников, один недоступный источник при независимых
обновлениях, отказ HEAD неполного набора DocSharp, новая попытка и тихая
автоматическая ошибка. Не выполняется скачивание/установка/запуск программ.
Проверки клавиатуры охватывают 2 темы × 3 масштаба VCL (96/144/192), Enter/Space
один раз, Tab без попадания в скрытый текст, default-action, фокус/скролл/zoom/reload.
Физический DPI монитора не изменяется.
