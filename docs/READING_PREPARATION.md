# Что происходит при открытии и конвертации книги

## Встроенная читалка

Подготовка зависит от содержимого файла. Архив сначала открывается как контейнер:
по записи каталога извлекается конкретная книга; для самостоятельного архива
с несколькими книгами пользователь выбирает файл. Результат подготовки хранится
в кэше с проверкой исходника. Читалка не повторяет преобразование неизменившегося
документа при каждом открытии.

| Вход | Путь чтения |
| --- | --- |
| FB2, FB3, EPUB, TXT, RTF, HTML/MHTML, Markdown, DOCX, ODT | Встроенный разбор текста и ресурсов, затем представление для чтения; отдельный офисный пакет не запускается |
| PDF | Отрисовка страниц PDFium; текстовый слой используется для выделения, если он есть |
| DjVu | Отрисовка страниц поставляемым DjVuLibre |
| Изображения и комиксы | Показ изображений с сохранением порядка страниц |
| DOC/DOT | Поставляемый HomeLibDoc с DocSharp читает двоичный документ в DOCX; затем используется встроенный разбор DOCX. LibreOffice не требуется |
| Поддерживаемый незашифрованный KF8/MOBI8 | Поставляемый KindleUnpack подготавливает EPUB; затем работает обычное чтение EPUB |
| Остальные поддерживаемые офисные документы: старые презентации, таблицы и отдельные варианты Word | Если прямой разбор не подходит, установленный LibreOffice подготавливает PDF. Это наиболее тяжёлый путь. LibreOffice не входит в основной архив |

«Прямое чтение» всё равно включает разбор формата, кодировки, структуры,
иллюстраций и построение страницы. Внешняя программа требуется только там,
где собственного разбора нет. Наличие расширения в меню не означает поддержку
защищённого паролем, повреждённого или любого исторического варианта формата.

Добавление отдельных библиотек имеет смысл после проверки конкретного формата
и задержки. Для текстового DOC такая замена уже сделана: DocSharp вместо
запуска LibreOffice. Для презентаций и таблиц важнее сохранить их расположение
и графику, поэтому немедленно заменять PDF-подготовку на извлечение одного текста
не следует.

## Экспорт в FB2 и EPUB

Экспорт выбирается отдельно от чтения. Сейчас поддерживаются FB2 ↔ EPUB,
FB3, TXT, HTML, Markdown, RTF, DOC/DOCX, ODT и Kindle без DRM → FB2 или EPUB. PDF и DjVu не конвертируются.
Подробности сохранения оформления и ограничения перечислены
в [описании конвертера](../tools/bookconvert/README.md).

FB3 и Markdown разбираются внутри конвертера. MOBI7 и KF8 подготавливаются
поставляемым KindleUnpack, затем используются общие пути HTML/EPUB.
Поддержка чтения и экспорта различается: защищённые и неизвестные варианты
конвертер отклоняет с объяснением. Сложная вёрстка может упрощаться.

## Сведения из книг и ошибки сканирования

В отчёте пользователя было 617 011 ошибок чтения на 1 465 776 записей.
Проверка физического расположения обнаружила 616 995 неудалённых FB2
в ZIP с методом сжатия PPMd. Прежний массовый сканер не читал этот метод,
хотя обычное открытие книг его поддерживало. Это объясняет основную массу
ошибок; разницу в 16 записей нельзя автоматически приписывать той же причине.

Сканер теперь использует уже поставляемую `7z.dll` и для PPMd, и для 7z.
Из FB2 читается ограниченное начало с описанием, без отдельного процесса
и без распаковки полной книги на диск. Индекс контейнера переиспользуется;
записи в каждой порции группируются по архивам. Полные выбранные поля
пропускаются до открытия файла. FB3, EPUB, DOCX и ODT разбираются как пакеты
с ограничением объёма ресурсов. Дата изменения документа не считается годом
издания, а компания автора — издательством.

Если самостоятельный архив содержит несколько подходящих книг, сканер
не приписывает их сведения одной записи случайным образом: он сообщает
неоднозначность. Недоступные файлы, ошибки описания и отсутствующий декодер
различаются в итоговом отчёте; первые 40 примеров содержат книгу и источник.

Аннотация — описание книги. Её заполнение выключено по умолчанию: сохраняются
только отсутствующие описания каталога, существующий текст не заменяется.
После проверки окно показывает число таких книг и приблизительный объём
текста из их файлов. Рост базы может быть больше из-за служебных данных.
Сохранённое описание доступно в нижней карточке книги без повторного открытия
исходного файла; этот же текст используется для поиска по аннотации.

Дополнительно сверены точные имена всех 1 211 469 местных неудалённых FB2 в 654 ZIP: все записи найдены однозначно, 594 474 используют Deflate, 616 995 — PPMd. Это проверка индексов архивов, а не повторный разбор описаний всех книг.

На реальной библиотеке проверено 20 книг только для чтения, включая 10 PPMd.
Все 20 описаний прочитаны. Полный повторный проход по 1,46 млн записей
не выполнялся; эти измерения не следует выдавать за результат полного сканирования.

Спецификации: [EPUB 3.3](https://www.w3.org/TR/epub-33/),
[Office Open XML](https://ecma-international.org/publications-and-standards/standards/ecma-376/),
[OpenDocument 1.3](https://docs.oasis-open.org/office/OpenDocument/v1.3/os/part3-schema/OpenDocument-v1.3-os-part3-schema.html),
[DocSharp](https://github.com/manfromarce/DocSharp),
[интерфейсы архивов 7-Zip](https://github.com/ip7z/7zip/blob/main/CPP/7zip/Archive/IArchive.h).
