# Проверки HomeLibre 3.0 beta 5

Тег выпуска `3.0.0_pre1.5`, версия файлов Windows `3.0.0.5`.

| Windows | Архив | SHA-256 |
| --- | --- | --- |
| x86 | `HomeLibre.zip` | `4af26536923de2aca2830735a7267e54e8acc909f7e17a2a3d519b13aabdd430` |
| x64 | `HomeLibre_x64.zip` | `43745fcc1ce5bd2cbeb3d12e8e1d5aa53182aae8f21bccc6da9521d57226000d` |

- **Обновление.** На x86 и x64 штатный помощник beta 4 установил итоговый архив beta 5, перезапустил каталогизатор и сохранил каталог, настройки и личные данные в тестовой установке. После публикации штатный загрузчик скачал оба архива с GitHub и проверил их по манифесту. Читалка и дополнительные обработчики поставляются отдельно. Все 28 новых пакетов прошли публичное скачивание, сверку SHA-256 и подготовку к установке. Архив исходников KFX проверен отдельно.
- **Читалка.** Из каждого итогового архивного комплекта проверено прямое открытие FB2 из каталога и сохранение позиции чтения. Отдельные проверки x86 и x64 покрыли F11, скрытие интерфейса, темы, развороты, масштабирование и перелистывание по одной странице или по развороту.
- **Сохранение.** Проверены исходные копии FB2, EPUB, PDF, DjVu и DOC, смешанный выбор, ZIP, обработка изображений, оценка и отмена. Установка модулей и продолжение операции проверены на точных пакетах с тестовым источником загрузки. Дополнительные форматы проверены по выходным файлам. Физические Kindle и Kobo в проверках не участвовали.
- **Сжатие.** На x86 и x64 два последовательных обновления INPX сохранили исходные поколения смешанной коллекции. Неизменённые архивы использовались повторно, итоговые книги прошли побайтовую сверку. Режимы с изменением иллюстраций проверялись отдельно, в том числе на сканах с бледными деталями.
- **Удаление.** Проверены выбор между удалением записи и файла, сохранение соседних книг, удаление пустого архива, отмена и восстановление. Проверка FLibrary использовала временные копии архивов с книгами и изображениями.
- **Большой каталог.** При высокой общей нагрузке нативный поиск «привет» занял меньше секунды на обеих архитектурах. Полная выдача 1 700 620 книг заняла около 15–17 секунд. Все количества совпали с отдельными запросами к базе. По одному запуску из архивов недостаточно для вывода об ускорении относительно beta 4.
