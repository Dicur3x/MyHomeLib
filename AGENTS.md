# Working space

- Keep at least 8 GiB free on the Windows system drive before builds, archive processing, installation or other disk-intensive work; monitor it during long jobs. Stop such work when the reserve is exhausted. Check the destination and temporary volume as well.
- Place new build outputs, test profiles and large temporary data on G: (the existing HomeLibre work cache), not the system drive. Clean only positively identified files owned by this task.
- Do not delete or move temporary files belonging to another active chat, including the game project. Do not delete conversation history to recover space.
- User libraries are tested using isolated copies. Keep unrelated untracked work intact.
