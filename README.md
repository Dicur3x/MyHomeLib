# HomeLibre

С версии **3.0 beta 1** проект называется **HomeLibre**; в предыдущих выпусках — HomeLib Ru.

**Русский** · [Українська](README.uk.md) · [English](README.en.md) · [Български](README.bg.md)

HomeLibre — программа для Windows, которая помогает хранить, искать и читать
электронные книги. Она ведёт каталог собственных файлов и работает с каталогами
онлайн-библиотек на движке «Либрусек», включая Флибусту.

Русская ветка [MyHomeLib](https://github.com/OleksiyPenkov/MyHomeLib),
оригинальный автор — **Олексій Пеньков (Oleksiy Penkov)**.

Текущий тестовый выпуск — **[HomeLibre 3.0 beta 10](https://github.com/Dicur3x/MyHomeLib/releases/tag/3.0.0_pre1.10)**.
[Изменения](https://github.com/Dicur3x/MyHomeLib/releases/tag/3.0.0_pre1.10) · [История выпусков](https://github.com/Dicur3x/MyHomeLib/releases) ·
[Проверки и ограничения](docs/RELEASE_VALIDATION_3.0.0_pre1.10.md).

| Скачать HomeLibre | Для какой системы |
| --- | --- |
| [HomeLibre — 64 бит](https://github.com/Dicur3x/MyHomeLib/releases/download/3.0.0_pre1.10/HomeLibre_x64.zip) | 64-разрядная Windows |
| [HomeLibre — 32 бит](https://github.com/Dicur3x/MyHomeLib/releases/download/3.0.0_pre1.10/HomeLibre.zip) | 32-разрядная Windows; также работает на 64-разрядной |
| [SHA256SUMS.txt](https://github.com/Dicur3x/MyHomeLib/releases/download/3.0.0_pre1.10/SHA256SUMS.txt) | Контрольные суммы архивов |

Требуется **Windows 10 или новее**. Архив содержит каталогизатор. Книги
скачиваются отдельно.

1. Распакуйте архив в папку, в которую можно записывать файлы.
2. Запустите **HomeLibRu.exe**.
3. Выберите **Коллекция → Создать новую коллекцию**. В мастере можно создать
   пустую коллекцию, импортировать INPX или подключить существующий каталог `.hlc2`.
4. Укажите папку с книгами. Для своей локальной коллекции можно добавить отдельные
   книги через **Коллекция → Импорт → Добавить файл…** или перетащить их из Проводника.
   При добавлении можно оставить файлы на месте, чтобы каталог хранил только ссылки.
5. Найдите книгу по автору, серии, жанру или через поиск и откройте её.

**F1** открывает справку для текущего окна.
[Создание коллекции](Program/Help/new_collection.html) ·
[Добавление книг](Program/Help/add_books.html).

## HomeLibre Reader

[Скачать Reader для Windows x64](https://github.com/Dicur3x/MyHomeLib/releases/download/optional-alreader-2.5.1009.25/HomeLibRu-HomeLibReader-3.0.0.8-Win64.zip) · [Скачать Reader для Windows x86](https://github.com/Dicur3x/MyHomeLib/releases/download/optional-alreader-2.5.1009.25/HomeLibRu-HomeLibReader-3.0.0.8-Win32.zip) ·
[Все компоненты и внешние читалки](https://github.com/Dicur3x/MyHomeLib/releases/tag/optional-alreader-2.5.1009.25)

HomeLibre Reader можно запустить отдельно, чтобы читать свои файлы без
каталогизатора и коллекции. Распакуйте архив, запустите **HomeLibReader.exe**
и нажмите **Ctrl+O**. Если вы открываете книгу из каталогизатора, он предложит
установить читалку при первом обращении.

- **Сразу доступны** FB2, FB3, EPUB, TXT, RTF, HTML/MHTML, Markdown, DOCX, ODT,
  JPEG, PNG, GIF, BMP, поддерживаемые TIFF и CBZ с такими изображениями.
- **По запросу** загружаются модули для PDF, DjVu, XPS, Kindle (MOBI, AZW, AZW3, PRC),
  старых документов Office (включая DOC), WebP и комиксов CBR/CB7.
  Презентации и таблицы можно открыть без установленного Office.
- **Редкие форматы** включают CHM, LIT, LRF, RB, ABW, SXW, WRI, TCR, RGO,
  IBK и поддерживаемые варианты PDB. Читалка также открывает поддерживаемые
  книги внутри ZIP, 7z и RAR. Если в архиве несколько книг, можно выбрать нужную.

В читалке можно настроить цвета, шрифт, развороты и плавную прокрутку.
Есть поиск по тексту, оглавление, закладки и заметки. Место чтения сохраняется.
Заметки можно выгрузить в TXT, HTML или DOCX. Для повторного открытия
подготовленные книги хранятся в кэше, который можно настроить и очистить.
В меню **Файл → Сохранить как…** можно сохранить или преобразовать открытую книгу.
Сложное оформление офисных документов и EPUB при подготовке может упроститься.
[Справка по чтению](Program/Help/reading.html).

## Возможности

### Каталог и поиск

- Несколько локальных и онлайн-коллекций; каталог хранится в SQLite.
- Импорт FB2, FBD и других файлов, INPX и metabib; книги могут находиться
  в ZIP и 7z. Подключение существующих каталогов MyHomeLib.
- Просмотр по авторам, книжным и издательским сериям, жанрам и группам.
  Одна книга может иметь несколько серий без копирования файла.
- Поиск по автору, переводчикам, названию, издательству, городу и году издания,
  ISBN, серии, жанру, ключевым словам,
  аннотации, имени файла, дате, языку и оценке; выражения и сохранённые пресеты.
- Импорт и экспорт пресетов в редактируемый XML; прежние cxml/cxml2 поддерживаются.
  Импорт сохраняет старые пресеты и текущий ввод.
- Фильтры столбцов с сочетанием условий. Результаты с несколькими сериями
  можно свернуть флажком **«Без повторов по сериям»**.
  Доступен необязательный столбец «Издательство» со своим фильтром.
- Избранное и собственные группы, оценки, прогресс, рецензии и редактирование
  описаний. Личные сведения и список любимых авторов можно экспортировать отдельно от каталога.
- Любимые авторы: сохраняемый список и новые книги после обновления коллекции.
  Компактные условия в поиске и фильтре автора; просмотр новинок отмечается явно.
- Обновление из INPX, несколько источников с отдельными папками и приоритетами,
  синхронизация папок, обслуживание базы и объединение коллекций с предпросмотром.
- **«Заполнить сведения из книг…»** заполняет выбранные пустые издательство,
  город, год, ISBN и переводчиков из местных FB2, FB3, EPUB, DOCX и ODT,
  включая поддерживаемые книги в архивах. Для ZIP/PPMd и 7z предлагается установить 7-Zip.
  Команда находится в меню **Коллекция**, окне источников и на последнем шаге
  успешного создания локальной коллекции. Проверка и заполнение запускаются
  отдельно; имеющиеся значения сохраняются. Аннотации выключены по умолчанию:
  их можно включить после проверки без повторного чтения книг, увидев примерный
  объём текста. Прочитанные сведения сохраняются между запусками: после остановки
  проверка использует их для неизменившихся файлов. До четырёх потоков читают книги
  параллельно. Во время проверки и заполнения видны прошедшее время, скорость и
  примерное оставшееся время. Поля берутся только там, где они записаны; причины
  ошибок видны в отчёте.
- Загрузка выбранных книг из онлайн-библиотеки, включая очередь загрузок.
- Обложки, аннотации и галерея иллюстраций; сведения об авторе и отзывы,
  если они доступны в источнике.

### Внешние читалки

**AlReader** и **SumatraPDF** доступны в каталогизаторе как дополнительные
читалки. Откройте контекстное меню книги, чтобы выбрать внешнюю программу.
Назначения для разных форматов можно задать в настройках.
[Настройка читалок](Program/Help/set_readers.html).

### Сохранение книг и обмен

- **«Сохранить как…»** сохраняет исходный формат или преобразует книги в FB2,
  FB2.ZIP, EPUB, TXT, MOBI или AZW3. Для нескольких книг можно оставить каждой
  её формат или выбрать общий. При включении **«Ещё форматы»** доступны EPUB 2,
  EPUB 3, KEPUB для Kobo, KFX и AZW8 для Kindle, PDF и Markdown, если выбранные
  книги можно в них преобразовать. Нужные модули скачиваются по запросу.
  Для PDF из EPUB используется Microsoft WebView2 Runtime.
- **«Оттенки серого»** убирают цвет из иллюстраций и сканов в сохраняемой копии.
  Это может уменьшить файл, если цвет не важен. Галочку можно сочетать с режимом
  сжатия, в том числе с **«Максимальной экономией»**. Нажмите **«Оценить размер»**,
  чтобы сравнить варианты. После переключения галочки запустите оценку заново.
  При сохранении в исходном формате обработка картинок доступна для FB2 и EPUB.
- Если в PDF или DjVu есть текстовый слой, его можно перенести при преобразовании.
  Страницы без текста сохраняются как изображения. Для больших PDF со сканами
  оценка по выборке страниц показывает примерный диапазон размера файла.
- Исходники сохраняются. При совпадении имени можно заменить файл, сохранить
  оба или отменить операцию. Папка назначения, маски имени и подпапок общие
  с разделом «Папки/Устройства». Пользовательские скрипты экспорта доступны отдельно.
  [Ограничения конвертации](tools/bookconvert/README.md).
- Экспорт каталога в INPX, списка книг в HTML и личных сведений отдельным файлом.
- Экспорт группы или всех групп в metabib, в том числе из нескольких коллекций.
  Получается переносимая папка с `catalog.jsonl` и архивами книг;
  оценки, рецензии, группы и прогресс в неё не входят.
- Локальный **OPDS-каталог**: другая поддерживающая OPDS читалка может искать
  и скачивать ваши книги. Запускается вручную для выбранной локальной коллекции;
  доступ с другого устройства включается отдельно.
- **MCP-сервер** `MHLMcpServer.exe`: доступ для AI-ассистентов к поиску,
  метаданным, оглавлению и тексту книги. Работает только на чтение и не требует
  запущенной главной программы.

### Компактные коллекции FLibrary и LightLib

HomeLibre поддерживает обычные раздачи с INPX/ZIP и их компактные варианты:

| Коллекция | Что поддерживается |
| --- | --- |
| [FLibrary](https://github.com/heimdallr/books) | 7z, отдельные `covers`/`images`, восстановление FB2/EPUB, преобразование JPEG XL в JPEG/PNG |
| LightLib | Объединённый локальный INPX Либрусека и Флибусты, ZIP/PPMd, несколько серий, преобразование встроенных WebP в PNG |

В мастере выберите INPX и **корневую папку всей раздачи**. Для FLibrary оставьте
рядом с архивами папки изображений. Без недостающих изображений текст открывается,
но сами картинки не восстанавливаются. Для совместимости WebP по умолчанию
преобразуется при чтении и экспорте; сохранение оригинала можно включить в настройках.

Сам INPX содержит каталог, а не книги. Новый путь к архивам не добавляет записи
из нового выпуска: для этого обновите коллекцию из соответствующего INPX.
Объединённый INPX LightLib подключается как локальная коллекция.
[Подробности форматов и отличий](FEATURES_RESEARCH_2026-10-05.md).

## Обновления и сохранность данных

В меню **Помощь** доступна проверка обновлений. Для нового профиля автоматическая
проверка выполняется раз в три дня; сохранённый период и выбор «Никогда» учитываются.
В фоне уведомление появляется только при новой версии. Ручная проверка сообщает
также об актуальной версии или ошибке проверки.

Скачивание и установка начинаются по вашему действию в окне обновлений.
Программа показывает список изменений, подготавливает файлы и перезапускается.
SQLite, SumatraPDF, DjVuLibre, 7-Zip и DocSharp проверяются на официальных
ресурсах авторов. Если совместимый выпуск подтвердить нельзя, окно сообщает об этом.
Нужные модули HomeLibre предлагает скачать прямо в программе. Все доступные
архивы, в том числе AlReader, собраны на [странице компонентов](https://github.com/Dicur3x/MyHomeLib/releases/tag/optional-alreader-2.5.1009.25).

Перед первым переходом с MyHomeLib или ручным обновлением закройте программу
и сохраните копию профиля и файлов коллекций `.hlc2`. Новый ZIP лучше распаковать
в отдельную папку, чтобы не оставить рядом старый `MyHomeLib.exe`.

Архивная поставка **портативна по умолчанию**: настройки каталогизатора
находятся рядом с EXE, личные данные — в папке `Data`. Файл `uselocaldata`
для этого не требуется. Каталоги коллекций `.hlc2` и книги могут храниться
в отдельных выбранных папках.

При переносе программы сохраняйте всю её папку, включая `myhomelib2.ini`,
`Data` и `presets.cxml2`; затем проверьте пути к книгам и коллекциям.

Поставка не содержит личных баз, книг, заметок и истории. При откате программы
оставляйте текущие пользовательские данные: старую резервную копию нельзя
автоматически возвращать поверх новых записей.
[Переносимый режим](Program/Help/portable.html) ·
[Обновление программы](Program/Help/upgrade.html).
