# HomeLib Ru 2.7.0_pre5.02

Версия исполняемого файла: **2.7.0.1069**. Исправление посвящено заполнению
издательских книжных серий на вкладке **«Книжные серии»**.

## Заполнение из книг

- FB2/FBD разбираются потоково только до конца описания книги. Основной текст
  и встроенные изображения не строятся в памяти как полный XML-документ.
- При чтении ZIP архив используется повторно для следующих книг, а XML
  читается только в объёме, необходимом для метаданных.
- Книги из 7z извлекаются ограниченными пакетами. Весь архив целиком не
  распаковывается; временные файлы удаляются после обработки или отмены.
- Вынесенные изображения FLibrary для этой операции не восстанавливаются.
- Обход использует отдельный компактный запрос к каталогу без загрузки
  авторов, жанров и прочих сведений, не нужных для индексации.

Обычный INPX не содержит отдельного поля издательской серии. Поэтому для
заполнения этих сведений по-прежнему нужны доступные файлы книг. Авторские
циклы с вкладки «Серии» и издательские серии остаются разными данными.
Автоматического обхода файлов при запуске программы нет.

## Продолжение и повторная проверка

- Успешно проверенные книги запоминаются, включая книги без издательской
  серии. Повторное **«Заполнить из книг...»** пропускает неизменившиеся файлы.
- После отмены сохраняются полностью обработанные книги. При следующем
  запуске заполнения они не читаются заново, если исходные файлы не изменились.
- Недоступные файлы и ошибки чтения описания не стирают прежние сведения и не
  отмечаются как успешно проверенные: при следующем запуске они проверяются
  снова.
- Ошибки XML в основном тексте после корректного описания больше не мешают
  получить издательские серии.
- Изменения определяются по пути, размеру и времени изменения файла или
  архива, с учётом записи книги внутри контейнера и версии способа чтения.
- Флажок **«Полная проверка»** отключает пропуск по кэшу. Он полезен и тогда,
  когда файл заменили с сохранением прежних размера и времени изменения.
- После отмены индикатор сохраняет фактический процент выполненной работы,
  а не перескакивает на 100%.

**Первый проход после обновления с версии 2.7.0.1068 проверит книги заново.**
В прежней версии сохранялись найденные серии, но не отметки успешной проверки
исходных файлов. Уже найденные сведения не удаляются из-за отсутствующего
файла; новый кэш заполняется по мере успешной обработки.

## Проверка скорости

На тестовом ZIP из 1000 книг время обхода Win64 сократилось с **5,89 до
0,72 секунды**; повторный проход занял **0,21 секунды** и не открывал архив.
На настоящем 7z из 40 книг: **6,57 → 1,55 секунды**, повторно **0,01 секунды**.
Найденные серии и их номера совпали со старым способом чтения.

Это небольшие контрольные примеры, а не прогноз для коллекции из 845 тысяч
книг. Кэш Windows не очищался; порядок замеров: старый способ, новый,
повторный, принудительный. Обе реализации использовали текущий слой БД;
подготовка тестовых данных не включалась во время обхода. На Win32 тестовый
ZIP также пройден: 6,13 → 0,62 секунды, повторно 0,24 секунды.

Первичное заполнение всё ещё требует чтения доступных книг. Само открытие
вкладки читает уже сохранённый индекс, а не запускает обработку архива.

## Обновление

Обе сборки Win32/Win64 проверены: чтение метаданных, кэш, отмена/продолжение,
изменение файлов, сохранность прежних серий, восстановление FB2/EPUB FLibrary
и запуск из готового ZIP. Полная коллекция владельца не сканировалась.
Из упаковки исключены рабочие настройки и история комплектных читалок.

Закройте программу и сохраните резервную копию профиля и файлов коллекций
`.hlc2`. Распакуйте **HomeLibRu.zip** (x86) или **HomeLibRu_x64.zip** (x64)
в отдельную чистую папку и запустите **HomeLibRu.exe**. Копировать только EXE
недостаточно. Обычный профиль по-прежнему хранится в `%APPDATA%\MyHomeLib`.
Для portable-режима перенесите собственные `uselocaldata`, `myhomelib2.ini`,
`Data` и `presets.cxml2` из резервной копии и проверьте пути к коллекциям.

Для возврата на старую версию используйте отдельную резервную копию профиля
и коллекций, сделанную до обновления. Не изменяйте одну рабочую коллекцию
попеременно старой и новой программой.
