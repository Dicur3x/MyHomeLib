# HomeLib Ru 2.7.0 pre5.16

Исправлены задержки большого отфильтрованного списка, выделение текста и работа встроенной читалки. Переработано окно обновлений, восстановлена отдельная автоматическая установка компонентов. Версия программы: **2.7.0.1084**.

## Обновления

- На вкладке «Обновления» показаны назначение компонента, название библиотеки, установленная версия, версия у автора и состояние проверки. В списке HomeLib Ru, SQLite, AlReader, SumatraPDF, DjVuLibre, 7-Zip и DocSharp.
- Для длинных описаний появилась отдельная просторная вкладка «Список изменений». Она увеличивает область чтения; можно выбрать компонент, изменить масштаб текста и размер окна. Оформление работает в светлой и тёмной темах.
- Компоненты устанавливаются автоматически из отдельных совместимых пакетов. Проверяются содержимое, версии, разрядность и контрольные суммы. Если установка не завершилась, заменённые файлы восстанавливаются; настройки и история сохраняются. Программа различает новую версию у автора и уже подготовленный совместимый пакет.

## Чтение

- DOC открывается через небольшой встроенный обработчик **DocSharp 0.21.0**. Подготовка идёт в фоне, готовая копия используется повторно. Для этого пути LibreOffice не требуется. Исходный документ сохраняется.
- Выделение мышью в FB2, EPUB и TXT соответствует реально нарисованным строкам, включая продолжение абзаца на следующей странице. Копирование сохраняет Unicode и эмодзи. Выделение включено по умолчанию и доступно для цитаты в заметке.
- Выделение PDF использует спокойную полупрозрачную подсветку, сохраняющую читаемость текста в обеих темах.
- Отрисовка новых страниц PDF вынесена в отдельный процесс. Интерфейс продолжает отвечать во время обработки скана; быстрые переходы показывают последний выбранный пункт. Размер кэша ограничен, переключение темы и отмена учитываются.
- Для приближения добавлена включённая по умолчанию настройка «Приближение при удержании»: отпускание кнопки возвращает прежний масштаб. Её можно отключить для переключения повторным щелчком. По умолчанию приближение составляет 150%, настройка допускает 120–300%.
- В DjVu исправлена обработка корректной пустой страницы без растрового слоя: она отображается белой, без ошибочного сообщения об отрисовке.
- Оглавление открывается одним деревом по кнопке, стрелке рядом с текущей главой и клавиатуре. Разделы можно сворачивать, поиск оставляет родительский контекст. В строке над книгой показана текущая глава, полный путь доступен в подсказке.
- Полоса прогресса стала толще; щелчок и перетаскивание позволяют перейти к нужному месту. Первые буквы абзацев работают независимо от основного оформления книги. Кнопки выгрузки подписаны как экспорт заметок.

## Большие коллекции и сохранность

- После фильтра «все типы, кроме FB2» действия главного окна больше не обходят весь список при каждом обновлении интерфейса. Это исправление действует для всех форматов и сохраняет операции с отмеченными книгами и группами.
- При объединении записываются только изменившиеся поля карточки. Основная и дополнительные серии, личные оценки, прогресс, отзывы и группы сохраняются. Дополнение отзыва сохраняет исходный текст вместе с его пробелами и переносами.
- Предпросмотр повторно использует уже прочитанные личные значения. Проверка привязок источников использует индекс вместо полного обхода старых ключей.
- Актуальные служебные триггеры базы больше не пересоздаются при каждом открытии. Старое определение исправляется один раз с защитой от неполной замены.
- Окно источников и проверка названий серий получили ясные результаты и отдельные действия применения; источники проверяются вместе без необходимости выделять все строки. Исправлено обрезание элементов при увеличенном масштабе Windows.

На отдельных копиях трёх больших каталогов обработаны **2 146 189 исходных записей**, результат содержит **1 856 990 книг**. Применение объединения заняло **10 минут 38 секунд**; обновление существующих карточек — около 95 секунд вместо 188. Отдельная предварительная проверка с прогретыми данными заняла около **39 секунд**. В другом полном запуске предпросмотр занял около пяти минут; причина различия времени чтения отдельно не установлена. Эти замеры не означают одинаковое время на любом диске.

Результат сопоставлен по всем содержательным полям книг; проверены таблицы источников, связи и пользовательский прогресс. Непустые личные отзывы, оценки, группы, отмена и ошибки записи дополнительно проверены отдельными случаями. Повторный предпросмотр актуальных каталогов сохраняет их файлы побайтно. Проверки выполнены для Win32 и Win64; сборка не включает пользовательские базы, книги, настройки или историю.
