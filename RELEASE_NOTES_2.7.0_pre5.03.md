# HomeLib Ru 2.7.0_pre5.03

Версия исполняемого файла: **2.7.0.1070**.

## Исправление чтения книжных серий

Исправлена ошибка **`Unable to switch the encoding`** при заполнении
издательских серий из некоторых FB2. В обнаруженных книгах содержимое записано
в UTF-16, а в XML-заголовке ошибочно указано UTF-8. Индексатор теперь учитывает
явную метку кодировки в начале файла (BOM). Сами книги и архивы не изменяются.

Исправление действует для обычных ZIP, 7z и отдельных FB2/FBD. Быстрое чтение
только описания книги сохранено: основной текст и изображения не разбираются.
Файлы без BOM по-прежнему читаются по стандартным правилам XML, без попыток
угадать кодировку. Другие ошибки XML в описании не скрываются.

На обеих архитектурах прошли 404 автоматические проверки чтения метаданных
и проверка двух книг из сообщения владельца. В каждой найдена издательская
серия; прочитано по 8192 байта из файлов размером 1506782 и 1125018 байт.

## Продолжение заполнения

После обновления снова нажмите **«Заполнить из книг...»**, оставив
**«Полная проверка» выключенной**. Успешно проверенные в pre5.02 неизменившиеся
книги будут пропущены, а книги с ошибками проверены повторно. Сохранённые серии
и результаты до отмены не сбрасываются. Всю коллекцию заново читать не нужно.

Индикатор показывает целые проценты: 7000 из 845008 книг составляют примерно
0,83%, поэтому на таком этапе отображается 0%. Это не означает остановку.

## Обновление

Закройте программу и сделайте резервную копию профиля и файлов коллекций
`.hlc2`. Архивы: **HomeLibRu.zip** (x86) и **HomeLibRu_x64.zip** (x64).
Порядок установки и переноса portable-профиля не изменился; подробности
есть в [описании pre5.02](https://github.com/Dicur3x/MyHomeLib/releases/tag/2.7.0_pre5.02).
